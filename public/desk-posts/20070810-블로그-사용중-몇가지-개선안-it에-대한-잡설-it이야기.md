1) 제가 블로그에서 리뷰쓰기를 쓰지 않고 다시 리뷰로그를 선택한 이유 포스트에 리뷰쓰기 템플릿이 제공된것을 매우 기뻐하면서 한개의 영화감상을 적었었습니다.

그런데..

리뷰로그를 위한 카테고리를 새로 만들려다 보니 카테고리가 이미 너무 많더군요.

더군다나, 막상 작성하고나니 기존의 리뷰로그를 다시 옮기는 것도 엄청난 일...

또한 리뷰로그에 좋아보이던 기능중 하나인책/영화/쇼핑에 대한 카테고리 기능 역시 못쓰게 된다는것도 아쉬움...

결국은 그냥 다시 리뷰로그를 작성하게 되었습니다.

덕분에 리뷰를 작성할때 스마트에디터의 막강한 기능은 포기해야하는 아쉬움도 있었지만기존의 리뷰로그의 이점을 포기하기는 아쉽더군요.

이전에도 한번 말씀드렸었는데...

2) 프롤로그/블로그/리뷰로그의 상단 탭도 사용자가 편집 할수 있으면 좋겠습니다.

현재 블로그-카테고리 리뷰로그-카테고리 구조를카테고리-카테고리로 쓰도록하고1개의 카테고리에 리뷰로그와 프롤로그의 속성을 부여할수 있게 해주면 좋겠습니다.

대문(프롤로그)/잡담(블로그1)/스크랩(블로그2)/감상록(리뷰로그) 아래로 너무 늘어지는 카테고리는 좀 답답해보입니다.

또한 리뷰로그에도 스마트 에디터 붙여주세요.

3) 글구..

recent comment 말고..

recent post도 좀 만들어주세요.

블로그가 느슨한 결합을 유도하는건 알겠지만,미니홈피용도로 쓰는 사람도 있고, 이웃 블로그에가도 최근 포스트가 어떤건지 알기가 어렵네요.

4) 네이버의 포토갤러리 멋지던데..

아예 포토로그대신 포토갤러리가 연동되었으면 합니다.

사진을 두군데 다 올리기는 힘들잖아요.

4) 블로그도 카테고리 클릭시 최근 포스트가 아닌 메모로그 방식으로 리스트로 설정할수 있었으면 좋겠습니다.

여전히 그 방식을 선호하는 사람들도 있습니다.

특히 자료용으로 모아놓은 스크랩 자료 같은 경우, 별로 포스트로 노출 하고 까지는 싶지 않거든요.

1) I was very happy to see the review writing template provided in the post "Why I chose Review Log again instead of writing reviews on my blog," and I wrote one movie review. However, when I tried to create a new category for Review Log, I realized I already had too many categories. Moreover, once I actually wrote it, moving existing review logs again seemed like a huge task... Also, it was a shame that I couldn't use the category function for books/movies/shopping, which was one of the features I liked about Review Log. In the end, I just decided to write Review Logs again. Thanks to this, I had to give up the powerful features of Smart Editor when writing reviews, which was a bit disappointing, but I found it hard to give up the advantages of the existing Review Log. I mentioned this once before...

2) It would be great if users could edit the top tabs for Prologue/Blog/Review Log. Currently, the structure is Blog-Category and Review Log-Category. It would be better if it could be used as Category-Category, and if one category could be given the attributes of both Review Log and Prologue. For example: Homepage (Prologue)/Chat (Blog1)/Scrap (Blog2)/Reviews (Review Log). Categories that stretch too far down look a bit cluttered. Also, please add Smart Editor to Review Log.

3) And... please create a "recent post" feature, not just "recent comment." I understand that blogs encourage loose connections, but some people use them like mini-homepages, and it's hard to tell what the recent posts are even when visiting a neighbor's blog.

4) Naver's photo gallery looks great... I wish the photo gallery would be linked instead of a separate photolog. It's hard to upload photos to two places.

4) I wish that when clicking on a category in a blog, it could be set to display a list in a memo log style instead of recent posts. There are still people who prefer that method. Especially for scrap materials collected for reference, I don't necessarily want them exposed as posts.
