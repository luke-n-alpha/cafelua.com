** 4.1. 용어정의**
4.1.1.  말풍선 영역 : 만화에서 그림 외에 대사가 위치하는 영역으로 흰색 구름이나 원형의 이미지로 이루어진 영역으로 대사영역을 포함한다.
4.1.2.  대사 영역 : 말풍선 영역 내에 검은색이나 흰색의 텍스트의 이미지 영역을 의미한다.
4.1.3.  대사 : 대사영역의 Text Context를 의미한다.

**             **

** 4.2. 방법1**
4.2.1. 원본과 대사 영역의 리사이즈 크기 이원화
4.2.1.1.  먼저 원본 이미지를 타겟 단말의 크기에 맞게 리사이즈

4.2.1.2. 말풍선 영역 추출 : 이미지 전처리기와 특징을 확인하여 원본이미지에서 말풍선 영역을 추출한다.
-  원본 이미지 위치 : 10,30,100,100 = 90*70 짜리 말풍선 영역 추출

4.2.1.3. 대사 영역 추출 : 말풍선 영역내에 검은글씨 영역을 추출한다.
-  90*70 말풍선 이미지 내에 : (10,5,85,60) = 75*55 짜리 대사 영역 추출

4.2.1.4. 말풍선 원본 리사이즈 비율로 리사이즈 :
-  90*70 을 0.4 비율로 리사이즈 = 36*28 크기로 변경

4.2.1.5.  대사 영역 리사이즈된 말풍선 크기에 최적화 리사이즈 비율 구하기
-  여백 없이 축소 리사이즈시 가장 적합한 크기로 리사이즈
-  말풍선영역이 다각형인 경우가 많으므로 흰색 영역을 벗어나지 않도록 한다.
-  대사 영역 리사이즈 비율을 0.5으로 구했다면 = 36*23 짜리 대사 리사이즈 이미지로 변경
4.2.1.6.  이미지 병합
-  리사이즈된 원본 이미지 + 리사이즈된 대사영역 을 합해 최종 이미지를 만든다.

4.3. 방법2.
4.3.1. 대사 영역의 Clear타입의 글씨로 변환
4.3.2.
4.2.1.3에서 추출된 대사영역에 OCR수행하여 텍스트 정보 추출
4.2.1.2에서 추출된 말풍선 영역에서 대사영역 삭제
(배경색을 추출하여 전경색을 삭제함)
4.3.3.  리사이즈된 비율에 따라 <Div>로 오버래핑할 대사 영역 재구성,
이때 Text의 크기는 위에서 구한 최대 크기에 적합하도록 구성
Html 태그를 통해 브라우져에서 대사영역을 랜더링 하도록 함
추출된 OCR 정보는 검색 컬랙션 데이터로 활용하여 만화의 Context기반 검색에 활용할 수 있음

**5. 특징점 **
- 카툰의 글씨 영역을 최적화 하기 위해 글씨 크기변경을 원본 크기와 이원화 하는 방법
- 카툰의 이미지 대사 영역을 제거하고, Text이미지 영역으로 대체하는 방법

**1. Title:** Mobile Cartoon Speech Bubble Reprocessor
****
**2. Background:** When trying to view mobile cartoons on low-resolution and small screens, the text is often difficult to read. This project aims to solve this problem as much as possible. I often struggled to read the text when viewing "Knight Run" on Naver Webtoon. I would like to propose a solution using image processing.
****
**3. First Written: February 23, 2010**
****
**4. Detailed Content**
**{{IMG:1}}**
**4.1. Terminology Definition**
   4.1.1. Speech Bubble Area: In a comic, this is the area where dialogue is located, apart from the illustrations. It consists of white cloud or circular images and includes the dialogue area.
   4.1.2. Dialogue Area: Refers to the image area of black or white text within the speech bubble area.
   4.1.3. Dialogue: Refers to the Text Context within the dialogue area.

**4.2. Method 1**
   4.2.1. Dual Resizing of Original and Dialogue Areas
     4.2.1.1. First, resize the original image to fit the target device's screen size.
- Assuming resizing based on a horizontal resolution of 320, if the original image's width is 800, the resizing ratio for the original image becomes 320/800 = 0.4.

    4.2.1.2. Extract Speech Bubble Area: Extract the speech bubble area from the original image by checking image preprocessors and features.
- Original image location: 10,30,100,100 = Extract a 90*70 speech bubble area.

    4.2.1.3. Extract Dialogue Area: Extract the black text area within the speech bubble area.
- Within the 90*70 speech bubble image: (10,5,85,60) = Extract a 75*55 dialogue area.

    4.2.1.4. Resize Speech Bubble by Original Resizing Ratio:
- Resize 90*70 by a 0.4 ratio = Change to 36*28 size.

    4.2.1.5. Determine Optimal Resizing Ratio for Dialogue Area to Fit Resized Speech Bubble Size
- Resize to the most suitable size when shrinking without margins.
- Since speech bubble areas are often polygonal, ensure they do not extend beyond the white area.
- If the dialogue area resizing ratio was determined to be 0.5 = Change to a 36*23 dialogue resized image.
    4.2.1.6. Image Merging
- Combine the resized original image + resized dialogue area to create the final image.

 4.3. Method 2.
     4.3.1. Convert Dialogue Area to Clear-type Text
     4.3.2.
       Perform OCR on the dialogue area extracted in 4.2.1.3 to extract text information.
       Delete the dialogue area from the speech bubble area extracted in 4.2.1.2.
        (Extract background color and delete foreground color)
      4.3.3. Reconstruct the dialogue area to be overlapped with <Div> according to the resized ratio,
             At this time, the text size should be configured to fit the maximum size determined above.
             Allow the browser to render the dialogue area using HTML tags.
             The extracted OCR information can be used as search collection data for context-based searching of comics.

**5. Key Features**
 - A method to optimize the text area of cartoons by dualizing text size changes from the original size.
 - A method to remove the image dialogue area of cartoons and replace it with a text image area.
