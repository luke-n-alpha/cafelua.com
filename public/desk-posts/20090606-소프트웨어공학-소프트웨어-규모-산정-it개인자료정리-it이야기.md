**마. FP 간이법 예제**
- 문제 : 기능수와 평균복잡도 가중치가 주어졌다. 간이법으로 조정된 개발 기능점수 AFP(DFP)를 계산 하시오.

| **구분** | **기능수** | **평균복잡도 가중치** | col4 |
| --- | --- | --- | --- |
| 데이터 | ILF | 3 | 7.4 |
| EIF | 1 | 5.5 |  |
| 트랜잭션 | EI | 3 | 4.3 |
| EO | 1 | 5.4 |  |
| EQ | 2 | 3.8 |  |

1) 기능별 평균 점수 구하기
- 공식 : 기능별 평균 점수= 기능수 * 평균 복잡도 가중치
IFL 기능 평균 점수(22.2) =  3 * 7.4
EIF 기능 평균 점수(5.5) =  1 * 5.5
EI 기능 평균 점수(12.9) =  3 * 4.3
EI 기능 평균 점수(5.4) =  1 * 5.4
EO 기능 평균 점수(7.6) =  2 * 3.8
2) 조정전 기능 점수(UFP)구하기
기능별 평균점수의 합(53.6) = 22.2 + 5.5 + 12.9 + 5.4 + 7.6
3) 영향도(TDI) 구하기
시스템의 특성에 따라 14항목에 대해 0~5점까지 점수 산정, 주어진 TDI가없으므로 모두 2.5로 가정
14항목의 점수의 합 = 2.5 * 14 = 35 = 영향도 (TDI)
4) 조정계수(VAF) 구하기
- 공식 :  VAF = (0.01 * TDI) + 0.65
VAF = (0.01 * 35) + 0.65 = 1
5) 조정된 개발 기능 점수 구하기
- 공식 : AFP(DFP) = UFP * VAF
UFP(53.6) * VAF(1) = AFP(DFP) = 53.6
*** 간이법 산정시 유의사항**
- 적용 시기 및 시스템 환경에 맞는 평균 복잡도 가중치 결정 중요 : 공인된 표준 지표 활용
- 시스템 특성에 따른 영향도 적용시 핵심 인자를 위주로 복잡도 고려, 보정 계수 적용
- 데이터/트랜잭션 기능수 식별이 어려운 경우, 기 축적되 FP산출 결과 활용

**1. Concept of Software Size Estimation**
 - Due to characteristics such as software's invisibility and changeability, it is difficult to predict the resources to be invested in development. This technique, as defined by ISO 14143-1, involves predicting and understanding the quantitative and qualitative size of software to estimate and manage the resources, costs, and personnel required. It is divided into methods that measure input effort and methods based on deliverables. Methods based on deliverables include FP, which considers both quantitative and qualitative levels, and COCOMO, which is based on LOC (Lines of Code) and focuses on quantitative levels.
** a. Difficulties in Software Size Estimation**
   - Invisibility of software
   - Many human-dependent factors
   - Strong dependency on development technology and environment
   - Emergence of new technologies
   - Low precision

**e. FP Simplified Method Example**
 - Problem: Given the number of functions and average complexity weights, calculate the adjusted development function points AFP (DFP) using the simplified method.

| **Category** | **Number of Functions** | **Average Complexity Weight** | col4 |
| --- | --- | --- | --- |
| Data | ILF | 3 | 7.4 |
| EIF | 1 | 5.5 | |
| Transaction | EI | 3 | 4.3 |
| EO | 1 | 5.4 | |
| EQ | 2 | 3.8 | |

 
1) Calculate the average score per function
  - Formula: Average score per function = Number of functions * Average complexity weight
   IFL Function Average Score (22.2) = 3 * 7.4
   EIF Function Average Score (5.5) = 1 * 5.5
   EI Function Average Score (12.9) = 3 * 4.3
   EI Function Average Score (5.4) = 1 * 5.4
   EO Function Average Score (7.6) = 2 * 3.8
2) Calculate Unadjusted Function Points (UFP)
 Sum of average function scores (53.6) = 22.2 + 5.5 + 12.9 + 5.4 + 7.6
3) Calculate Degree of Influence (TDI)
  Score 0-5 for 14 items based on system characteristics. Assuming all are 2.5 as no TDI is given.
  Sum of scores for 14 items = 2.5 * 14 = 35 = Degree of Influence (TDI)
4) Calculate Value Adjustment Factor (VAF)
  - Formula: VAF = (0.01 * TDI) + 0.65
    VAF = (0.01 * 35) + 0.65 = 1
 5) Calculate Adjusted Development Function Points
  - Formula: AFP (DFP) = UFP * VAF
    UFP (53.6) * VAF (1) = AFP (DFP) = 53.6
 *** Precautions for Simplified Method Estimation**
   - Importance of determining average complexity weights appropriate for the application timing and system environment: Utilize certified standard indicators.
   - When applying the degree of influence based on system characteristics, consider complexity focusing on key factors and apply correction coefficients.
   - If identifying data/transaction function counts is difficult, utilize previously accumulated FP calculation results.

**5. Future Outlook for Software Size Estimation**
** a. Emergence of New Software Prediction Models**
  - Neural network models: Modeling for quantitative and non-quantitative processing
  - Case-based models: Based on past similar experiences
** b. Focus on Object-Oriented and Component-Based Prediction Methods**
  - LOC methods are fading, FP methods are an alternative.
