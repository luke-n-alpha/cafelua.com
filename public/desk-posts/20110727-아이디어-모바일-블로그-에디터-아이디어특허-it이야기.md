**1. 제목 : 모바일 블로그 에디터****
****2. 최초 작성일 : 2010년 11월 25일****
****3. 배경 :** 현재 블로그 에디터는 기능이 매우제한적이다. 또한 웹에서 이미지를 추가하거나 붙히는것 또한 쉽지 않다. 그래서 좀더 자유롭고 강력한 에디터를 구성해본다.
**4. 개념****1) Pic say와 같이 레이어와 이미지기반의 에디터**- 축소 확대가 자유로울것- 파워포인터나 포토샵처럼 객체간 레이어를 제공할것- 다수의 이미지를 로딩해 배열이 가능할것
**2) html 변환**- 편집과 저장시에는 이미지기반의 에디터로 동작하지만 html export기능 제공, 개시시에는 이를 이용해 퍼블리싱을 지원한다.
**3) 미리보기**- 설정한 블로그의 미리보기 지원
**4) 개시**- 블로그의 open api를 이용한 퍼블리싱 기능 사용- 복수개의 블로그를 관리기능
**5) 템플릿 지원**- 공통 배너를 삽입하는 기능- 메타블로그의 스크립트를 삽입하는 기능
**6) 포스팅 속성 지원**- 공개범위와 ccc, 혹은 포스팅의 카테고리 등의 속성을 xml형태로 제공하여 이를 지원하고 이를 오픈하여 블로그는 포스팅시 타겟블로그는 선택적으로 이를 사용할 수 있도록 한다.   **http://opencast.naver.com/FS565****[****](http://www.hanrss.com/add_sub.qst?url=http%3A%2F%2Fblog.rss.naver.com%2Ffstory97.xml)** {{IMG:1}}

**1. Title: Mobile Blog Editor****
****2. Initial Creation Date: November 25, 2010****
****3. Background:** Current blog editors have very limited functionality. Also, adding or pasting images on the web is not easy. Therefore, I propose to build a more flexible and powerful editor.
**4. Concept****1) Layer and image-based editor like Pic say**- Free scaling (zoom in/out)- Provide layers between objects like PowerPoint or Photoshop- Able to load and arrange multiple images
**2) HTML Conversion**- Functions as an image-based editor during editing and saving, but provides HTML export functionality, supporting publishing using this feature upon posting.
**3) Preview**- Supports preview for the configured blog
**4) Publishing**- Uses publishing functionality via blog's open API- Multi-blog management functionality
**5) Template Support**- Function to insert common banners- Function to insert meta-blog scripts
