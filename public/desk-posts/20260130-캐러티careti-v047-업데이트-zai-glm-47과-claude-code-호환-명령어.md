안녕하세요. **Careti(캐러티)**를 만들고 있는 루크입니다.업데이트가 배포되었습니다. 이번 버전에서는 새로운 모델, 명령어 시스템, UI 개선을 추가했습니다.

{{IMG:1}}

**1. Z.AI GLM-4.7 지원**

가성비와 성능을 갖춘 **Z.AI의 GLM-4.7** 모델을 추가했습니다.비용 부담 없이 코딩 작업을 진행하거나, 사이드 프로젝트에서 실험해보고 싶을 때 활용할 수 있습니다. 기존 Z.AI 사용자분들도 Careti에서 바로 연동 가능합니다.**​**

**2. Claude Code 호환 명령어 시스템**

**Claude Code와 호환되는 명령어 시스템**을 추가했습니다.**.agents/commands/** 폴더에 명령어 파일을 만들면 **/init**, **/commit** 같은 슬래시 명령어를 사용할 수 있습니다. Claude Code를 사용하시던 분들은 기존 워크플로우 그대로 Careti에서도 사용할 수 있습니다. 마이그레이션 비용 없이 두 도구를 함께 사용하거나 전환할 수 있습니다.*📖 **상세 문서: 에이전트 표준화 & Claude Code 호환*

**​**

**3. SmartEditEngine 개선**

코드 수정 시 정확한 위치를 찾는 **SmartEditEngine**을 개선했습니다.9단계 퍼지 매칭(Fuzzy Matching)과 6단계 폴백(Fallback) 시스템을 적용했습니다. AI가 생성하는 SEARCH 블록의 공백이나 들여쓰기가 미세하게 달라도 자동으로 보정하여 편집 성공률을 높입니다.저성능 모델에서 특히 효과가 큽니다. 실제 테스트에서 Gemini Flash Lite는 70%→100%, Solar Mini는 63%→100%로 성공률이 향상되었습니다. 재시도 없이 바로 성공하므로 시간이 약 절반으로 줄어듭니다.*📖 **상세 문서: SmartEditEngine**​*

**4. UI 개선**

- **GFM Markdown 지원**: AI 응답에 테이블이 포함될 때 구조화된 형태로 표시됩니다. Cline은 raw 텍스트로 표시되지만, Careti는 비교표와 옵션 목록을 시각적으로 명확하게 전달합니다. ([상세 문서](https://github.com/caretive-ai/project-careti/blob/main/careti-docs/features/f17-gfm-table-markdown-support.md))
- **TypewriterText**: 스트리밍 텍스트에 shimmer 애니메이션을 추가했습니다.
- **ThinkingRow**: reasoning/thinking 모드 표시를 위한 새로운 UI를 추가했습니다.
- **ToolGroupRenderer**: 도구 작업들을 그룹으로 표시합니다.
- **Background Edits**: 백그라운드에서 파일 편집을 지원합니다.
- **Explain Changes**: 코드 변경 사항을 설명해주는 도구를 추가했습니다.
**​**

**5. 그 외 변경사항**

- **웹 검색**: SerpAPI 연동으로 웹 검색 기능을 추가했습니다.
- **리브랜딩**: Caret → Careti 브랜드 변경을 완료했습니다.
**​****마치며**v0.4.7에서는 모델 선택의 폭을 넓히고, Claude Code 사용자들도 편하게 사용할 수 있도록 호환성을 추가했습니다.피드백은 언제든 환영합니다.​

Hello, this is Luke, creator of **Careti**. An update has been released. This version adds a new model, a command system, and UI improvements.

{{IMG:1}}

**1. Z.AI GLM-4.7 Support**

We've added **Z.AI's GLM-4.7** model, which offers both cost-effectiveness and performance. You can use it for coding tasks without worrying about costs, or for experimenting with side projects. Existing Z.AI users can also link it directly within Careti.

**2. Claude Code Compatible Command System**

We've added a **Claude Code compatible command system**. By creating command files in the **.agents/commands/** folder, you can use slash commands like **/init** and **/commit**. Users who have been using Claude Code can continue to use their existing workflow in Careti. You can use both tools together or switch between them without migration costs.
*📖 **Detailed documentation: Agent Standardization & Claude Code Compatibility***

**3. SmartEditEngine Improvement**

We've improved **SmartEditEngine**, which accurately finds the correct location when modifying code. It now applies a 9-step Fuzzy Matching and a 6-step Fallback system. This automatically corrects minor differences in spaces or indentations in the SEARCH blocks generated by AI, increasing the success rate of edits. This is particularly effective with lower-performance models. In actual tests, the success rate improved from 70% to 100% for Gemini Flash Lite, and from 63% to 100% for Solar Mini. Since edits succeed immediately without retries, the time taken is reduced by approximately half.
*📖 **Detailed documentation: SmartEditEngine**​*

**4. UI Improvements**

- **GFM Markdown Support**: When AI responses include tables, they are displayed in a structured format. While Cline displays raw text, Careti visually conveys comparison tables and option lists more clearly. ([Detailed documentation](https://github.com/caretive-ai/project-careti/blob/main/careti-docs/features/f17-gfm-table-markdown-support.md))
- **TypewriterText**: Added a shimmer animation to streaming text.
- **ThinkingRow**: Added a new UI for displaying reasoning/thinking mode.
- **ToolGroupRenderer**: Displays tool operations as a group.
- **Background Edits**: Supports file editing in the background.
- **Explain Changes**: Added a tool to explain code changes.

**5. Other Changes**

- **Web Search**: Added web search functionality by integrating with SerpAPI.
- **Rebranding**: Completed the brand change from Caret to Careti.

**Conclusion**
In v0.4.7, we've expanded the range of model choices and added compatibility to make it easier for Claude Code users. Feedback is always welcome.
