**1. 목적
**- 메타정보화
- 대사의 텍스트화를 이용해 검색및 번역에 활용
- 만화 컨텐츠 내에 있는 구조를 표현하고 각 구조를 객체로 설정하여 댓글이나 트랙백등의 유저 인터렉션을 가능하게 한다.

****
**2. 개념**
제작툴(윈도우어플 혹은 웹) -> 오픈된 표준 포맷 파일 생성 -> 다양한 리딩툴(모바일및 웹)

**3. 제작툴 상세 내용
**1) 포토샵, 일러스트레이터, 페인터를 이용한 디지털 원화 작업

2) 메타정보 셋팅
- 만화 제목, 국가, 장르, 권장 등급, 작가, 홈페이지, 저작권회사, 읽기방향 등 표기
-> 결과물 xml 파일

3) 컷 지정툴
- 만화에 컷에 대한 정의를 할 수 있는 툴, 컷을 지정하는 목적은 다수의 원화가 모바일이나 다른 툴로 옮겨지거나 웹툰으로 정의되는 과정에서 잘리거나 합쳐지는 단위로 지정하기 위함이다. 또한 만화의 가장 하부 컨텐츠로 지정이가능하다.
이를 이용해 웹에서는 컷에 댓글을 다는 형태의 액션을 취할 수 있다.

- 컷 마스크 - 만화원화작업중에 마스크레이어를 만들고 마스크 이미지만을 따로 저장하여 원본이미지와 마스크 이미지 파일을 동시 업로드시 이 정보를 이용하여 자동으로 컷 지정을 해준다.

4) 말풍선툴
- 말풍선 영역에 대사를 입력하는 툴, 기본적으로 말풍선에는 대사를 비워둔채로 툴로 입력하는 것이 가장 손쉬운방법이다.
- 말풍선 마스크 : 말풍선 영역을 흑백이미지로만들고 하얀색글씨로 글을 써넣은 추가의 이미지 파일, 이 역시 포토샵등의 레이어 기능으로 손쉽게 제작이 가능하다.이를 이용시 자동으로 추출이 가능한데 psd파일을 올려 포맷을 분석해서 텍스트를 추출하는 방법과 퀄리티가 충분히 보장되는경우 ocr기술을 이용하여 추출해낸다.
: 말풍선의 경우 말풍선 영역은 정형화된 도형이 아닌 경우가 대다수 이므로 마지막 목적 파일에서는 저장되지 않고 대사만 xml 로 저장이된다. 이때 글자영역은 글자의 위치인 rect정도만 표현된다.
: 이를 이용해서 만화의 대사 역시 하나의 웹 리소스로 여겨지므로 대사에 댓글을 달거나 공유하는 행동이 가능하다.
: 이미지 처리가 쉽지 않다면 대사를 넣는 별도의 툴을 제공한다.
: 작가가 수기로 쓴 폰트를 원하는 경우에는 말풍선내의 글씨이미지는 그대로 둔채로 대사의 메타정보만 기억해 네이버의 본문검색 형태로 보여줄 수 있다.

==> 최종 결과물 : 원화이미지, 컷마스크, 말풍선대사를 포함한 레이어드된 포토샵의 psd파일 혹은 레이어별의 별도의 다른 이미지 파일

**4. 뷰어**
위의 포맷을 볼수 있는 어플리케이션으로 웹이나 pc혹은 모바일이 될수도 있다.

**- 공유/댓글 기능 :** 뷰어의 대사와 컷에 마우스를 클릭시 팝업이 뜨면서 해당 리소스에 댓글을 달거나, 미투데이, 블로그, 페이스북, 트위터에 공유할 수 있는 고유주소를 제공한다.

- 네이버 블로그에 컷이나 대사를 스크랩도 가능하다. 이때 출처와 컷이미지나 대사가 본문에 삽입된다.
**- 댓글 보기 :** 댓글의 경우 하단에 달린 리스트의 댓글에 추가가되며 해당 댓글을 클릭시 만화리소스의 앵커로 직접이동하고 하이라이트 시킬수 있다. 만화의 상단에 영역별 댓글 보기를 클릭시, 각 영역별로 달린 댓글의 개수가 표기되고, 해당 영역을 재클릭시 하단의 댓글리스트는 해당영역의 댓글로 필터링 되거나 팝업으로 해당영역의 댓글만 리스트업된다.

**5. 컷이미지의 활용
**단순히 컷이미지를 스크랩하는것이 아니라 저작권이 허용하는한에서 2차저작물로 활용도 가능하다. 스크랩대신 클릭후 2차저작물 만들기 버튼을 누르면 이미지에디터로 해당 컷이 통째로 넘어가면서 이를 편집하여 활용할 수 있다. 이를 통해 해당 컷의 대사를 바꾸거나 스티커를 붙여서 블로그에 개제하는 행위를 할 수있다. 이때 스크랩과 마찬가지로 컷이 활용된 링크와 개수는 원본에 남게된다.
- 유저는 다수의 컷을 함께 필요로 할수 있으므로 이때 컷선택은 멀티선택을 지원할 수도 있다.

**6. 차별성
**1) 만화의 컷별 대사별 xml 파일을 이용한 메타정보화
2) 컷별 대사별 공유및 댓글 기능
3) 마스크 이미지를 통한 컷 입력기
5) 컷의 2차저작물 제작및 공유방법

**1. Purpose**
- Metadata creation
- Utilize text conversion of dialogue for search and translation
- Express the structure within comic content, set each structure as an object, enabling user interactions like comments or trackbacks.

**2. Concept**
Production Tool (Windows app or web) -> Generate Open Standard Format File -> Various Reading Tools (Mobile & Web)

**3. Production Tool Details**
1) Digital original artwork using Photoshop, Illustrator, Painter
  -> Result: High-resolution jpg; tif; png images

2) Metadata Settings
- Display comic title, country, genre, recommended rating, author, homepage, copyright company, reading direction, etc.
 -> Result: XML file

3) Panel Designation Tool
- A tool to define panels in a comic. The purpose of designating panels is to define units that can be cut or merged when multiple original artworks are transferred to mobile or other tools, or defined as webtoons. It can also be designated as the lowest-level content of a comic.
Using this, on the web, actions such as adding comments to panels can be taken.

- Panel Mask - During comic original artwork creation, a mask layer is created, and only the mask image is saved separately. When the original image and mask image files are uploaded simultaneously, this information is used to automatically designate panels.

 At this time, panels can be automatically numbered according to the reading direction specified for the comic. The input file is a grayscale image of the same resolution, a layered file composed of PNGs, or a graphic file including layers from Naver Photo Editor. If PSD format layer information can be read, it can be used as is.

4) Speech Bubble Tool
- A tool for entering dialogue into speech bubble areas. The easiest method is to leave the speech bubbles empty and input the dialogue using the tool.
- Speech Bubble Mask: An additional image file where the speech bubble area is made into a black and white image with white text written on it. This can also be easily created using layer functions in Photoshop, etc. When used, text can be automatically extracted by uploading a PSD file to analyze the format, or by using OCR technology if sufficient quality is guaranteed.
: In the case of speech bubbles, the speech bubble area is often not a standardized shape, so it is not saved in the final destination file; only the dialogue is saved as XML. At this time, the text area is represented only by its position (rect).
: Using this, comic dialogue is also considered a web resource, making it possible to comment on or share dialogue.
: If image processing is not easy, a separate tool for entering dialogue will be provided.
: If the author desires a handwritten font, the text image within the speech bubble can be left as is, and only the dialogue's metadata can be remembered and displayed in the form of Naver's body text search.

==> Final Output: Layered Photoshop PSD file including original artwork, panel masks, and speech bubble dialogue, or separate image files for each layer.

**4. Viewer**
An application that can view the above formats, which could be web, PC, or mobile.
For web servers, the original artwork is resized to a resolution optimized for each device, and the panel XML file is also resized. Afterwards, the dialogue is overlaid on the original artwork using a ClearType font.
**- Multi-language Translation Support (Panel Subtitle Support):** Dialogue information can be converted into other languages. Translated dialogue can be re-applied over the original artwork using ClearType, or displayed as **subtitles** at the bottom of the panel area.

**- Share/Comment Function:** When clicking on dialogue or panels in the viewer, a popup appears, allowing users to comment on the resource or providing a unique URL to share on Me2day, blogs, Facebook, or Twitter.

- It's also possible to scrap panels or dialogue to Naver blogs. In this case, the source and the panel image or dialogue are inserted into the body of the post.
**- View Comments:** Comments are added to the list at the bottom. Clicking on a comment directly navigates to the anchor of the comic resource and highlights it. When clicking "View Comments by Area" at the top of the comic, the number of comments for each area is displayed. Re-clicking an area will filter the comment list at the bottom to show only comments for that area, or list only comments for that area in a popup.

**5. Utilization of Panel Images**
Beyond simply scrapping panel images, they can also be used as derivative works, as long as copyright allows. Instead of scrapping, clicking the "Create Derivative Work" button transfers the entire panel to an image editor, where it can be edited and utilized. This allows users to change the dialogue of the panel or add stickers and post it on a blog. In this case, similar to scrapping, the link and count of how many times the panel was used remain with the original.
- Users may need multiple panels together, so panel selection could support multi-selection.

**6. Differentiators**
1) Metadata creation using XML files for each panel and dialogue of a comic
2) Share and comment functions for each panel and dialogue
3) Panel input tool via mask images
4) Subtitle function for each panel
5) Method for creating and sharing derivative works of panels
