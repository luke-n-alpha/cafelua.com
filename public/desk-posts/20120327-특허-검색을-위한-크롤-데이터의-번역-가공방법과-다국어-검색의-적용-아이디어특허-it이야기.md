{{IMG:1}}**특허 제목 :  검색 서비스를 위해 데이터를 생성하기 위한 방법, 시스템 및 컴퓨터 판독 가능한 기록 매체** METHOD, SYSTEM AND COMPUTER-READABLE RECORDING MEDIUM FOR CREATING DATA FOR RETRIEVAL**IPC 코드 :**  G06F 17/30 (2006.01)**출원번호 :** 1020080103894 (2008.10.22)**공개번호 :** 1020100044670 (2010.04.30)**등록번호 :** 101117171 (2012.02.09)**발명자/고안자 :** 양병석 | 황준호 | 성기준**관련 URL :** [http://me2.do/GlKWy4I](http://me2.do/GlKWy4I)

아이디어는 기존의 크롤링된 데이터들을 다국어로 번역하여 검색시 제공하는 방법입니다. 간단히 말해 한글로 포켓몬이라고 쳤을때, 일본사이트의 크롤링 된 데이터를 노출할 수 있도록, 크롤링의 index를 한국어로 번역해두는 방법입니다. 최근 등록됬네요. 물론, 이 아이디어는 적용되지 않았습니다. 검토 제안 드린적이 있던가 ? 워낙 오래전 일이라 가물가물.
**-- 출원 초안 --****1. 제목 : 검색을 위한 크롤 데이터의 번역 가공 방법과 다국어 검색의 적용****2. ****배경 :** 해외 사이트 검색을 위해서는 해외 사이트의 언어를 알아야 한다. 한국어 사이트보다도 더 많은 데이터가 해외에 존재 할 수 있다. 이를 위해 언어적 장벽을 뛰어넘기 위한 수단으로 다국어 검색을 하기위한 크롤 데이터의 번역기 적용 기능과 이를 이용한 검색기를 제안한다.
**1) 현재의 일본어 번역 검색기능**{{IMG:2}}
- 위의 예에서 보이는 것은 현재 네이버의 일본어 검색 기능이다. 검색어를 쳐 넣으면 한국어 쿼리를 일본어로 번역하여 일본 구글에 쿼리를 넘기고 그 결과를 다시 번역해주는 과정을 거치고 있다.- 그러나 이는 네이버의 입장에서는 검색 결과를 번역한 경우이고, 구글은 단순히 일본어 검색 결과를 나타낸 것 뿐이다.

**3. 개****선 : **보유하고 있는 크롤링 데이터들을 번역해 새로운 크롤링 인덱스를 만든다. 그리고 이를 다시 인덱싱 하여 검색에 활용하고, 사용자가 해당 사이트에 접속시, 번역기를 통해 검색 결과를 보여준다.
**-> 현재 포켓몬(ポケモン)의 원문으로 네이버에서 검색어를 친 결과**{{IMG:3}}
[위의 결과는 일본어로된 크롤 데이터를 현재 네이버가 보유하고 있음을 보여준다.]
**-> 이 데이터를 번역기를 통해 번역을 해 둔다면, 한글로 포켓몬을 쳤을 때, 해당 사이트의 번역 크롤 데이터를 보여 줄 수 있다.** [크롤링된 데이터의 번역결과를 만들어보기 위해, 위의 결과를 번역해보려고 하였으나, 네이버의 검색결과는 한국어 사이트로 인식해, 일어로 번역해버렸다.]{{IMG:4}}

**-> 사용자가 번역된 크롤링 데이터를 통해 검색 결과를 선택할 시, 해당 사이트 전체가 번역이 되어 있지 않다면, 기존의 네이버 일본어 번역기를 통하여 사이트를 브라우징 하게 해준다.** {{IMG:5}} [이는 위의 결과에서 첫번째 검색 결과의 사이트를 네이버 웹 번역기를 통해 본 결과이다.]

**Publication Number:** 1020100044670 (2010.04.30)

**Related URL:** [http://me2.do/GlKWy4I](http://me2.do/GlKWy4I)

The idea is a method of translating existing crawled data into multiple languages and providing it during search. Simply put, when you search for 'Pokemon' in Korean, it's a method of translating the crawl index into Korean so that crawled data from Japanese sites can be exposed. It was recently registered. Of course, this idea was not implemented. Did I ever propose it for review? It was so long ago that I can barely remember.
**-- Application Draft --**
**1. Title: Method for Translating and Processing Crawled Data for Search and its Application to Multilingual Search**
**2. Background:** To search foreign websites, one must know the language of those foreign websites. More data may exist abroad than on Korean websites. To overcome this language barrier, we propose a translator application function for crawled data for multilingual search and a search engine utilizing it.
**1) Current Japanese Translation Search Function**
{{IMG:2}}
- What is shown in the example above is Naver's current Japanese search function. When a search query is entered, it translates the Korean query into Japanese, passes the query to Japanese Google, and then translates the results back.
- However, from Naver's perspective, this is a case of translating search results, while Google merely displays Japanese search results.

**3. Improvement:** Translate the owned crawling data to create a new crawling index. Then, re-index it for use in search, and when a user accesses the corresponding site, show the search results through a translator.
