**XRCloud로 메타버스를 만들어봅시다.** 안녕하세요. 빌리버의 대표 루크입니다. 저희 빌리버에서 드디어 XR Cloud에서 사용해보실 수 있는 API를 내놓았습니다. 아직 만들어가는 팀이다보니 개발 중에 많은 일들이 있었지만 최대한 빠르게 쓰실 수 있는 것을 먼저 보여드리고 싶었습니다. medium.com

​안녕하세요. 웹기반의 메타버스 클라우드 플랫폼, XRCloud를 서비스하고 있는 빌리버의 대표 루크입니다. 저희 빌리버에서 드디어 XRCloud에서 사용해보실 수 있는 API를 내놓았습니다. 아직 만들어가는 팀이다보니 [개발 중에 많은 일들](https://velog.io/@juunini/%EC%84%9C%EB%B9%84%EC%8A%A4%EB%A5%BC-%EC%B6%9C%EC%8B%9C%ED%95%B4%EC%95%BC-%ED%95%A9%EB%8B%88%EB%8B%A4%EB%A7%8C-%EC%A7%80%EC%83%81-%EC%B5%9C%EA%B0%95%EC%9D%98-%EA%B0%9C%EB%B0%9C%EC%9E%90%EB%8A%94-%EB%8D%98%EC%A0%84%EC%97%90%EC%84%9C-%EC%BD%94%EB%94%A9%EC%9D%84-%EC%B6%94%EA%B5%AC%ED%95%98%EB%A9%B4-%EC%95%88%EB%90%98%EB%8A%94%EA%B1%B8%EA%B9%8C-%ED%95%98%ED%8E%B8-)이 있었지만 최대한 빠르게 쓰실 수 있는 것을 먼저 보여드리고 싶었습니다. 많은 말보다 보여드리는것이 먼저라고 데모 페이지를 보여드리겠습니다.[https://demo.xrcloud.belivvr.com/trial/XRCI-S6yhbKLQwcja2cmTQYKI](https://demo.xrcloud.belivvr.com/trial/XRCI-S6yhbKLQwcja2cmTQYKI)

데모페이지에서는 이름을 입력하고 아바타를 선택하고, 씬을 선택하고 입장을 합니다. 개발자가 아니신 분들은 이게 뭐지? 라고 싶을지 모르겠는데, 데모페이지의 맨 위를 보시면 App name이라고 적혀있죠 ? 여러분이 새로운 웹사이트를 만드시고, 저희 개발자센터에서 API를 통해 이런식으로 웹사이트를 만들 수 있음을 의미합니다. [https://demo.xrcloud.belivvr.com](https://demo.xrcloud.belivvr.com/)는 여러분이 만들 새로운 메타버스 플랫폼의 예시이고, XRCloud에서 api를통해 아바타와 씬을 불러와서 접속하는 과정을 보여줍니다.좀더 자세히 순서대로 말씀드리면 아래와 같습니다.​**1. 빌리버 개발자센터에 앱을 등록한다.**[https://developers.belivvr.com/user/apps](https://developers.belivvr.com/user/apps)

개발자센터에 앱을 등록한 모습(앱키는 지웠습니다.)

**2. 원하는 아바타와 씬을 앱과 연결한다.**[https://developers.belivvr.com/spaces](https://developers.belivvr.com/spaces)[https://developers.belivvr.com/avatars](https://developers.belivvr.com/avatars)

**3. API문서대로 개발한다.**[https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/)**3.1. 인증**api : [https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/authorization](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/authorization)* 설명 : 등록된 apID와 appKey를 이용하여 접근가능한 token을 얻고 이를 통해 XRCloud를 이용가능합니다.**3.2. 인증후에 등록된 씬과 아바타들을 받아와서 사용자가 선택할 수 있도록 화면에 뿌려줍니다.****3.2.1. 씬 리스트 가져오기**apidocs : [https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/scenes](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/scenes)앱에 등록된 씬들을 가져옵니다. 헤더에는 인증을 통해 가져온 token을 필요로 합니다.json으로 가져온 아바타들을 적절한 개발을 통해 화면에 뿌려주시면 됩니다.**3.2.2. 아바타 리스트 가져오기**api docs [https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/avatars](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/avatars)씬과 동일합니다. 자세한 설명은 생략합니다.

**3.3. 허브API를 통해 접속하기**api docs : [https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/hubs](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/hubs)post type으로 헤더에는 인증값을 넣어주시고, body에는 적절한 사용자의 닉네임(노출이름), 아바타id를 url에 sceanid와 hubSid를 넣어 접속해주시면 됩니다.

Rather than many words, I'll show you the demo page first. [https://demo.xrcloud.belivvr.com/trial/XRCI-S6yhbKLQwcja2cmTQYKI](https://demo.xrcloud.belivvr.com/trial/XRCI-S6yhbKLQwcja2cmTQYKI)

On the demo page, you enter your name, select an avatar, choose a scene, and enter. For those who are not developers, you might be wondering, "What is this?" If you look at the top of the demo page, it says "App name," right? This means you can create a new website, and through our developer center's API, you can build a website in this way. [https://demo.xrcloud.belivvr.com](https://demo.xrcloud.belivvr.com/) is an example of a new metaverse platform you can create, demonstrating the process of loading avatars and scenes via the XRCloud API and connecting. To explain in more detail, the steps are as follows:
**1. Register an app in the Belivvr Developer Center.** [https://developers.belivvr.com/user/apps](https://developers.belivvr.com/user/apps)

                            App registration in the Developer Center (app key removed)

**2. Connect the desired avatars and scenes to the app.** [https://developers.belivvr.com/spaces](https://developers.belivvr.com/spaces) [https://developers.belivvr.com/avatars](https://developers.belivvr.com/avatars)

                            Adding a scene to My App

**3. Develop according to the API documentation.** [https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/)
**3.1. Authentication**
api : [https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/authorization](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/authorization)
* Description: Obtain an accessible token using the registered appID and appKey, which allows you to use XRCloud.
**3.2. After authentication, retrieve the registered scenes and avatars and display them on the screen for the user to select.**
**3.2.1. Get Scene List**
apidocs : [https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/scenes](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/scenes)
Retrieves scenes registered in the app. The header requires the token obtained through authentication. You can display the avatars retrieved as JSON on the screen through appropriate development.
**3.2.2. Get Avatar List**
api docs [https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/avatars](https://belivvr.github.io/xrcloud-3rd-app-user-api-doc/ko/docs/api/avatars)
Same as scenes. Detailed explanation omitted.

Additionally, what you're probably most curious about here is the question of whether you can register your own scenes and avatars through an editor (Spoke), like Mozilla Hubs. If you look on YouTube, many people have uploaded Spoke tutorials.

Yes, that's correct. We have not yet opened that feature in our developer center. This is to reduce risk, as it's difficult to predict what problems might arise if we receive user data while usage is not yet stable. **However, because we use the file format of Mozilla Hubs project as is, we are privately opening the registration of additional custom avatars and scenes to companies collaborating with us at a B2B level.** If you are interested, please contact us. In the future, we plan to open avatar and scene addition features to general users and also provide our own customized features to control the hub. We appreciate your continued interest.
