* Object's basic methods
 : Uses Override annotation
 - clone() - Copy : Implementation required
 - equals(Obj) - Comparison : Implementation required
 - finalize() - Termination
 - getClass() - No implementation required, but frequently used with Reflection
 - hashCode() - Used to uniquely identify an Object
 - toString() - When implementing a Class that holds a Value
                  (Low usage frequency at NHN)
                   - Represents the state of a Class (Useful in Debug, good practice)

 * If `@override` is written for a method, the compiler checks for the existence of the method in the superclass.
  `@override public boolean equals(Object obj){}`

Annotations can be used at both runtime and compile time. Override is
a type of reflection, performing actions by reading signatures at runtime.

* Meaning of Reflection : At runtime, for a certain class, a method can read the class's signature.
   - Methods are retrieved as an array of classes.

* Resource Bundle : Role of fetching necessary resources from the locale
 - getBundle(String?baseName) : Loads the corresponding resource.
 - getKeys() : Retrieves the list of keys.
 - getObject(key) : Retrieves the value for the corresponding key.
 - getString(key) : Retrieves the value for the corresponding key as a String.

 * Simple syntax, easy to use, changes are not reflected at runtime (cached in memory)
  Cannot handle complex data (lists, hierarchical structures)
  Unicode handling is inconvenient (conversion process required)
