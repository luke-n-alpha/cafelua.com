#### [LG Electronics Cyon LG-LB1700](http://shopping.naver.com/blog/go.nhn?cat_id=00110201&nv_mid=4021336657)

				Cyon
				
				**Rating** 
			
		

	
	

 
		
		
		
	
My current phone,
Best value for money~ I paid 1000 won.
Terrestrial DMB works well,
If there's one drawback, it's that the internal memory is small and full-screen videos
 only support 7.5 fps, which is a bit of a concern,
but I'm using it well with a 1GB memory card inserted. I also watch animations on this thing while commuting.
