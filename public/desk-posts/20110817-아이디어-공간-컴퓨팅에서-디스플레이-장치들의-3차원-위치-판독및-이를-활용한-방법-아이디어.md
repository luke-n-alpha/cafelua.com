**1. 제목 : 공간 컴퓨팅에서 디스플레이 장치들의 3차원 위치 판독및 이를 활용한 방법

****2. 최초 작성일 : 2010년 12월 15일****
****3. 개념 : **[http://health20.kr/1928](http://health20.kr/1928) 의 방법을 보면 KINECT를 이용해 공간을 계산한후, 이를 프로젝트를 통해 투사하는 방식으로 만들어지고 있습니다. 그러나 프로젝트는 어두운곳에서만 활용해야 하고, 사람이 빛속에 있어야 하는 불편함이 있습니다. 이를 개선하기 위해 공간에 위치한 다수의 디스플레이 장치들의 3차원 좌표를 인식하고 이를 유저의 제스츄어의 공간 컴퓨팅으로 활용하는 방법을 제시합니다.
**4. 구현방법**** 1) 고정디스플레이의 위치 구성단계** 디스플레이에서 특정 이미지나 태그를 띄우게 하여 해당 디스플레이가 어디에 위치하는지를 3차원 좌표로 재구성합니다. 이 디스플레이 장치를 찍고 있는 1개 혹은 다수의 카메라를 통해 3차원 좌표를 알아냅니다. 이는 증강현실에서 태깅을 인식하는 방법과 동일합니다.
** 2) 유저 액션** 공간에서 유저가 한개의 디스플레이 앞에 서서 다른 디스플레이를 향해 손짓을 하거나, 어떤 액션을 취할때, 이 액션을 인식하는 단계입니다.
** 3) 유저 인터랙션** 유저가 행한 액션에 맞는 디스플레이들간의 인터렉션을 보여줍니다. A란 디스플레이에서 B의 디스플레이로 이미지나 창이 이동하는 형태로 구현이 가능합니다.
**5. 특징점및 차별점** - 다수의 디스플레이의 액션을 정의하는 컴퓨팅 환경 - 각 디스플레이에 연결된 서버나 데스크탑은 1대 혹은 다수로 각디스플레이마다의 하나의 장치로 연결되어 가상의 공간을 구현합니다.

**1. Title: 3D Position Reading of Display Devices in Spatial Computing and Methods Utilizing It

****2. Original Publication Date: December 15, 2010****
****3. Concept: **Looking at the method in [http://health20.kr/1928](http://health20.kr/1928), it is being created by calculating space using KINECT and then projecting it through a projector. However, projectors must only be used in dark places, and there is the inconvenience of people having to be in the light. To improve this, we propose a method that recognizes the 3D coordinates of multiple display devices located in space and utilizes them for spatial computing based on user gestures.
**4. Implementation Method**** 1) Fixed Display Position Configuration Stage** By displaying a specific image or tag on the display, the location of that display is reconstructed into 3D coordinates. The 3D coordinates are determined through one or more cameras capturing this display device. This is the same method as recognizing tagging in augmented reality.
** 2) User Action** This is the stage of recognizing an action when a user stands in front of one display in space and gestures towards another display or takes some action.
** 3) User Interaction** It shows interactions between displays that match the action performed by the user. This can be implemented in the form of an image or window moving from display A to display B.
**5. Key Features and Differentiators** - A computing environment that defines actions for multiple displays. - Servers or desktops connected to each display, either one or multiple, are connected as a single device per display to create a virtual space.
