결국 오늘은 이렇게 gg.
이러면 안되는데.. 체리필터 너무 좋잖아~!

툴 : 아트패드2, 네이버 블로그 그림그리기 툴
블로그 그림그리기 툴 여태까지는 잘 안썼었는데
투명도 기능을 잘 쓰면 회화 같은 느낌이 나는것 같아 의외로 괜찮다.
싸이월드 툴보다는 크기도 커서 좋고,
시간이 많지 않아 맘먹고 큰 작품 만들기는 어려우니 종종 이놈으로 그려봐야겠다.
문제는 가끔 투명도가 제대로 안먹는 버그가 좀 있는듯..

Got hooked on Cherry Filter and didn't do the studying I was supposed to, but grabbed my tablet instead.
So today, it's gg.
I shouldn't be doing this... But Cherry Filter is just too good~!
 
Tools: ArtPad2, Naver Blog Drawing Tool
I hadn't really used the Naver Blog Drawing Tool much until now,
but if you use the transparency function well, it gives a painterly feel, which is surprisingly good.
It's also better because it's larger than the Cyworld tool,
and since I don't have much time to commit to large-scale works, I think I'll draw with this one often.
The problem is, sometimes the transparency doesn't work properly, which seems to be a bug...
