**--------------------------------**
**1. 제목 : 위치 로그 서비스**
**2. 배경 : **
2.1. 모바일 기기의 확산
2.2. 개인의 안전에 대한 욕구가 높음
2.3. 블로그 포스팅을 작성시, 맵을 연동한다던지의 위치에 대한 DB 연동이 잦음

**3. 개념 :**
3.1. 개인의 모든 일상 위치 정보 기록
- 개인의 이동 경로를 중앙 서버에 기억하고, 웹에서 조회하게 해주는 서비스
=> 집에 도착하여 포스팅을 작성시, 금일의 이동경로를 조회하고, 해당 경로중 좌표를 찍어 포스팅을 바로 할 수 있다.
ex) 금일의 위치 로그 : 삼성역 - KOEX 대서양 홀 - 삼성역 - 평촌역
* KOEX 대서양 홀 클릭 후, SEEK 관람기를 포스팅 한다.
- 모바일 단말에서 이동 중 포스팅
: 지도DB 클릭시, 현재 있는 위치가 삽입 됨

** 3.2. 개인이 탑승한 교통 정보 기록**
- 개인의 이동 경로 정보에는 단순한 좌표 뿐만 아니라 이용 운송 수단의 정보 까지 포함한다.
이때 개인의 위치는 GPS로부터 수신 받는것이 아니라, 탑승한, 혹은 탑승하게 될 운송수단으로부터 무선기술을 이용하여 전송받는다.

{{IMG:6}}

: 개인의 안전에 대한 욕구에 기인 함, 이용한 대중교통의 구체적인 정보가 표시되면, 차 후 범죄 발생시 대응을 쉽게 가능함
- 유실물 찾는데 활용 가능
: 지하철에서 물건을 잊어버린 경우, 대부분 탑승했던 지하철 번호를 아는 경우는 매우 드뭄, 역사에 해당 정보로 연락 가능
ex) 지하철 4호선 16:04 사당 2043호 - 16:20 인덕원
강남 택시 탑승 (가 45 1234 - 선진운수)

** 3.3. 비등록 차량 센싱 가능**
- 개인의 모바일 단말에서 탑승하기 전에 위치 정보 비등록 차량인지 확인 가능
ex) 택시의 경우, 차번호등의 식별 정보를 입력하면, 해당 차량이 등록 차량인지, 또한 현재의 위치가 지금 타려고하는 곳인지 택시 운전기사의 사진등을 조회가 가능함

{{IMG:7}}

**4. 문제점및 사업의 어려움**
4.1. 보안과 개인정보유출의 문제
- 책임있는 사업자가 해당 정보의 생성,보관,폐기
- 개인의 동의하에 수집및 서비스
4.2. 대중교통의 종합 정보 서비스가 갖추어져야 함
- 택시,버스,지하철과도 연계해야하는 대규모 서비스

I haven't had a chance to confirm the scope of the patent, but I'm sharing the initial idea discussed with the patent attorney.
**--------------------------------**
**1. Title: Location Log Service**
**2. Background:**
  2.1. Proliferation of mobile devices
  2.2. High demand for personal safety
  2.3. Frequent DB linkage for location information, such as map integration, when writing blog posts
 
**3. Concept:**
 3.1. Recording all personal daily location information
 - A service that records an individual's movement path on a central server and allows it to be viewed on the web.
=> When arriving home and writing a post, one can view today's movement path and immediately post by marking coordinates along that path.
ex) Today's location log: Samseong Station - KOEX Atlantic Hall - Samseong Station - Pyeongchon Station
   * After clicking KOEX Atlantic Hall, post a SEEK viewing log.
 - Posting while on the move from a mobile device
: When clicking on the map DB, the current location is inserted.

{{IMG:1}}

  [ Inserted similarly to a general DB ]

{{IMG:2}}

 [ When a date is selected, the movement path and main, moved areas for that day are displayed ]

{{IMG:3}}

  [ When clicking on a major destination or mode of transport, the movement path can be displayed and inserted (above shows the path highlighted in red when a mode of transport is clicked) ]

{{IMG:4}}

   [ The time at which the location was inserted is also displayed (time is omitted in the image above) ]
 
{{IMG:5}}

  [ When a mode of transport is inserted, the boarding time is displayed ]

** 3.2. Recording personal transportation information**
 - An individual's movement path information includes not only simple coordinates but also information about the mode of transport used.
In this case, the individual's location is not received from GPS but is transmitted from the mode of transport boarded or to be boarded, using wireless technology.

{{IMG:6}}

  : Stemming from the demand for personal safety, displaying specific information about the public transport used makes it easier to respond in case of future crime.
 - Can be used to find lost items
  : If an item is lost on the subway, it's very rare for people to know the subway car number they boarded. This information can be used to contact the station.
  ex) Subway Line 4, 16:04 Sadang Car 2043 - 16:20 Indeogwon
      Gangnam Taxi Ride (Ga 45 1234 - Seonjin Transport)
 
** 3.3. Sensing unregistered vehicles possible**
 - From an individual's mobile device, it's possible to check if a vehicle is unregistered for location information before boarding.
 ex) In the case of a taxi, by entering identification information such as the car number, one can check if the vehicle is registered, if its current location matches where one intends to board, and view the taxi driver's photo, etc.

{{IMG:7}}

 
**4. Problems and Business Difficulties**
 4.1. Issues of security and personal information leakage
  - Responsible operator for the generation, storage, and disposal of such information
  - Collection and service under individual consent
 4.2. A comprehensive public transport information service must be established
  - A large-scale service that needs to be linked with taxis, buses, and subways
