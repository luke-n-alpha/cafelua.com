*** 사용자 공간 서비스 개발에 유용한 내용으로 XRCLOUD 가이드 문서가 업데이트 되었습니다.****​**

**​****3. 사용자 공간 서비스 개발****1) 접속시 공간의 기능 제한과 아바타 전달**- XRCLOUD의 Hubs접속시 쿼리 파라미터로 Hubs의 기능구성을 통제하거나 아바타, 사용자 이름을 전달할 수 있습니다.
- [XRCLOUD Room접속시 이용 가능한 쿼리파라미터 기능](https://belivvr.notion.site/XRCLOUD-Room-dd59f8659d7b4c5990b2f72212835885)
**2) 크리에이터들을 위한 공간 공유 서비스 개발**- XRCLOUD를 이용하여 내 서비스의 유저들이 자유롭게 창작하고 공유하는 서비스를 만드는 방법에 대한 문서입니다.
- [XRCLOUD를 이용한 크리에이터들을 위한 공간 공유 서비스 개발 방법](https://belivvr.notion.site/XRCLOUD-bb24bdffdcf544408d0e50a8d5cf3b1b)
**3) 템플릿 Scene을 이용한 사용자 서비스 개발**- XRCLOUD를 이용하여 유저별로 템플릿 공간(Room)을 제공하고 꾸미고 공유하게 할 수 있는 서비스 개발 방법에 대한 문서입니다.
- 기본 개발 방법은 서비스에서 Scene을 템플릿 공간으로 취급하여 사용자에게 Room을 생성해 주고 이를 이용하여 사용자별로 해당 공간을 꾸미거나 자유롭게 이용할 수 있게 합니다.
- 필요 API는 Room생성 API입니다.
- [https://api.xrcloud.app/docs/ko/#tag/room/operation/CreateRoom](https://api.xrcloud.app/docs/ko/#tag/room/operation/CreateRoom)
- 생성된 Room은 제작한 플랫폼의 DB에 사용자 정보와 함께 관리합니다.
- 사용자는 Room에 접속하여 공간을 꾸밀 수 있습니다. 템플릿 공간을 만들어 사용자에게 꾸미게하는 상세 방법은 아래의 문서를 참고하세요.
- [템플릿](https://belivvr.notion.site/e4ec0982870e4938b1407cecbad316e2)[공간을 제공하고 사용자가 공간을 꾸미게 하는 방법](https://www.notion.so/e4ec0982870e4938b1407cecbad316e2?pvs=21)
**4) 페이지를 벗어나지 않고 외부 웹페이지의 정보를 제공하는 인라인뷰 컴포넌트**- Hubs는 링크, 이미지 컴포넌트에 링크를 걸어 외부 웹페이지로 보낼 수 있는데 플랫폼 서비스의 사용자 경험을 해칠 수 있습니다.
- XRCLOUD의 Spoke는 Room을 벗어나지 않고 웹페이지를 볼 수 있는 추가 기능을 제공하는 인라인뷰 컴포넌트를 제공합니다. 상세한 설명은 아래의 페이지를 참고하세요.
- [Room을 벗어나지 않고 외부 웹페이지의 정보를 제공하는 XRCLOUD의 인라인뷰 컴포넌트](https://belivvr.notion.site/3D-XRCLOUD-4b861e5ca4394c499b43e7b75645c7ce)
**5) 외부 웹페이지에 동적 데이터를 전달할 수 있는 인라인뷰 컴포넌트**- XRCLOUD의 인라인 컴포넌트에는 개발자가 원하는 정보를 동적으로 전달이 가능합니다.
- 이를 통해 유저별로 다른 웹페이지를 보여준다던가, 혹은 Room에서 다른 공간으로 이동하는 것을 동적으로 설정하게 하거나 분기를 할 수 있게 합니다.
- GetRoom API를 호출할 때 LinkPayload에 원하는 정보를 실어서 인라인뷰가 호출하는 웹페이지에 전달함으로서 해당 웹페이지에서 넘어온 정보에 따라 다른 정보를 보여주거나 혹은 페이지를 라우팅 시키는 용도로 사용이 가능합니다.
- 개발방법과 상세한 예시는 아래의 문서를 참고하세요.
- [외부 웹페이지에 동적 데이터를 전달할 수 있는 인라인뷰 컴포넌트의 개발 및 활용 방법](https://belivvr.notion.site/591573adf4f8482c8c135447fb011975)
**6) 개발자가 동적으로 변경 가능한 객체 Empty Frame**- XRCLOUD는 Spoke메타버스 에디터에서 배치하면 외부에서 API를 통해 동적으로 변경가능한 Empty Frame이라는 신규 객체를 개발했습니다. 아직까지 XRCLOUD API가 아닌 hubs의 reticulum api로 커스텀 되어있어 BELIVVR내부에서만 사용했습니다.
- 향후 XRCLOUD API로 변경하여 정리 공개하겠습니다.

**3. User Space Service Development**
**1) Limiting Space Functions and Delivering Avatars upon Connection**
- When connecting to XRCLOUD Hubs, you can control Hubs' functional configuration or deliver avatars and user names using query parameters.
- [Query Parameter Functions Available When Connecting to XRCLOUD Room](https://belivvr.notion.site/XRCLOUD-Room-dd59f8659d7b4c5990b2f72212835885)
**2) Developing a Space Sharing Service for Creators**
- This document describes how to create a service where users of your service can freely create and share using XRCLOUD.
- [How to Develop a Space Sharing Service for Creators Using XRCLOUD](https://belivvr.notion.site/XRCLOUD-bb24bdffdcf544408d0e50a8d5cf3b1b)
**3) Developing User Services Using Template Scenes**
- This document describes how to develop a service that allows users to provide, decorate, and share template spaces (Rooms) using XRCLOUD.
- The basic development method involves treating a Scene as a template space within the service, creating a Room for the user, and allowing each user to decorate or freely use that space.
- The required API is the Room creation API.
- [https://api.xrcloud.app/docs/ko/#tag/room/operation/CreateRoom](https://api.xrcloud.app/docs/ko/#tag/room/operation/CreateRoom)
- The created Room is managed in the platform's DB along with user information.
- Users can connect to the Room and decorate the space. For detailed instructions on creating a template space for users to decorate, refer to the document below.
- [How to Provide Template](https://belivvr.notion.site/e4ec0982870e4938b1407cecbad316e2)[Spaces and Allow Users to Decorate Them](https://www.notion.so/e4ec0982870e4938b1407cecbad316e2?pvs=21)
**4) Inline View Component that Provides External Webpage Information Without Leaving the Page**
- Hubs can link to external webpages via link and image components, but this can harm the user experience of platform services.
- XRCLOUD's Spoke provides an inline view component that offers additional functionality to view webpages without leaving the Room. For detailed explanations, refer to the page below.
- [XRCLOUD's Inline View Component that Provides External Webpage Information Without Leaving the Room](https://belivvr.notion.site/3D-XRCLOUD-4b861e5ca4394c499b43e7b75645c7ce)
**5) Inline View Component that Can Dynamically Deliver Data to External Webpages**
- XRCLOUD's inline component allows developers to dynamically deliver desired information.
- This allows for showing different webpages per user, or dynamically setting up transitions to other spaces from a Room, or creating branches.
- By including desired information in the LinkPayload when calling the GetRoom API and delivering it to the webpage called by the inline view, it can be used to display different information or route pages based on the information received by that webpage.
- For development methods and detailed examples, refer to the document below.
- [Development and Utilization Methods for Inline View Components that Can Dynamically Deliver Data to External Webpages](https://belivvr.notion.site/591573adf4f8482c8c135447fb011975)
**6) Empty Frame: A Dynamically Modifiable Object for Developers**
- XRCLOUD has developed a new object called "Empty Frame" that, when placed in the Spoke metaverse editor, can be dynamically changed via an external API. Currently, it is customized with Hubs' Reticulum API, not the XRCLOUD API, and has only been used internally by BELIVVR.
- In the future, we will convert it to the XRCLOUD API and release it.
