검색을 위해 크롤링된 멀티미디어 데이터에 OCR기술을 이용해 태깅하여, 검색에 적용하는 방법을 고민해본겁니다.

** 제안 당시 초안**

1.       **제목 **: 크롤링된 이미지들의 OCR을 이용한 태깅과 검색 방법
2.       **의의** : -      **구글에도 OCR****을 ****이용한 ****이미지 ****검색은 ****현재 ****존재하지 ****않음**
[http://scholar.google.co.kr/intl/ko/scholar/publishers.html](http://scholar.google.co.kr/intl/ko/scholar/publishers.html)에 의하면
PDF에만 한정되어있으며 이는 시스템에서 OCR을 수행하는 것이 아님
현재 본문검색의 경우 클롤링된 무작위 이미지가 아닌 포탈이 직접 이미지 소스를 구해 OCR을 하여 직접 의미 있는 검색 컬랙션을 만드는 작업을 하고 있음

3.       **현재** :
현재 크롤러는 웹사이트 들을 돌아다니며, 페이지와 그에 포함된 이미지 파일도 함께 수집하고 있다. 그 때, 해당 페이지들의 텍스트 정보를 인덱싱 하여 검색에 활용하고 있다.

이미지 검색을 수행시, 페이지내에서 유관된 텍스트 정보를 추출하여, 이미지에 태깅을 해두고 이를 인덱싱 하여 이미지 검색을 수행한다.
{{IMG:2}}

**5.       ****발명 ****내용**
크롤러가 웹사이트들을 돌아다니며, 가져온 이미지 파일들을 OCR 엔진을 통하여 이미지들을 태깅 하고, 이를 통하여 이미지 검색에 활용 하는 것을 제안한다.
{{IMG:3}}

-  이미지에서 텍스트를 OCR 하다 보면, 많은 무의미한 텍스트가 추출 될 수 있다. 이를 언어모델을 이용하여 필터링을 할 수도 있다.
-  이미지와 텍스트가 함께 있는 문서의 경우에는 기존 방식대로 텍스트의 정보를 함께 활용하여 상호 보완적으로 검색의 품질을 높이는데 사용 할 수 있다.
-  OCR태깅은 위의 예시에서 보인 단문이 아닌 이미지에서 추출된 텍스트 전체의 내용이 될 수도 있음
-  크롤러에 의해 수집되지 않고, 포탈내에서 사용자의 활동에 의해 올라온 이미지에도 동일하게 적용 할 수 있음 (네이버 블로그 이미지 OCR 태깅)

I considered a method to apply OCR technology to tag crawled multimedia data for search purposes.
 

** Draft at the time of proposal**
  
1.       **Title **: Tagging and Search Method Using OCR for Crawled Images
2.       **Significance** : -      **Image search using OCR does not currently exist even on Google**
According to [http://scholar.google.co.kr/intl/ko/scholar/publishers.html](http://scholar.google.co.kr/intl/ko/scholar/publishers.html)
it is limited to PDFs and is not performed by the system itself.
Currently, for body text search, portals are directly acquiring image sources, performing OCR, and creating meaningful search collections, rather than using randomly crawled images.

3.       **Current State** :
Currently, crawlers browse websites, collecting pages and the image files included therein. At that time, the text information of those pages is indexed and utilized for search.

When performing image search, relevant text information is extracted from the page, tagged to the image, and then indexed to perform image search.
 {{IMG:2}}

**5.       ****Invention Details**
We propose that crawlers browse websites, tag the retrieved image files through an OCR engine, and utilize this for image search.
    {{IMG:3}}
 
-  When performing OCR on text in images, many meaningless texts can be extracted. These can be filtered using a language model.
-  In the case of documents containing both images and text, the text information can be utilized together in the existing manner to complementarily improve search quality.
-  OCR tagging can be the entire content of the text extracted from an image, not just the short phrase shown in the example above.
-  It can also be applied to images uploaded by user activity within the portal, not just those collected by crawlers (Naver Blog image OCR tagging).
