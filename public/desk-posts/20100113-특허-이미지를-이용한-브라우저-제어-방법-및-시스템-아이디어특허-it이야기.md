간단하게는 마우스로 그림을 그린다던가, 글자를 쓴다던가 해서 웹객체에 어떠한 사용자 의미를 전달하는 기술적 방법입니다.

**1. 기존 방식**
1) 마우스나 키 이벤트(Text변경, Click, OnMouse, OutMouse등)를 일반적인 웹콤포넌트
(텍스트 박스, Flash, 텍스트 Area, img객체, Button객체)가 받는다.
- 사용자의 입장에서 보면 : 주로 버튼을 누르거나, 키를 입력하거나 하는 일반적인 행위이다.

2) - 그에 따른 자바스크립트가 동작하여 브라우져의 DomTree를 변경한다.
- 플래시가 독자적으로 DomTree를 변경한다.
(이 과정에서 플래시나 자바스크립트는 서버와 통신을 할 수도 있다)

3) Javascript나 각종 웹 인터페이스를 이용해 DomTree등을 변경하여 브라우져가 변경된 페이지를 보여준다.

**2. 이미지 기반 방식
**  1) 마우스 이벤트를 이미지커맨드 콤포넌트가 받는다.
- 이미지 커맨드 콤포넌트는 마우스를 통하여 그림을 그릴수 있는 형태이다.
- 이미지 커맨드 콤포넌트의 범위 : 플래시나 자바스크립트, 액티브X등 일반적인 웹콤포넌트
* 사용자의 입장에서 보면 : 마우스나 타블렛을 가지고 그림을 그리는 행위이다.

2) 이미지 커맨드 콤포넌트가 마우스의 이벤트에 의하여 조합된 정보(좌표, 입력 순서, 클릭과 Release여부)를 가지고 이미지 데이터 형태를 만든다.
- 이때, 입력 순서나 (타블렛의 경우)압력 여부등의 부가적인 정보도 포함될 수 있다.
(꽉누른것과 살짝 누른것의 행동을 다르게 인식할수도 있다)

3) 이미지 커맨드 콤포넌트는 이미지 데이터를 가지고, 사전에 정해놓은 어떤 행동을 브라우져에 줄것인지를 판단한다.
- 사전에 정해놓은 어떤 행동은 브라우져가 행동할수 있는 모든것이 될 수 있다.
- 판단은 이미지 커맨드 콤포넌트 자체가 아니라, 콤포넌트는 이미지 데이터만 전달하고,
판단은 서버에서 할수도 있다. (서버의 활용)

3.1) 이미지 커맨드의 예
예) 브라우징 : <- 의 형태의 이미지를 그려 넣으면 (뒤로가기)라고 판단한다.
if (cmd.type==BACK)    // 입력받은 명령이 뒤로가기 이면, 뒤로가기 실행
history.go(-1);

예) 쿼리입력 : 글자 형태의 이미지가 그려 넣어지면, 사전에 정의한 특정 콘트롤
(텍스트 에디터 등)에 인식한 글자의 데이터를 던져준다라고 판단한다.
if (cmd.type==TEXT)    // 입력받은 명령이 텍스트이면, 텍스트에디터에 입력받은 스트링을 셋팅
textComponent.SetText(cmd.string);

예) 색깔 바꾸기 : C 라고 이미지를 그려넣으면 테이블의 색깔을 바꾸기로 했다라고 판단한다.
if (cmd.type==CHANGE_TABLE_COLOR)   // 입력받은 명령이 테이블 색깔 변화면 색깔 변경
tableComponent.SetBgColor(BLACK);

예) 색깔 바꾸기 : blue 라고 이미지를 그려 넣으면
if (cmd.type==CHANGE_TABLE_COLOR)   // 입력받은 병령이 테이블 색깔 변화면 입력받은 색깔 변경
tableComponent.SetBgColor(cmd.color);

3.2) 특정 기능에 특화된 이미지 커맨드의 예
예) 브라우징 전용 이미지 콤포넌트
<- (뒤로가기)   -> (앞으로가기)   ↓ (스크롤 내리기)  ↑ (스크롤 올리기) 만 인식할수도 있다.
if (cmd==BACK)    // 입력받은 명령이 뒤로가기 이면, 뒤로가기 실행
history.go(-1);

예) 쿼리 입력 전용 이미지 콤포넌트
가   可  8   (검색창에 글자를 넣는다)
if (cmd)
textComponent.SetText(cmd.string);

예) 색깔 바꾸기 이미지 콤포넌트
if (cmd==CHANGE_IMG)   // 입력받은 명령이 테이블 색깔 변화면 색깔 변경
tableComponent.SetBgColor(BLACK);

예) 색깔 바꾸기 이미지 콤포넌트
Blue  Black  (페이지의 백그라운드 색깔이 바뀐다)
if (cmd)
tableComponent.SetBgColor(cmd.color);

4) Javascript나 각종 웹 인터페이스를 이용해 DomTree등을 변경하여
브라우져가 변경된 페이지를 보여준다.

**Title:** [**Method and System for Browser Control Using Images**](http://academic.naver.com/view.nhn?doc_id=14593125&applicationNumber=1020070065339)

{{IMG:1}}

Simply put, it is a technical method for conveying user intent to web objects by drawing pictures or writing text with a mouse.
 
**1. Existing Method**
 1) General web components (text boxes, Flash, text areas, img objects, button objects) receive mouse or keyboard events (e.g., Text change, Click, OnMouse, OutMouse).
  - From the user's perspective: This is typically a common action like pressing a button or typing keys.

  2) - Corresponding JavaScript operates to change the browser's DOM Tree.
    - Flash independently changes the DOM Tree.
   (During this process, Flash or JavaScript may communicate with the server.)

 3) The browser displays the changed page by modifying the DOM Tree, etc., using JavaScript or various web interfaces.
 
**2. Image-Based Method**
  1) The image command component receives mouse events.
  - The image command component is a form that allows drawing with a mouse.
  - Scope of the image command component: General web components such as Flash, JavaScript, ActiveX.
 * From the user's perspective: This is the act of drawing with a mouse or tablet.

 2) The image command component creates image data from information combined by mouse events (coordinates, input order, click and release status).
   - At this time, additional information such as input order or (in the case of a tablet) pressure status can also be included.
     (A firm press and a light press can be recognized as different actions.)
 
 3) The image command component uses the image data to determine what predefined action to give to the browser.
  - The predefined action can be anything the browser can do.
   - The determination is not made by the image command component itself; the component only transmits the image data, and the determination can be made by the server. (Utilization of the server)
 
    3.1) Examples of Image Commands
      Example) Browsing: If an image in the shape of "<-" is drawn, it is determined to be "Go Back".
         if (cmd.type==BACK)    // If the received command is "Go Back", execute "Go Back"
          history.go(-1);
 
      Example) Query Input: If an image in the shape of text is drawn, it is determined to pass the recognized text data to a predefined specific control (e.g., text editor).
         if (cmd.type==TEXT)    // If the received command is "TEXT", set the received string in the text editor
           textComponent.SetText(cmd.string);
 
      Example) Change Color: If "C" is drawn as an image, it is determined to change the table's color.
         if (cmd.type==CHANGE_TABLE_COLOR)   // If the received command is "Change Table Color", change the color
           tableComponent.SetBgColor(BLACK);
 
      Example) Change Color: If "blue" is drawn as an image,
         if (cmd.type==CHANGE_TABLE_COLOR)   // If the received command is "Change Table Color", change to the received color
           tableComponent.SetBgColor(cmd.color);
