XRCLOUD 는 (주) 빌리버에서 제공하고 있는 공간 컴퓨팅 시대의 3D 웹(메타버스)을 위한 클라우드 서비스입니다.  이용자는 홈페이지 개발 비용으로 메타버스 만들고, 사용한 만큼만 비용을 지불하여 기존 웹 서비스에서도 이용할 수 있는 클라우드 서비스입니다. 신뢰할 수 있는 네이버 클라우드에서 안정적으로 제공 되는 XRCLOUD 를 이용하시면 큰 개발 비용 없이도, 공간 컴퓨팅 시대의 웹 서비스 운영이 가능합니다.** 본 포스팅은 “Wix로 15분만에 메타버스 포트폴리오 만들기, XRCLOUD로 쉽게" 시리즈의 1편 XRCLOUD 이용하기으로서 포트폴리오 사이트를 만드실 수 있는 예시 가이드 시리즈의 첫 문서** 입니다. 아래를 순차적으로 따라오시면, 어느새 노코드 툴인 Wix를 통해 자신만의 3D 공간 웹(메타버스)를 만들어 보실 수 있습니다. **현재 Free-tier버전으로 프로젝트와 공간수가 제한되어있으며 메타버스의 공간에 동시접속자 수도 10명으로 제한 되어있습니다.**​

**1. 개발자 센터 가입하기**

먼저 [https://developers.xrclolud.app](https://developers.xrclolud.app/)에 접속해서 회원가입을 필요로 합니다.​

**2. 프로젝트 생성하기**

프로젝트 아래의 Create Project 를 눌러주세요.

{{IMG:2}}

1)  Product를 설정하게 되어있는데, 이건 Hubs를 선택하시면 됩니다. 모질라의 웹메타버스 오픈소스인 Hubs기반의 프로젝트 외에도 XRCLOUD는 XR환경에 필요한 다양한 기술을 XRCLOUD를 통해 선보이려는 계획이 있습니다.2)  프로젝트 이름을 기입하신뒤 파비콘과 로고 등록을 진행 한뒤, ADD 버튼을 눌러 프로젝트를 만들어주세요.  3)  로고는 공간에 진입하거나 할때 사용되는 로고이며 파비콘은 웹사이트에 사용되는 이미지입니다. XRCLOUD는 자신만의 웹서비스에 연동하는 서비스이다보니 만드실려고 하는 웹사이트의 로고와 파비콘을 등록해주시면 일관성 유지가 가능합니다.​** 현재 Free-tier버전에서 도메인 등록은 지원되지 않으나, 실제 B2B용 서비스에는 Proxy 서버를 이용한 3rdParty의 도메인을 지원합니다. **​

**3. 씬(공간 프로젝트) 생성, 공간 에디팅**

프로젝트를 생성했으니 이번에는 내 공간을 만들어야겠죠 ? 일반적인 3D게임 엔진과 동일하게 3D공간 프로젝트를 Scean으로 지칭합니다.

{{IMG:3}}

Scean은 Hubs의 Project개념이기도 하므로, XRCLOUD의 Project와 다소 헷갈리실 수도 있을것 같습니다. 그리고 Scean을 편집하는 도구는 역시 모질라재단에서 만든 Spoke라는 오픈소스 프로젝트 입니다. 물론 이 XRCLOUD에서 제공되는 Spoke는 빌리버에서 조금 확장기능 제공을 위해  커스터마이징을 가합니다. 원래 오픈소스와 함께 형상관리를 잘 해내가야 하는게 현재 빌리버의 가장 큰 숙제이자 고민이기도 합니다. 아무튼, 씬을 추가하면 공간 에디터(Spoke)가 뜹니다. 영어라 조금 불편하시겠지만, 올해내 Spoke의 언어팩도 저희가 PR하겠습니다. Hubs의 한글 언어팩도 빌리버가 기여 했습니다.

**4. 룸(공간) 만들기**

XRCLOUD is a cloud service for the 3D web (metaverse) in the era of spatial computing, provided by Believer Co., Ltd. It's a cloud service that allows users to create a metaverse at the cost of website development, pay only for what they use, and utilize it with existing web services. By using XRCLOUD, which is stably provided by the reliable Naver Cloud, you can operate web services in the era of spatial computing without significant development costs. **This post is the first document in the "Create a Metaverse Portfolio in 15 Minutes with Wix, Easily with XRCLOUD" series, specifically "Part 1: Using XRCLOUD," serving as an example guide series for creating a portfolio site.** If you follow the steps below sequentially, you will soon be able to create your own 3D spatial web (metaverse) using the no-code tool, Wix. **Currently, the Free-tier version has limitations on the number of projects and spaces, and the number of concurrent users in a metaverse space is limited to 10.**

**1. Sign up for the Developer Center**

First, you need to access [https://developers.xrclolud.app](https://developers.xrclolud.app/) and sign up.

**2. Create a Project**

Click "Create Project" under "Project."

{{IMG:2}}

1) You will need to set the Product; select Hubs for this. In addition to Hubs-based projects, which are Mozilla's web metaverse open source, XRCLOUD plans to introduce various technologies necessary for XR environments through XRCLOUD.
2) Enter the project name, then register a favicon and logo, and click the "ADD" button to create the project.
3) The logo is used when entering a space, and the favicon is an image used on the website. Since XRCLOUD is a service that integrates with your own web service, registering the logo and favicon of the website you intend to create will help maintain consistency. **Currently, domain registration is not supported in the Free-tier version, but actual B2B services support 3rd-party domains using a Proxy server.**

**3. Create a Scene (Spatial Project), Edit Space**

Now that you've created a project, it's time to create your space, right? Similar to general 3D game engines, a 3D spatial project is referred to as a Scene.

{{IMG:3}}

Since a Scene is also a Hubs Project concept, it might be a bit confusing with XRCLOUD's Project. The tool for editing Scenes is also an open-source project called Spoke, created by the Mozilla Foundation. Of course, the Spoke provided by XRCLOUD is customized by Believer to offer some extended features. Properly managing configuration with open source is currently Believer's biggest challenge and concern. Anyway, when you add a scene, the spatial editor (Spoke) appears. It might be a bit inconvenient in English, but we will release a language pack for Spoke within this year. Believer also contributed to the Korean language pack for Hubs.

After finishing scene editing, click "Publish Scene" in the upper right corner to save by entering the project name and scene name. **4. Create a Room (Space)**

While it would be nice if it ended with the scene, in fact, it doesn't end with the scene; you need to deploy a ROOM. If a scene is compiling and deploying a Spoke project, a room is closer to deploying a space that can be uploaded to a service for actual users to enter. You can create multiple Rooms within one Scene. It might be easier to think of a Scene as a project and a Room as a deployed space. Creating a room is very simple. Just select a scene and create a new room.

{{IMG:5}}

Then, the URL for the room you can access will appear. You can then access that URL.
