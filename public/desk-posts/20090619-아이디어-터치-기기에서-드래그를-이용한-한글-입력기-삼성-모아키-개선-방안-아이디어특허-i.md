**5.     ****배경**
**1)**** **    모음을 입력시, ㅏ ㅓ ㅗ ㅜ 를 제외하고는 2타 이상의 타수를 입력 받는다.
: ㅣ ㅡ ㅐ ㅙ 같은 모음 입력시 새로 뜨는 버튼 이미지를 조합해야 한다.
버스같은 이동중에는 촉각으로 키를 찾을 수 없는 환경하에 특정 키를 찾는 것은 대단히 어려운일이다. ㅏ ㅓ ㅗ ㅜ 의 경우에 이러한 문제를 거의 격지 않고 속도가 빠르다는 점에 착안하여 드래그입력을 다른 모음으로 확대하기 위한 개선방안이다.
**2)    **2.8인치 화면에 비해 키가 너무 많아 손가락으로만 조작하기는 어렵다.
**3)**  터치기기의 경우 키의 입력 회수보다는 이동중에 오인식을 줄이는 것이 더 중요하다. 키를 찾는 회수 자체를 감소 시켜야 한다.
**4)** 대안으로 필기 인식이 있을 수 있으나 이동중에 Class개수(한글의 경우 2350자)가 많은 필기 입력은 오입력률이 굉장히 높고, 스타일러스펜을 사용하여 양손을 다 써야 한다.

**6.     **개선 방법****
1)     한번의 드래그를 이용하여 ㅐ와 ㅙ 를 받을 수 있도록 하자.****
l  ㅣ : ↗↓
l  ㅡ : ↙→
**위의 경우는 기존 모아키와 달리 대각선 방향을 인지하여 ㅜ 와  ㅏ 대신 l와 ㅡ를 입력하도록 했다.**
l  ㅐ : →(ㅏ)←(추가 모음 커맨드)↗↓(ㅣ)
l  ㅙ : ↑(ㅗ)↓(추가 모음 커맨드)→(ㅏ) ←(추가 모음 커맨드)↗↓(ㅣ)
l  ㅑ : →(ㅏ) ←(추가 모음 커맨드) →(ㅏ)
-       **추가 모음 커맨드 획** : 최초의 드래그를 통한 모음 입력을 반대로 입력시, 추가 모음을 입력한다라는 의미가 되게 한다.

**2. First Written: July 24, 2008**
3. **Related Naver Service**: Embedded Machine Input Method Using a Touch Pen
4. **Existing Service**:
**Samsung's Moakey**

**5. Background**
**1)** When inputting vowels, except for ㅏ, ㅓ, ㅗ, ㅜ, two or more strokes are required.
: For vowels like ㅣ, ㅡ, ㅐ, ㅙ, new button images must be combined.
In environments where it's difficult to find keys by touch, such as while traveling on a bus, locating specific keys is extremely challenging. This improvement plan aims to extend drag input to other vowels, inspired by the fact that ㅏ, ㅓ, ㅗ, ㅜ rarely encounter such problems and allow for fast input.
**2)** The screen is 2.8 inches, but there are too many keys, making it difficult to operate with just fingers.
**3)** For touch devices, reducing misrecognition during movement is more important than the number of key presses. The number of times a key needs to be searched for must be reduced.
**4)** As an alternative, handwriting recognition could be considered, but handwriting input with a large number of classes (2350 characters for Hangeul) has a very high error rate when moving, and requires using both hands with a stylus pen.

**6. Improvement Method**
1) Let's enable input of ㅐ and ㅙ with a single drag.
l ㅣ : ↗↓
l ㅡ : ↙→
**Unlike the existing Moakey, the above cases recognize diagonal directions to input ㅣ and ㅡ instead of ㅜ and ㅏ.**
l ㅐ : →(ㅏ)←(additional vowel command)↗↓(ㅣ)
l ㅙ : ↑(ㅗ)↓(additional vowel command)→(ㅏ) ←(additional vowel command)↗↓(ㅣ)
l ㅑ : →(ㅏ) ←(additional vowel command) →(ㅏ)
- **Additional Vowel Command Stroke**: When the initial drag input for a vowel is entered in the opposite direction, it signifies the input of an additional vowel.
Ex) When inputting [왜]
: ㅇ ↑↓→←↗↓
(After finishing the drag, the moment the pen is lifted, it returns to the consonant input mode.)
ㅇ : Click ㅇ
오 : ㅇ↑
와 : ㅇ ↑↓→
왜 : ↑↓→←↗↓

2) Let's reduce the number of keys and eliminate unnecessary keys when they are not needed for input.
Ex) If you click ㅁ and don't lift the pen, it means it's ready to receive a vowel input, so there's no need to show other consonant keys.
