**1. Title: Web SMS Service Synchronization Using a Proposed App Name**
**2. First Draft Date: November 25, 2010**
**3. Background:** Naver Me gained the ability to send and receive SMS, but actual SMS records sent and received on a mobile phone cannot be managed or linked with Naver Me. However, smartphone apps can access the mobile phone's SMS list and PWEs like Naver Me simultaneously via 3G or Wi-Fi.
**4. Concept:** However, an SMS app developed for smartphones would enable the management of SMS send/receive lists on the web through synchronization with a web platform.
**5. Scenario:** A PWE vendor directly distributes an SMS app, such as 'handset sms'. Alternatively, if a standard API is created, the SMS app could operate independently. When the SMS app is downloaded and run for the first time, the user logs in by entering their PWE service ID and login. The app accesses the SMS send/receive list and transmits that data to the PWE server. If the smartphone sends or receives SMS later, it provides SMS popup functions, similar to 'handset sms', and notifies the PWE server again via the 3G network. Synchronization via the 3G network does not necessarily have to be real-time.
The send/receive SMS list received from the PWE is merged and managed with content used on the web. If a friend does not exist in the existing address book, the PWE can ask the user to add them to the address book or recommend that the friend also subscribe to the PWE.
