**나노바나나 이미지 생성 예시**

​Caret으로 콘텐츠 제작 과정이 얼마나 편리해지는지 실제 예시로 보여드립니다. 저는 저를 돕는 AI 에이전트 '알파'의 컨셉을 바탕으로 개인 프로젝트 홈페이지(cafelua.com)를 만들고 있습니다.​기존에는 컨셉 문서와 이미지를 참고해 다른 툴에서 이미지를 생성하고 다운로드하는 과정이 번거로웠지만, 이제 Caret 안에서 모든 것을 해결할 수 있습니다. ​**1. 프롬프트 입력**​프로젝트 내 컨셉 문서와 이미지를 참조하여 아래와 같이 프롬프트를 입력했습니다.​

> `@/data/cafelua/lounge/lounge-snow.png 를 기반으로 한국의 설 분위기로 실내가 꾸며져 있고, 카운터에서 @/data/alpha/illust/539900895_10163277490304817_7111357477122125959_n.jpg 의 알파가 한복을 입고 반갑게 맞이하는 이미지를 만들어줘. 알파의 디자인 프롬프트는 @/data/alpha/prompt/alpha_design_prompt_v2.md 를 참고하면 되고 라운지 컨셉은 @/data/cafelua/posting/design/cafelua_space_concept.md 를 참고하면되. 새롭게 만드는 이미지와 프롬프트 컨셉은 data폴더에 적당한 곳에 정리해줘 이미지 생성시에는 반드시 전달한 배경이미지와 알파 캐릭터 이미지를 전달한 이미지를 참조 이미지로 사용해줘`

입력한 참조 리소스는 카페 라운지 이미지와 알파 캐릭터 이미지입니다.

The first update of 2026, Caret v0.4.4, has been released! This update brings powerful features and important usage tips, including **image generation using Nanobanana Pro, new Naver Cloud support, and the adoption of the AAIF international standard `Agents.md`**.

{{IMG:5}}

**Key Feature Updates**

**1. Caret-Nanobanana Integrated Image Generation**

Caret can now generate image resources using Nanobanana Pro by interactively providing prompts and reference images. You can set the aspect ratio and resolution in the settings. This allows you to immediately obtain the desired output by utilizing your project's concept documents and images.

{{IMG:6}}

**2. New Naver Cloud Support**

Naver Cloud has been added as a new provider, allowing the use of HyperclovaX models (HCX-007, HCX-005, HCX-DASH-002). We plan to continue expanding support for domestic models in the future.

**3. AAIF Standard `Agents.md` Support and Project Initialization**

Caret/Cline has been changed to comply with the AAIF international standard `Agents.md` instead of its dedicated rules. Projects without an `Agents.md` file will automatically support initial context setup, and explicit setup is also possible with the `/init` command.

**4. Caret CLI Provision Delay Notice**

The Caret CLI (supporting Caret accounts, LiteLLM, etc., BYO), which was scheduled to be included in the first 2026 version, has been excluded from this release due to cross-platform support issues. The existing Cline CLI operates normally.

**Nanobanana Image Generation Example**

Here's a real example demonstrating how convenient content creation becomes with Caret. I am building a personal project website (cafelua.com) based on the concept of 'Alpha,' an AI agent that assists me. Previously, it was cumbersome to generate and download images from other tools, referring to concept documents and images, but now everything can be done within Caret.

**1. Prompt Input**

Referring to the concept documents and images within the project, I entered the following prompt:

> `@/data/cafelua/lounge/lounge-snow.png 를 기반으로 한국의 설 분위기로 실내가 꾸며져 있고, 카운터에서 @/data/alpha/illust/539900895_10163277490304817_7111357477122125959_n.jpg 의 알파가 한복을 입고 반갑게 맞이하는 이미지를 만들어줘. 알파의 디자인 프롬프트는 @/data/alpha/prompt/alpha_design_prompt_v2.md 를 참고하면 되고 라운지 컨셉은 @/data/cafelua/posting/design/cafelua_space_concept.md 를 참고하면되. 새롭게 만드는 이미지와 프롬프트 컨셉은 data폴더에 적당한 곳에 정리해줘 이미지 생성시에는 반드시 전달한 배경이미지와 알파 캐릭터 이미지를 전달한 이미지를 참조 이미지로 사용해줘`

The input reference resources are a cafe lounge image and an Alpha character image.

**2. Task Planning and Execution**

Upon receiving instructions, Caret first creates a task plan and asks the user for confirmation. This is to track and document all processes.

{{IMG:8}}

Once the plan is approved, Caret reads the reference resources, combines the necessary prompts for image generation, and sends them to Nanobanana. The generated image and prompt are saved in the `.agents/generated-assets` folder.
