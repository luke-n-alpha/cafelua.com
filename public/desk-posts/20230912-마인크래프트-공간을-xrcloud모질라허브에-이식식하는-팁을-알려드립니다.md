메타버스의 원조라고하면 누구나 떠올리는 게임이 있습니다. 바로 마인크래프트죠. 2009년 모장스튜디오에서 만든 샌드박스 형식의 인디게임으로 네모난 복셀형식의 3D디자인이 트랜드 마크인 게임입니다. 마인크래프트의 맵 크기는 총  4,096,000,000㎢로 무려 지구의 8배 크기를 자랑하는 어마어마한 크기입니다.

존재하지 않는 이미지입니다.

마인크래프트의 오픈월드 크기

그리고 그 세계에서 만들어진 건축물들은 정말 세계 불가사의의 건축물 처럼 크고 아름다운 것들이 많습니다.

이러한 마인크래프트는 구버전이 오픈소스로 공개되었고 맵 데이터 포맷도 공개되어있기 때문에 프로그래밍이 가능하다면 여러가지로 활용 가능합니다. 빌리버가 서비스하는 웹메타버스 PaaS 서비스는 맵의 디자인에 제한이 없는 모질라허브를 기반으로 하고 있습니다.  그렇다면 저희 서비스, 곧 모질라허브에서도 마인크래프트의 맵데이터를 사용해볼 수 있지 않을까?  하는 생각을 해봤죠.  그래서. 해봤습니다. 결론부터 말씀드리면 잘 됩니다. 먼저 만든 맵의 영상을 보여드리고 만드는 방법에 대해 설명 드리겠습니다.

- 개념을 먼저 설명 드리면 마인크래프트 데이터를 모질라허브 맵에디터인 Spoke로 불러오기 위해서는 3D파일의 표준 포맷인 gltf로 변환후 불러와서 맵을 만들어 배포합니다. 설명과 함께 필요한 파일 다운로드 경로는 알려드리겠지만, 혹시 찾기 어려우신 분은 아래의 구글 드라이브에 파일을 모두 공유해드리니 참고 바랍니다.

2. OBJ파일 전환, MineWays, JMCobj다운로드 및 설치

obj파일로 전환하기 위해 윈도우는 mineways를 mac이면 jmcobj를 설치합니다.윈도우용 : [https://www.realtimerendering.com/erich/minecraft/public/mineways/](https://www.realtimerendering.com/erich/minecraft/public/mineways/)MAC용 : [https://www.jmc2obj.net/](https://www.jmc2obj.net/)​저는 Mineway로 설명 드리겠습니다.메뉴에서 File > Open으로 위에서 압축푼 파일을 찾아보시면, level.dat 파일이 보입니다. 이게 마인크래프트 데이터 파일입니다. 이걸 열면 맵이 열립니다. 그리고 아래 그림  처럼 마우스오른쪽 키로 필요 영역을 드래그하여 선택합니다. 모질라 허브의 경우, 맵 데이터가 너무 크면 원할한 활동이 어려울 수 있으니 적당한 크기로 자릅니다. Height와 Depth로 해당 영역의 불러올 높이와 깊이를 설정 합니다. 쓸데 없이 깊어지면 용량이 커집니다.

그리고 Export for Rendering 메뉴를 선택하여 저장하면 아래와 같은 옵션이 나오는데 이때 아래의 설정을 체크 해주셔야 텍스쳐를 넣어주고 불필요한 블럭은 포함하지 않습니다.

{{IMG:2}}

그러면 obj파일이 저장됩니다. 하지만, 에디터인 Spoke에서는 obj를 부를 수 없으니 이번에는 obj파일을 gltf파일로 변환이 필요합니다.

1. Download Minecraft Data

Download a suitable map from [https://www.minecraftmaps.com/](https://www.minecraftmaps.com/). I downloaded the first map, 'a-modern-house 13', from the House Maps section under the Best Map menu. [https://www.minecraftmaps.com/house-maps/a-modern-house-13](https://www.minecraftmaps.com/house-maps/a-modern-house-13)

[**A Modern House #13** A Modern House with indoor decoration. www.minecraftmaps.com](https://www.minecraftmaps.com/house-maps/a-modern-house-13)

Download and unzip it.

2. OBJ File Conversion, MineWays, JMCobj Download and Installation

To convert to an OBJ file, install Mineways for Windows or JMC2OBJ for Mac.
For Windows: [https://www.realtimerendering.com/erich/minecraft/public/mineways/](https://www.realtimerendering.com/erich/minecraft/public/mineways/)
For Mac: [https://www.jmc2obj.net/](https://www.jmc2obj.net/)
I will explain using Mineways. In the menu, go to File > Open and browse to the unzipped file from above; you'll see a 'level.dat' file. This is the Minecraft data file. Opening it will open the map. Then, as shown in the image below, drag and select the desired area with the right mouse button. For Mozilla Hubs, if the map data is too large, smooth operation might be difficult, so cut it to an appropriate size. Set the import height and depth for the selected area using 'Height' and 'Depth'. Unnecessarily deep settings will increase file size.

{{IMG:1}}

Then, select the 'Export for Rendering' menu and save; options will appear as shown below. You must check the settings below to include textures and exclude unnecessary blocks.

{{IMG:2}}

This will save the OBJ file. However, since Spoke, the editor, cannot load OBJ files, you now need to convert the OBJ file to a glTF file.

3. Import OBJ file into Blender and Export as glTF

Blender can be downloaded from the URL below: [https://www.blender.org/](https://www.blender.org/)
When you run it, a single box will appear as shown below. Select and delete any unnecessary boxes...

{{IMG:3}}
                                
                            Blender Initial Screen

Insert the File > import > wavefront(obj) file into the Blender project.

{{IMG:4}}
                                
                            Importing OBJ file

When first loaded, it appears gray as shown below.

{{IMG:5}}
                                
                            Blender Import View of Minecraft Map Data

Changing the shader to Material Preview allows you to see it in color, but since it's not for editing purposes, simply select File > Export > glTF 2.0 and save the file.

{{IMG:6}}

4. Import glTF file into Spoke

Now, add a project in XRCLOUD (Mozilla Hubs) and click the '+' (Add) button in the Scene menu to open the Spoke editor. [https://xrcloud.app/ko/scenes](https://xrcloud.app/ko/scenes)

{{IMG:7}}

The initial screen looks like this; delete the default glb terrain.

{{IMG:8}}

In the Asset area at the bottom, add the glTF file you just created to My Assets, then select it again to add it to the project. Since I didn't set the depth separately, it was buried under the 3D file as shown in the image below.

{{IMG:9}}

Adjusting the height value makes it look decent now. However, a warning is visible. This is because the Minecraft map has more polygons than recommended by Mozilla. You can largely ignore this.

{{IMG:10}}

5. Editing the Map in Spoke

Afterward, I performed a few tasks.
- I selected an appropriate spawn point so the house is clearly visible.
- The door was blocked when climbing the stairs, so I used Link Asset and Waypoint Asset at that location to allow passing through the door with a click. This was the [method used when creating a 360-image gallery in a previous post](https://blog.naver.com/fstory97?Redirect=Log&logNo=223174026927&from=postView).
