** 1. 윈도우8은 태블릿과 PC의 컨버전스기기가 아니다.**** 1) 데스크탑모드는 데스크에서만**윈도우8은 태블릿과 PC의 컨버전스 기기는 아닙니다. 데스크탑 모드와 태블릿 모드의 메트로 UI는 완전히 분리된 UX와 분리된 환경을 제공합니다. PC모드와 데스크탑 모드의 경우에는 이름 처럼 데스크에 앉아서 키보드와 마우스를 꽂은채로 이용하게 됩니다.   **  2) 메트로 UI는 소파와 버스에서만** 출, 퇴근 시에는 키보드독을 가지고 다니지 않습니다. 비상시에 사용할 수 있는 플렉시블 키보드와 무선마우스 정도를 가지고 다니기는 하죠. 그나마 특수 상황이 아니면 잘 안씁니다. 그보다는 메트로 UI를 이용하여 뉴스를 보고, 동영상을 보고, 페이스북을 보는 용도로 사용하게 됩니다. 전형적인 아이패드의 이용시나리오 입니다.  ** 3) 윈도우8 태블릿은 Two in One 기기** 따라서 윈도우8의 포지션은 컨버전스가 아닌, 수륙양용차 같은 Two in One기기라고 봄이 맞을것 같습니다. 따라서 윈도우8의 향후 디자인이나 UX도 데스크탑을 죽이고, 메트로 UI로 가겠다는 전략보다는 Two in One의 두가지 모드가 동작하는 하나의 기기라는 컨셉이 더 나을듯 합니다.  **2. Two in One기기의 컨셉으로 가져갈 수 있는 매력**** 1) 가격** Two in One기기로서의 윈도우8의 매력은 바로 가격에 있습니다. 노트북은 업무 때문에 구매해야하고, 태블릿도 하나쯤 있으면 좋겠습니다. 이런 이들에게 매력적인 기기가 될 수 있습니다. 두개를 구매하면 엄청 부담스럽거든요. ** 2) 데이터 호환성** 작업하던 워드나 오피스 파일을 가장 있는 그대로 볼 수 있는 기기라는 장점이 있습니다 . 불편하긴 하지만 급할때는 소규모의 작업도 가능하죠. ** 3. Two in One기기를 극대화 할 수 있는 모델은 10인치 ATOM** W510을 사용하면서 느낀 점은 바로, 이 사용 패턴에 가장 최적화된 기기는 10인치 아톰CPU를 갖춘 모델이라는 점입니다. 저는 이미 TM2라는 i시리즈의 무거운 터치노트북을 가지고 있었습니다. 지금도 데스크에서는 해당 TM2로 작업을 하고는 있습니다. 클라우드로 데이터를 동기화 하고 있구요. 그러나, 현재 W510으로도 왠만큼 무거운 작업에는 큰 무리가 없는 수준입니다. 예전의 아톰을 생각하고 사용했다가 깜짝 놀랄 수준이었죠. 11인치 아티브는 직접들어 보고 너무 커서 패스 했습니다. 그 모델은 데스크탑 전용으로 밖에 쓸수 없더군요. 10인치를 선택한 잡스옹의 실력에 다시 한번 박수를.. ** 1) ATOM과 아이패드를 비교하면?** 가격면에서도 경쟁모델인 아이패드 대비 괜찮은 조건이었고, 배터리도 아이패드 대비 괜찮습니다. 키보드독 이용시 오히려 아이패드보다 긴 사용시간을 자랑합니다.**
**** 2) ATOM과 RT를 비교하면?** RT는 애석하게도 거의 태블릿 전용으로 보셔야 할겁니다. Two in One으로 쓰기에는 무리죠. 데스크톱 모드가 있으나, 태블릿용 앱도 별로 없는데, RT용 데스크탑용 앱은 오피스외에는 거의 전멸이라고 봐도 무방합니다. ** 3) ATOM과 i시리즈를 비교하면?** 배터리와 가격, 무게면에서 승리입니다. 오직 한가지 걸리는것은 다들 '퍼포먼스'라고들 얘기합니다. 그리고 데스크탑에서 '퍼포먼스'는 절대로 양보할 수 없는 가치였기 때문에, 사실 ATOM은 아예 비교대상에서 제외시키고들 많이 얘기하더군요. 그러나, 간과하지 않아야 할 점은, 제가 느꼈듯이 이제는 작업에 큰 무리가 없을 정도의 퍼포먼스로 올라왔으며, CPU는 1년에 2배이상 좋아진다는 점입니다. 듀얼코어 ATOM은 곧 쿼드코어 ATOM으로 거듭나겠죠. 2년후에 아톰은 어떻게 변할까요? 또한 i시리즈를 쓰는 많은 이유중 하나가 3D게임 때문입니다. 그러나, 게임 시장의 판도는 어느새 모바일로 옮겨갔습니다. 이미 많은 사용자들이 윈도우에서 게임을 하고 있지 않습니다. 따라서 i시리즈가 가지고 있는 매력은 지속적으로 낮아지고 있는 중이죠. **4. 넷북은 사라지지 않았다. ATOM 태블릿PC로 진화중** 얼마전에 뉴스를 보니 한시대를 풍미했던 넷북이 사라졌다는 기사가 올라왔더군요. 그러나, W510을 보며 느낀것은 넷북은 사라진것이 아니라, ATOM태블릿으로 진화를 하고 있습니다.

I purchased an Acer laptop called W510. This laptop is a popular hybrid model that can be used as a 10.1-inch Windows tablet when the monitor is detached, and as a regular laptop when using the keyboard dock. When only the monitor is detached, it's a 10.1-inch tablet weighing a light 560g, comparable to an iPad. I'd like to talk about the tablet potential of Windows 8 that I've felt while using this device.

**1. Windows 8 is not a convergence device for tablets and PCs.**
**1) Desktop Mode is for Desks Only**
Windows 8 is not a convergence device for tablets and PCs. The desktop mode and the tablet mode's Metro UI provide completely separate UX and environments. As the name suggests, PC mode and desktop mode are used while sitting at a desk with a keyboard and mouse connected.
**2) Metro UI is for Sofas and Buses Only**
I don't carry the keyboard dock when commuting. I might carry a flexible keyboard and a wireless mouse for emergencies, but I rarely use them unless it's a special situation. Instead, I use the Metro UI to read news, watch videos, and browse Facebook. This is a typical iPad usage scenario.
**3) Windows 8 Tablet is a Two-in-One Device**
Therefore, it seems more accurate to view Windows 8's position not as convergence, but as a Two-in-One device, like an amphibious vehicle. Thus, future design and UX for Windows 8 should adopt the concept of a single device with two operating modes (Two-in-One), rather than a strategy of eliminating the desktop and solely focusing on the Metro UI.
**2. Advantages of the Two-in-One Device Concept**
**1) Price**
The appeal of Windows 8 as a Two-in-One device lies in its price. You need to buy a laptop for work, and it would be nice to have a tablet too. This device can be attractive to such users. Buying two separate devices can be a huge burden.
**2) Data Compatibility**
It has the advantage of being able to view Word or Office files you were working on in their most original form. Although it can be inconvenient, small-scale tasks are possible in a pinch.
**3. The 10-inch ATOM model maximizes the Two-in-One device concept.**
What I realized while using the W510 is that the most optimized device for this usage pattern is a model equipped with a 10-inch Atom CPU. I already owned a heavy i-series touch laptop called TM2. I still use that TM2 for work at my desk, syncing data via the cloud. However, even with the current W510, moderately heavy tasks are not a big problem. I was surprised by its performance, having thought of the old Atom. I picked up an 11-inch Ativ and found it too big, so I passed on it. That model could only be used as a desktop. Once again, applause to Jobs for choosing 10 inches...
**1) Comparing ATOM and iPad?**
In terms of price, it was a good deal compared to the competing iPad, and the battery life is also good compared to the iPad. When using the keyboard dock, it boasts even longer usage time than the iPad.
**2) Comparing ATOM and RT?**
Unfortunately, RT should be considered almost exclusively for tablets. It's difficult to use as a Two-in-One. Although it has a desktop mode, there are few tablet apps, and desktop apps for RT are practically non-existent except for Office.
**3) Comparing ATOM and i-series?**
It wins in terms of battery, price, and weight. The only concern everyone talks about is 'performance.' And because 'performance' was an absolutely non-negotiable value on desktops, Atom was often excluded from comparison altogether.
However, what shouldn't be overlooked is that, as I've experienced, its performance has now reached a level where it can handle tasks without significant issues, and CPUs improve by more than double every year. Dual-core Atom will soon evolve into quad-core Atom. How will Atom change in two years?
Furthermore, one of the main reasons many people use i-series is for 3D games. However, the gaming market has already shifted to mobile. Many users are no longer playing games on Windows. Therefore, the appeal of the i-series is continuously decreasing.
**4. Netbooks haven't disappeared. They are evolving into ATOM Tablet PCs.**
I recently saw a news article stating that netbooks, which once dominated an era, have disappeared. However, what I felt while looking at the W510 is that netbooks haven't disappeared; they are evolving into ATOM tablets.

**5. Windows 8 still has challenges to overcome.**
However, as Windows 8 has just transitioned to a tablet, there are more than a few issues. Especially when assuming a Two-in-One approach, several areas need modification.
**1) Windows 8 Virtual Keyboard Needs Improvement**
In desktop mode, some applications occasionally become unresponsive to touch. These seem to be applications using Xwindow rather than the default Windows UI. Therefore, a shortcut is needed to bring up the virtual keyboard via touch in any situation. Furthermore, the virtual keyboard is not very convenient. A uniform keyboard for Windows, which has various screen sizes, often resulted in worse usability than Android's default keyboard. It seems necessary to allow opening the keyboard and creating various virtual keyboard apps, similar to Android.
**2) Windows 8 Charm Menu Opening and Improvement Needed**
When everything else becomes unresponsive, the only thing that works well and is intuitive is the Charm menu that appears on the right when you press the Windows button. I wish it were possible to register essential apps on this menu bar. What I want most is the Task Manager. There's no way to close unresponsive applications in desktop mode from the Metro UI. I've registered the Task Manager on the Metro UI home menu for forced process termination.
**3) Windows 8 Tablet Mode Multi-Window Improvement Needed**
It's not very pleasant for auxiliary apps like dictionaries or messengers to cover the entire 10-inch screen. While it's possible to place multi-windows small on the right or left, I'm not sure if message passing between these windows is possible. The advantage of Windows is multi-windowing, but this aspect seems weak in Windows 8.
**4) Windows 8 Start Menu Revival Needed. Complete Isolation of Metro UI and Desktop Apps.**
For Two-in-One users, desktop mode should be fully usable as desktop mode. Therefore, the desire for a Windows Start button remains. It's also incredibly annoying to constantly have to delete apps that aren't even Windows 8 apps from the home menu. I think these two need to be completely isolated.
**5) Still Lacking Apps**
Tablet apps are still very much lacking. The good thing, though, was that Junior Naver worked directly in IE for Saebom (my daughter).
**6. Windows 8: More Potential Than Drawbacks**
However, I believe Windows 8 has far more potential than drawbacks. First, the fact that it can handle both productivity and consumption tools was truly appealing to me. I currently have Android SDK and Photoshop installed and running on the W510 with an ATOM CPU. (For Photoshop, as long as the files aren't too heavy, some work is perfectly manageable.)
I recommend a Windows 8 tablet over an iPad.
