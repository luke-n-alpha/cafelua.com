기존의 버튼식과 달리 핸드폰을 기울이는것만으로 방향을 인식한다. Analog식이라 각방향으로 128단계의 미세 각도를 감지함으로서..미세한 조작이 가능함.
기울이는 각도에 따라 X축과 Y축의 조합도 가능합니다.
기존의 버튼 방향키 4개를 없애 핸드폰의 입력을 용이하게 하며 아주 간단한 손목 조작으로 직관적인 인터페이스를 구현하므로서 게임같은것에 조작감을 높입니다.

Scenario :
비행시뮬레이션, 자동차게임, 슈팅게임을 몰입도 있게 가능함

* 확장 : ----------------------
핸드폰을 들고 흔들면 해드폰에서 어느방향으로 얼마만한 속도로 이동했는지를 알아내는 시스템..
(핸드폰을 들고 마법진을 공중에 그리면.. 마법이 발동하는 게임을 만들수 있음)

Scenario :
A 와 B가 네트워크로 연결된 시스템에서..
A 와 B는 마법대전 게임을 하는중
A 공중에 오망성 별을 그려 파이어볼을 발사하면..
B가 공중에 삼각형을 그려 방어한다.

** 기술적 문제
핸드폰의 각도변화와 상대속도및 상대위치를 감지하는 시스템. 비행기에서 사용하는 자이로스코프같은건 좀 오버겠고 핸드폰 카메라를 이용한 거리와 변화정도를 측정하여 처리하는 시스템이라면 가능하지 않을른지..

## Title: [Mobile Analog Angle Pad](http://minihp.cyworld.com/pims/board/sketch/sktbrd_view.asp?item_seq=1997219614&tid=16159007&board_no=27&cpage=1&search_type=0&search_keyword=&allcnt=7&parent_reply_seq=&isLastPage=1&thisPageCnt=7)

IPC Code H04B 1/40 (2006.01) 
Application Number 1020040106713 (2004.12.16) 
Publication Number 1020060068120 (2006.06.21) 
 
{{IMG:1}}
 
 
 
Unlike traditional button-based methods, it recognizes direction simply by tilting the phone. Being analog, it can detect 128 levels of fine angles in each direction, allowing for precise control.
Combinations of X and Y axes are also possible depending on the tilt angle.
By eliminating the four existing directional buttons, it facilitates phone input and enhances the control feel in games by implementing an intuitive interface with very simple wrist movements.

Scenario :
Enables immersive flight simulations, car games, and shooting games.

* Expansion : ----------------------
A system that detects which direction and at what speed the phone has moved when held and shaken.. 
(If you hold the phone and draw a magic circle in the air.. you can create a game where magic is activated)

Scenario : 
In a system where A and B are connected via a network..
A and B are playing a magic battle game.
If A draws a pentagram star in the air and casts a fireball..
B draws a triangle in the air to defend.

** Technical Problem
A system that detects the phone's angle changes, relative speed, and relative position. A gyroscope like those used in airplanes might be overkill, but perhaps a system that measures distance and change using the phone's camera could be feasible..
