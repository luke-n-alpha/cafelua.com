**1. Title: Navigation Widget Using Web Page Snapshots**
**2. First Organized Date**: October 9, 2009
**3. Concept**
A method for developing a navigation widget that uses previews of target pages, similar to the 3D UI of Spb Mobile or Touch Flow.
{{IMG:1}}
** [Existing Spb Mobile 3D UI]**
 
**4. Implementation Example**
** 1) Registration Steps**
**- Skin Settings**
  **[3D Skin]**
{{IMG:2}} **[Panel Skin]**
  - Page Registration
   : Enter the URL of the target page for navigation
          Ex) Naver Blog : [http://blog.naver.com](http://blog.naver.com/)
              Naver News : [http://news.naver.com](http://news.naver.com/)
              Naver Webtoon : [http://comic.naver.com](http://comic.naver.com/)
 
   : Set the name of the navigation target web frame, either by passing it as a parameter to the widget or by configuring it during OpenAPI registration.
         Ex) Assuming the following source code is used,
<embed src='naviWidget.swf?target=myFrame'>
<iframe src='_blank' width=500 height=300 name=’myFrame’> </html>
 

 
** 2) User Data Generation**
- The widget stores rendered images of pages registered by the user on the server. These rendered images are updated when the page is refreshed or periodically re-collected.
Ex)
Naver Blog : [http://blog.naver.com](http://blog.naver.com/)

{{IMG:3}}
Naver News : [http://news.naver.com](http://news.naver.com/)
{{IMG:4}}
    Naver Webtoon : [http://comic.naver.com](http://comic.naver.com/)
  {{IMG:5}}
 
** 4) Rendering and Serving to User Widget**
 - A method of downloading rendered page images to a widget (like Flash) and utilizing the local PC environment.
 - A method of pre-compiling existing Flash binaries and generating them on the server side.
   {{IMG:6}}
- Change the URL of the pre-configured target frame to the page selected by the user in the widget.
