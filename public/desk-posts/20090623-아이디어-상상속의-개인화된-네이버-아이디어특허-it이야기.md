상상속의 개인화된 미래의 네이버 입니다.
이런 상상속의 네이버를 이용자에게 프로모션하고 해당 포스팅을 시상하는것도 좋을것 같다는 생각도 드네요.
최초작성일은 2007년 9월 18일이라 이전의 네이버 디자인을 기본으로 한것이라 3단 구조도 아니고, 로그인 위치도 왼쪽에 있습니다. 개인적으로 현재 네이버 디자인이 훨씬 깔끔한 것 같습니다.
일단 전 디자이너는 아니니까 상세 디자인은 패스..

{{IMG:1}}

**1.     첫화면에 개인화 페이지 도입**
-      블로그와 같이 **리모콘과 스킨을 도입**하여 **유저들이 편집하고 공유**할 수 있게 함

**2.     ****블로그/메일/해피빈등 산발적으로 흩어져 있는 개인 정보 창들을 첫화면에** 추가/삽입 가능하게 함

3.     일정공간은 기존의 수익보호를 위해 베너광고는 유지하고 리모콘에 필수 창으로 포함함 (블로그의 필수 위젯과 동일)

**4.     블로그와 같이 펼침 메뉴를 적극적으로 이용함**

**5.     웹 위젯 확대, 윈도우의 작업관리바 처럼 웹 위젯 바를 만들어, 추가/삭제가 가능하게 함**
(현재 데스크탑에서 제공하는 위젯외에도 개인 스토리지, 워드, 이미지편집기 등 다양한 것을 웹위젯으로 제공하고 확대하도록 함
-      차후 웹의 첫페이지는 윈도우 바탕화면과 웹위젯은 윈도우 어플리케이션에 비견할수 있을정도로 되야 한다고 생각함
-      웹의 오픈API를 보다 강력하게 만들어 플랫폼화 하고, 윈도우의 MFC로 어플리케이션을 만들수 있듯이. 오픈 API로만으로도 웹위젯을 제공 공유할수 있는 시스템이 되었으면 함
(브라우져가 단순히 웹을 넘어 OS개념으로 발전시킴)
-      위의 좌측 하단에 캐릭터의 경우 플레시 웹 위젯임

** 기본적으로 네이버의 기본 개념과 [http://www.google.com/ig](http://www.google.com/ig) 의 개인화 페이지를 합친 개념입니다만, 구글의 경우 디자인을 템플릿만 이용해 바꿀 수 있다는 점. 위젯들이 페이지 개념으로 나오고 있으며, 위의 아이디어에서는 아이콘과 같은 개념으로 사용자에게 접근한다는 것 입니다. (유저가 느끼기에 입장 차이에 불과할지도 모르지만)

This is a personalized Naver of the imagined future.
I also think it would be good to promote such an imagined Naver to users and award prizes for related posts.
Since the original creation date was September 18, 2007, it's based on the previous Naver design, so it's not a 3-column structure, and the login is on the left. Personally, I think the current Naver design is much cleaner.
Since I'm not a designer, I'll skip the detailed design...

{{IMG:1}}

**1. Introduction of a personalized page on the homepage**
- Like a blog, **introduce remote controls and skins** to allow **users to edit and share**.

**2. Allow scattered personal information windows like blog/mail/Happy Bean to be added/inserted on the homepage.**

3. For a certain space, banner ads are maintained to protect existing revenue and included as essential windows in the remote control (same as essential widgets in blogs).

**4. Actively utilize expandable menus, similar to blogs.**

**5. Expand web widgets, create a web widget bar like Windows' taskbar, allowing addition/deletion.**
(In addition to widgets currently provided on desktops, various items such as personal storage, word processors, and image editors should be provided and expanded as web widgets.
- I believe that in the future, the web's homepage should be comparable to a Windows desktop, and web widgets to Windows applications.
- Make the web's Open API more powerful to platformize it, and just as applications can be created with Windows' MFC, I hope a system is created where web widgets can be provided and shared solely with Open APIs.
(Evolving the browser beyond just the web into an OS concept)
- The character in the upper left corner is a Flash web widget.

** Basically, it's a concept combining Naver's fundamental idea with the personalized page of [http://www.google.com/ig](http://www.google.com/ig), but in Google's case, the design can only be changed using templates. Widgets appear as page concepts, whereas in the idea above, they approach the user with an icon-like concept. (Though for users, it might just feel like a difference in approach.)
