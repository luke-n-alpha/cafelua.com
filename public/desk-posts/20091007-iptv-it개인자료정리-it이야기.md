**1. 인터넷과 방송의 컨버젼스 IPTV**
****
** 가. IPTV의 가치**
- 인터넷 초고속 통신망을 이용하여 방송 컨탠츠를 제공하는 서비스로, VOD를 개념으로 시작하였으나 보다 다양한 양방향 서비스로 확장이 가능하며, PC에 비해 접근도가 높은 가전기기이자 정보단말기기로서 그 가치가 있다.
****
** 나. IPTV의 등장 배경**

| 구분 | 배경 | 기술 및 사례 |
| --- | --- | --- |
| 네트워크 | HD급 라이브 동영상 전송이 가능한 안정된100mbps급 초고속 통신망과 멀티캐스트 기술 | VDSL, FTTH, DOCSIS 3.0, QoS, CDN |
| 알고리즘 | 스트리밍이 가능한 멀티미디어 압축 알고리즘 | H.264, DIVX, AC3, MPEG2/4 |
| 컨버젼스 서비스 | ip기반의 컨버젼스 모델 | TPS, QPS |
| 컨탠츠 | 전문화, 다양한 채널에 관한 시장 욕구 | 케이블 방송, 교육, 뉴스 전문 방송 |
| 비즈니스 모델 | 양방향 개인화 부가 서비스 | VOD, 게임, 금융, 쇼핑 |

| IP-STB | TV단말기의 네트워크 인터페이스 | - CAS, DRM, 압축/복원 - 부가 기능 |

**1. Convergence of Internet and Broadcasting: IPTV**

**a. Value of IPTV**
- A service that provides broadcast content using high-speed internet communication networks, which started with the concept of VOD but can be expanded to more diverse interactive services, and holds value as a home appliance and information terminal with higher accessibility compared to PCs.

**b. Background of IPTV's Emergence**

| Category | Background | Technology & Examples |
| --- | --- | --- |
| Network | Stable 100mbps-class high-speed communication network capable of HD-quality live video transmission and multicast technology | VDSL, FTTH, DOCSIS 3.0, QoS, CDN |
| Algorithm | Multimedia compression algorithm capable of streaming | H.264, DIVX, AC3, MPEG2/4 |
| Convergence Service | IP-based convergence model | TPS, QPS |
| Content | Market demand for specialization and diverse channels | Cable broadcasting, education, news specialized broadcasting |
| Business Model | Interactive personalized value-added services | VOD, games, finance, shopping |

b. Key IPTV Technologies

| Technology | Description | Details |
| --- | --- | --- |
| Multicast | Method of transmitting data packets to multiple recipients at once | - Node: Uses IGMP to inform the router of its intention to receive multicast - Transmission: Packet transmission by indicating recipient group addresses in the header using D-class IP - Router: Requires a router that supports multicast; if not supported, transmission via tunneling |
| Compression/Decompression (Encoder/Decoder) | Minimizes loss of original meaning and transmission capacity | - MPEG2, MPEG4, H.264, DIVX - Trade-off between compression efficiency and image quality exists |
| Conditional Access System (CAS) | Controls user viewing rights | - Business model for digital pay TV - Content scrambling and encryption to prevent illegal viewing - Encrypted management of subscriber information and smart card information - Granting access rights per channel and per user - Monitoring to prevent illegal copying - Processing user reception logs |
| IP-STB | Network interface for TV terminals | - CAS, DRM, Compression/Decompression - Additional functions |

c. IPTV STB 4-Layer Model

| Layer | Description | Technology & Examples |
| --- | --- | --- |
| Application | Implementation of interactive and value-added services | Home Networking, VoD, VoIP, Game, PVR |
| Middleware | Broadcast application development environment like ACAP, MHP | Java VM, CAS/DRM Interface, Streaming(RTSP) |
| System Software | OS, Device Driver | OS, Device Driver |
| Hardware | STB hardware components | CPU, DSP, SoC, Ram, Ethernet |
