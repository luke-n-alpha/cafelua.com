**I. 개방형 OS로 변화하는 모바일 플랫폼**
- H/W의 발달과 멀티미디어 Data 통신에 대한 사용자 니즈로 인하여 모바일 플랫폼은 단말사와 H/W에 의존적인 전통적인 RTOS에서 개방형 OS로 변화하고 있다.
** 가. 모바일 플랫폼의 개념**
-  모바일 S/W Application을 개발하고 구동시키는 환경
-  모바일 OS + Brwoser + Middle Ware의 영역을 포괄하는 개념
** 나. 모바일 플랫폼의 환경 변화**
{{IMG:1}}
- 4세대 이동통신의 고속 멀티미디어 통신 환경
- 데이터 정액제와 이동통신사의 프로모션을 통해 저렴해지는 데이터 요금
- 유비쿼터스 환경하에 Seemless Computing 니즈
- 특정 브라우져의 의존도가 낮은 Mobile Full browsing

**II. 개방형 OS와 기존 RTOS 의 비교**

| 구분 | 개방형 OS | RTOS |
| --- | --- | --- |
| H/W Spec | 고성능 CPU, 넉넉한 메모리 | 상대적으로 낮은 성능 |
| 개발환경 | 좋음 Emulator, IDE, Open SDK API 제공 | Trace 32 (H/w Emulater) 단말사에 제한적 개발환경 제공 |
| 기능 | 다양한 Application | 전통적인 통화 기능 중시 |
| 표준 | OS/플랫폼별 표준화된 API | H/W의존적 API |
| 개방성 | API, SDK, 소스 개방 | 개방성 낮음 |
| 제품 | 안드로이드, Windows Mobile, Limo, OS X, Symbian, RIM OS | RexOS, VxWorks, Nucleus |

**III. 개방형 OS로 대체하게 될 WIPI**
** 가. WIPI의 한계점**
- WIPI는 국내표준으로만 자리잡아 해외와의 범용성에서 떨어짐
- 각 단말사들의 비표준 WIPI사용 통제에 실패하여 플랫폼간 호환성도 낮음
- 개방형 OS는 이동통신사간 플랫폼 호환문제는 존재하지 않음
- 무역장벽으로 인식한 해외의 WIPI의무화 폐지 요구
- 카메라, 자이로센서등 모바일 기기의 다양한 요구 수용하지 못한 한계
- 이동통신사 의존적인 S/W 배포시스템으로 인하여 시장의 확장에 한계점을 드러냄
**나. WIPI 폐지로 변화될 CP 시장**
- 개방형 OS간 비호환성으로 인한 중복 개발 이슈 재등장
- 전세계로 넓어지는 컨탠츠 시장
- 대형 Vendor 회사들의 CP 참여로 경쟁 심화
- 개인및 소형 CP들에게도 열린 가능성

**IV. 향후 전망및 모바일 플랫폼 전략**
** 가. WIPI로부터의 교훈**
- 시장변화및 사용자 니즈에 맞는 기술전략 수립 필요
- 국가 경쟁력을 위한 지속적인 기술 통제및 투자 필요
- 국산 기술을 해외 진출 노력 및 적극적인 지원 필요
** 나. 4g 주도의 국내 S/W 산업의 역량 강화**
- wibro등 4g 국제 표준을 주도
- 무선 인터넷 사용을 확대하고, 무선 인터넷 소프트웨어 활용을 촉진 시키는 국가적 전략및 지원 필요
: 중소 CP 지원, S/W 등록 간소화및 규제 철폐, 무선인터넷요금제 보조, 정액제 장려, wibro확산
- 오픈 소스 형태로 운영되는 모바일 OS에 대한 기술력 확보 및 참여 장려

** **
**I. Mobile Platforms Evolving Towards Open OS** 
 - Due to the development of H/W and user needs for multimedia data communication, mobile platforms are evolving from traditional RTOS, which are dependent on device manufacturers and H/W, to open OS.
** A. Concept of Mobile Platform**
  - An environment for developing and running mobile S/W applications.
  - A concept encompassing the areas of Mobile OS + Browser + Middleware.
** B. Changes in Mobile Platform Environment**
{{IMG:1}}
  - High-speed multimedia communication environment of 4th generation mobile communication.
  - Data plans becoming more affordable through flat-rate data plans and promotions from mobile carriers.
  - Need for Seamless Computing in a ubiquitous environment.
  - Mobile Full browsing with low dependency on specific browsers.

**II. Comparison of Open OS and Traditional RTOS**

| Category | Open OS | RTOS |
| --- | --- | --- |
| H/W Spec | High-performance CPU, ample memory | Relatively lower performance |
| Development Environment | Good Emulator, IDE, Open SDK API provided | Trace 32 (H/W Emulator) Limited development environment provided by device manufacturers |
| Features | Various Applications | Emphasis on traditional call functions |
| Standard | Standardized API per OS/platform | H/W-dependent API |
| Openness | API, SDK, source open | Low openness |
| Products | Android, Windows Mobile, Limo, OS X, Symbian, RIM OS | RexOS, VxWorks, Nucleus |

**III. WIPI to be Replaced by Open OS**
** A. Limitations of WIPI**
 - WIPI was established only as a domestic standard, lacking universality abroad.
 - Failure to control non-standard WIPI usage by each device manufacturer resulted in low compatibility between platforms.
 - Open OS does not have platform compatibility issues between mobile carriers.
 - Overseas demand for the abolition of mandatory WIPI, perceived as a trade barrier.
 - Limitations in accommodating various demands of mobile devices such as cameras and gyro sensors.
 - Market expansion limited by a mobile carrier-dependent S/W distribution system.
**B. Changes in the CP Market Due to WIPI Abolition**
 - Re-emergence of duplicate development issues due to incompatibility between open OS.
 - Content market expanding globally.
 - Intensified competition due to participation of large vendor companies in CP.
 - Open possibilities for individuals and small CPs.
 
**IV. Future Outlook and Mobile Platform Strategy**
** A. Lessons from WIPI**
  - Need to establish technology strategies that align with market changes and user needs.
  - Continuous technology control and investment needed for national competitiveness.
  - Efforts to advance domestic technology overseas and active support needed.
** B. Strengthening the Competitiveness of the Domestic S/W Industry Led by 4G**
  - Lead 4G international standards such as WiBro.
  - National strategies and support needed to expand wireless internet usage and promote the utilization of wireless internet software.
   : Support for small and medium CPs, simplification of S/W registration and abolition of regulations, subsidies for wireless internet plans, encouragement of flat-rate plans, WiBro expansion.
  - Secure technological capabilities for mobile OS operated in open-source form and encourage participation.
