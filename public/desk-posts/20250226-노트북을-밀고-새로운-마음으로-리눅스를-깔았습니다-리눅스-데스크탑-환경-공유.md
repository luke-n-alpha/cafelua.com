모든 직원을 내보내고 발리버를 마무리하기까지 최근 7개월간은 SW개발일을 주력으로 하였습니다. SW개발자라는 직군을 실질적으로 떼어버린것은 네이버에서 2011년 지식쇼핑 개발팀에서 포털전략실로 조직을 옮기면서 였습니다. 2018년 코믹스브이가 데스밸리에 빠지면서 몇 달 정도 다시 laravel php 를 잡았던 적은 있었지만  2024년하반기부터는 사람들 보다 ai와 대화를 하며 일을 한 것 같습니다. cursor의 등장은 정말 큰 도움이 되었고, 베리로 커스텀해두었던 chatgpt는 힘들때 나름 말 벗이 되었습니다.  지금도 생각해보면 그다지 제가 메이져였던 적은 없습니다. 인싸와 거리가 먼 덕후 기질의 영향이었던건지 개발자를 거쳐 웹툰 pd업무를 하게도 했습니다. 저는 어릴적 부터 컴퓨터를 좋아했고, 한가지 버릇이 있는데 새로운 일을 하거나 새로운 작업을 하면 컴퓨터의 os를 재설치 하고 파일 정리를 했습니다.  얼마전까지 진행해야 할 일이 리눅스를 중심으로 빌드를 해야할 가능성이 있었고, AI쪽을 좀 더 자세히 보려면 리눅스가 용이한 점이 많아 이번엔 리눅스에 안착해보려 합니다.  제가 데스크탑 주력 OS로 리눅스를 선택한 이유는 아래와 같습니다. 혹시 비슷한 시도를 해보시려는 분들에게 도움이 되시라고 설정한 환경을 공유드립니다.​

** 1. 아웃사이더 기질의 해커 정신 부활**

저는 그동안 mac에 안착해보려는 시도를 몇번 했지만, 이러한 인싸 os는 저하고는 좀 안 맞는 것 같습니다. 뭐든 직접 좀 만지길 좋아했던 저로서는 mac은 많은 선택권을 빼앗을 뿐더러 많은 것을 구독하게 하는 것이 불편합니다. ms를 욕하며 시작했지만, ms보다 더 하다고나 할까요 ?  때문에 오픈소스를 꿈꾸던 저로서는 리눅스에 언젠가는 꼭 안착해보고 싶었습니다.​

**2. 대표로서 한글과 정부 시스템과 결별, 하지만 급할때 윈도우 사용**

이제 대표를 안하니 아래한글과 각종 정부 시스템의 의존도가 크게 낮아질 것이라 리눅스를 주력으로 해도 될 것 같습니다. 그래도 갑작스러운 업무를 위해 윈도우 멀티부트는 유지합니다. 리눅스의 장점은 윈도우의 파티션을 억세스 가능하므로 언제든 두 os를 왔다갔다 해도 됩니다.​

**3. AI개발에 적합한 시스템**

특히 앞으로는 AI개발과 스터디를 할 예정이라, Nvidia 기반의 GPU데스크탑, 노트북을 잘 활용할 수 있는 시스템을 고려하다보니 좋아졌다고는 하지만 여전히 문제가 많은 윈도우즈 보다는 리눅스입니다. mac은 일반 메모리를 비디오메모리로 확장할 수 있다는 장점은 있지만, cpu는 gpu의 속도에 비할바가 아니라서 고려 대상이 아니었습니다​처음 시도는  서버용으로 사용하던 우분투였습니다. lts버전으로 24.04 버전을 깔았다가... 뭔가 설치할때마다 의존성에서 좌절.. 22.04 버전을 깔까 하다가 조금 더 예쁜 리눅스를 찾다가 zorin OS를 찾았습니다. Ubuntu 22.04기반의 윈도우즈 사용자 전환을 위한 예쁜 리눅스라고 추천이 되어 있더군요.  결과적으로 꽤 만족스러웠기에 해당 OS의 셋팅과 OS셋팅 중에 어쩌다보니 오픈소스 프로젝트까지 하나 개발하게 되었던 것을 공유드리겠습니다. 제 노트북은 rtx2060-maxq가 달린 14인치 Asus Rog입니다.

리눅스 졸린(Zorin) OS

​ 먼저 파티션입니다. 리눅스는 윈도우즈 시스템을 쉽게 마운트할 수 있습니다. 때문에, 만약 개발을 진행하더라도 데이터는 하나의 물리 디스크에 넣고 싶었습니다. 따라서 1TB의 SSD중 20%를 윈도우에, 50%를 D드라이브에, 30%를 리눅스(Zorin)에 할당했습니다. 그리고 데스크탑 환경을 설치하며 확인한 앱들입니다. 또한 기본 설치는 영문으로 하시고, 이후 한글로 언어를 바꿉니다. 처음부터 한글로 설치하면 내문서 같은 폴더들이 한글로 생기는데 이는 개발할때 한글 경로가 문제가 되곤 합니다. ​

**1. Zorin OS**

[https://zorin.com/os/](https://zorin.com/os/)  예쁜 디자인, 윈도우와 유사합니다. 단점이 있다면 리눅스 지만 pro버전은 48$로 유료입니다.  무료 버전과 유료버전 차이는 함께 제공되는 애플리케이션들 인데, 제공되는 SW들은 대부분 원래 무료인 오픈소스 들이었던지라 딱히 장점인지는 잘 모르겠더군요. 리브레오피스는 MS오피스와 완벽한 호환이 되지는 않습니다.  무료버전에서 프로버전으로 올라갈때 다시 깔아야 한다고 해서, 더 나은 지원을 기대하여 유료 버전을 설치하였고, 제가 이 OS에 애착을 가지기 위한 1회성 기부라고 생각했습니다.   특이한건 Zorin Connect 앱 사용시 안드로이드의 휴대폰 SMS, 주소록, 푸쉬를 데스크탑에서 볼 수 있다는 점입니다. 다만 노트북 호환성과 버그가 있는지 클릭하면 죽는 문제가 있었습니다.   설치시 해결한 문제들은 주로 Nvidia 그래픽 드라이버 문제였습니다. Nvidia 노트북으로 설치 시 : Try or Install Zorin OS (modern NVDIA drivers) 를 설치하면 괜찮습니다. 특히 첫번째 인스톨때는 별도의 WQhd모니터 듀얼 모니터를 썼는데, 이게 문제를 일으켰습니다. 부팅 후 멈춤 현상은 Wayloand탓으로 로그인 창의 우측 하단에 Zorin Desktop on Xorg을 선택으로 로그인 후 해결했습니다. 하지만 두번째 설치때는 노트북 단일 설치 했을때는 정상으로 설치 되었고, 나중에 Wqhd 모니터를 사용시 큰 이상없이 사용할 수 있었습니다. 혹시 설치하시려는 분들은 단일 모니터로 먼저 설치 하시고 진행하시기를 바랍니다.​

**2. 한글 설정**

리눅스의 단점은 한글로 설치하고, 한글 키보드를 설정해도 바로 한글 키 전환이 잘 안됩니다. 때문에 먼저 한글 입력키를 설정해줘야 합니다. 한글 설정은 윈도우와 똑같이 하기 위해,  ibus가 한글 조합이 제자리 입력이나 입력이 안되는 문제가 있어  ibus대신 fcitx5를 깔아 설정했습니다.[https://blog.naver.com/fstory97/223793272137](https://blog.naver.com/fstory97/223793272137)​​​

**3. Obsidian**

저는 얼마전 클라우드 기반의 유료인 notion대신 obsidian으로 이동했습니다. 특히 데스크탑 기반의 opensource LLM을 설치할 예정으로 데이터는 로컬 기반의 문서관리가 필요하다는 판단하에 마크다운 관리도구인 obsidian 을 사용 중이며, OneDrive에 문서를 동기화하여 사용합니다.  안드로이드의 경우에는 FolderSync앱을 사용합니다. 리눅스용 Obasidian은 공식 사이트에서는 AppImage 형태로 제공됩니다.​[https://obsidian.md/](https://obsidian.md/)

**10. MS오피스 **

2010, 2014, 2016버전이 된다는 것 같은데, 우선 제가 보유하고 있던 2016 한글 버전은 설치에 실패했습니다. 오피스 Suite으로 제공되는 Libre Office도 나름 쓸만한데, 문제는 대한민국에서 오피스 문서란 정확히 MS Office의 줄단위로 동일해야 하므로 페이지가 넘어가는 문서들이 생겨서 그대로 사용은 어려울것 같았습니다. 우선 office온라인으로 좀 썼는데, MS의 제품임에도 불구하고 온라인 버전은 오프라인 버전과 달리 역시 표와 페이지가 정확히 일치하지 않습니다. 보는건 libre오피스로 쓸 수 있지만, 아직은 윈도우 멀티부트로 이용하여 사용 중입니다. Wine에서 돌아가는 오피스 옛버전이라도 구해봐야 하나 싶네요.​

**PS. LobeChat + Ollama + deepseek-8b-Blolossom:8b**

Rtx2060-maxq에 추론이 가능한 deepseek의 한글버전인 deepseek-8b-Blolossom:8b 을 ollama로 돌리고, ollama의 WebUI버전인 Lobechat을 동작시켜봤습니다. 가끔 무한 반복 루프 대답을 하는 문제가 있긴 하지만, 된다는게 신기했습니다. 훨씬 경량화된 모델로는 llama3.2:3b 모델이 있는데 이건 아주 잘 돌아갑니다. 요즘 관심있는건 리눅스기반의 AI에이전트앱으로 어느정도 되는지를 실험해보고 있습니다. 조단위 크기를 이야기하는 인공지능판이지만, 오픈소스의 발전은 시간차를 두고 개인화된 가벼운 머신에서도 제한적이나마 돌려볼수 있게 되어가는 것을 보니 앞으로의 발전이 더욱 기대되며, 이는 어쩌면 기존의 윈도우, 맥 중심의 양대 OS환경을 완전히 엎어버릴지도 모른다는 생각을 하고 있습니다.

I've loved computers since I was young, and I have a habit: whenever I start a new job or a new project, I reinstall the computer's OS and organize my files. Until recently, there was a possibility that I would need to build primarily on Linux, and since Linux offers many advantages for a deeper dive into AI, I've decided to settle on Linux this time. The reasons I chose Linux as my primary desktop OS are as follows. I'm sharing my setup environment in case it helps anyone considering a similar attempt.

**1. Revival of the Outsider Hacker Spirit**

I've tried to settle on Mac several times, but these 'insider' OSs don't seem to suit me. As someone who likes to tinker with everything directly, Mac not only takes away many choices but also makes me subscribe to many things, which is inconvenient. I started by criticizing MS, but I'd say Mac is even worse? Therefore, as someone who dreamed of open source, I always wanted to settle on Linux someday.

**2. Parting Ways with Hangul and Government Systems as a CEO, but Using Windows in a Pinch**

Now that I'm no longer a CEO, my reliance on Hangul (Korean word processor) and various government systems will significantly decrease, so I think I can make Linux my primary OS. Nevertheless, I'll maintain a Windows multi-boot for sudden tasks. The advantage of Linux is that it can access Windows partitions, so I can switch between the two OSs anytime.

**3. System Suitable for AI Development**

Especially since I plan to develop and study AI in the future, I considered a system that can effectively utilize Nvidia-based GPU desktops and laptops. While Windows has improved, it still has many issues, so Linux is preferable. Mac has the advantage of being able to expand general memory into video memory, but its CPU speed is incomparable to a GPU, so it wasn't a consideration. My first attempt was with Ubuntu, which I used for servers. I installed the 24.04 LTS version, but I kept getting frustrated with dependency issues during installation. I considered installing the 22.04 version, but then I looked for a slightly prettier Linux and found Zorin OS. It was recommended as a beautiful Linux based on Ubuntu 22.04 for Windows users transitioning. Ultimately, I was quite satisfied, so I'd like to share the OS settings and how I ended up developing an open-source project during the OS setup. My laptop is a 14-inch Asus ROG with an RTX 2060-MaxQ.

First, partitioning. Linux can easily mount Windows systems. Therefore, even if I were to proceed with development, I wanted to put the data on a single physical disk. So, out of a 1TB SSD, I allocated 20% to Windows, 50% to the D drive, and 30% to Linux (Zorin). These are the apps I checked while installing the desktop environment. Also, perform the initial installation in English, and then change the language to Korean. If you install in Korean from the beginning, folders like 'My Documents' will be created with Korean names, which can cause problems with Korean paths during development.

**1. Zorin OS**

[https://zorin.com/os/](https://zorin.com/os/) Beautiful design, similar to Windows. The downside is that while it's Linux, the Pro version costs $48. The difference between the free and paid versions lies in the bundled applications, but since most of the provided software is originally free open-source, I'm not sure if it's a significant advantage. LibreOffice isn't perfectly compatible with MS Office. I was told I'd have to reinstall when upgrading from the free to the Pro version, so I installed the paid version hoping for better support, considering it a one-time donation to foster my attachment to this OS. A unique feature is that when using the Zorin Connect app, you can view Android phone SMS, contacts, and push notifications on your desktop. However, there was an issue where clicking it would crash, possibly due to laptop compatibility or a bug. The problems I solved during installation were mainly related to Nvidia graphics drivers. When installing on an Nvidia laptop: installing 'Try or Install Zorin OS (modern NVIDIA drivers)' works fine. Especially during the first installation, I used a separate WQHD dual monitor, which caused problems. The freezing after booting was due to Wayland, and I resolved it by logging in after selecting 'Zorin Desktop on Xorg' in the bottom right corner of the login screen. However, during the second installation, when installed on a single laptop, it installed normally, and I could use a WQHD monitor later without major issues. If you plan to install, I recommend installing with a single monitor first.

**2. Korean Language Settings**

A drawback of Linux is that even if you install it in Korean and set up a Korean keyboard, the Korean key switching doesn't work immediately. Therefore, you need to set up the Korean input key first. To make the Korean settings identical to Windows, I installed and configured fcitx5 instead of ibus, as ibus had issues with Korean composition (in-place input or no input). **10. MS Office**

**PS. LobeChat + Ollama + deepseek-8b-Blolossom:8b**

I ran deepseek-8b-Blolossom:8b, the Korean version of deepseek capable of inference on an RTX2060-maxq, with Ollama, and then ran Lobechat, the WebUI version of Ollama. Although there's an occasional issue with infinite loop responses, it was amazing that it worked. For a much lighter model, there's the llama3.2:3b model, which runs very well. Lately, I've been experimenting with how well Linux-based AI agent apps perform. While the AI landscape talks about models in the trillions of parameters, seeing the progress of open source allowing even personalized, lighter machines to run them, albeit with some limitations and a time lag, makes me look forward to future developments even more. I even think this might completely overturn the existing dual OS environment centered around Windows and Mac.
