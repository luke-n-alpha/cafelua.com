카카오의 수익모델 중 하나는 바로 플러스 친구라는 광고 구독 모델입니다. 그 중에 저한테 리뷰 요청이 온 것이 OK캐시백의 포인트 친구의 리뷰요청이 왔는데요. 이 리뷰를 통해 카카오의 플러스친구에 대한 분석도 함께 이야기해볼까 합니다. (단순 리뷰는 절대 안할거라고 혼자 다짐하는..)
**1. 포인트 친구 애딩(카카오 플러스친구)추가 방법** - 일종의 사용자 유입경로가 됩니다. 특히, 3) 4)의 경우 모바일 SNS에서 생긴 새로운 방법이므로 카카오에는 매우 중요한 요소입니다. 각 방법을 잘 활용하는 것이 광고주가 효과를 극대화 시킬 수 있는 방법입니다.**
**** 1) 사용자 : 카카오톡의 메뉴를 통한 접근법** 친구추천 > 플러스 친구 전체 보기를 통한 찾기 - depth 가 너무 깊어서 사실상, 이 방법으로 플러스친구를 추가하는 유저가 있을지 의문 스러운 방법입니다만, 인기 플러스친구들을 리스팅해서 보거나 검색을 통해 찾아볼 수 있습니다.  인쇄물같은 오프라인 미디어에서 사용자들에게 플러스 친구를 추가하는 방법에 대한 소개를 쓸때 의미가 있을것 같습니다. 검색창에 애딩 이라고 검색하시면, 추가가 가능하십니다.
{{IMG:1}}
** [검색 이미지]**** 진입경로 : 친구추천 > 플러스친구 전체보기 > 검색창**
** 2) 광고주: 웹을 통한 친구 추가 방법** OK캐시백 프로모션 페이지에서 카카오톡을 친구 추가하는 방법을 안내 합니다. [http://www.pointfriend.co.kr/](http://www.pointfriend.co.kr/) 이 페이지를 안내를 따라 진행하시면, SMS인증대신 카카오인증이라는 것이 있고, 이때 카카오의 플러스 친구를 추가할 수 있습니다.**{{IMG:2}}
****[ 웹에서 받은 카카오 인증번호 ]** 웹에 대한 영향력이 강한 대형 광고주라면, 웹의 영향력을 카카오로 전이하는 방법 중에 하나입니다.

** 3) 광고주 : 모바일웹을 통한 친구 추가 방법** 위의 PC웹과 비슷한 방법인데, 모바일 브라우져의 경우, 카카오톡 친구 추가 버튼을 동작시킬 수 있습니다. 아래의 URL을 모바일 브라우져로 보면, 카카오톡의 친구추가 API가 호출됩니다.  [http://m.kakao.com/s/473](http://m.kakao.com/s/473){{IMG:3}}
**[ 모바일 웹의 친구추가 버튼 ]**
** 4) 카카오톡 친구 : 바이럴 방법** 플러스 친구를 추가하고나면, 플러스친구의 대화창을 열면, 친구에게 추천 기능이 존재합니다. 이를 통해 바이럴을 할 수 도 있습니다. 친구추천을 통해 가입을 늘리면, 추가적인 혜택을 주는 방식으로의 바이럴 마켓팅이 가능한 수단입니다.{{IMG:4}}
**[ 친구 추천 누르면 다른 친구에게 추천 ]**
**2. 포인트 친구 애딩(카카오 플러스친구)는 뭐지?** 광고를 구독하고, 혜택을 받는 구조의 OK캐시백의 마켓팅 수단입니다. 광고를 구독하면, 소정의 캐시백에 대한 정보와 캐시백을 받아볼 수 있는 수단을 제공합니다. 애딩이 말하는것은 **광고를 보시면, 돈이 되요! **심플하게 말하자면 그겁니다.
{{IMG:5}}**[ 친구를 추가하니 200점이 적립되었습니다. ]****
** 혹은 연예인의 관심있는 내용을 받아보거나 신문과 같은 구독으로 보시면 되겠습니다.
**3. 오프라인 최대 광고플랫폼이 모바일 광고 플랫폼과 만나다.** 재밌는것은 카카오톡의 플러스친구는 광고 플랫폼이고, 광고주는 OK캐시백이지만, 사실은 OK캐시백도 광고 플랫폼이고, 캐시백을 적립해주는 가맹점 또한 OK캐시백의 광고주입니다. 오프라인의 가장 영향력있는 광고플랫폼인 OK캐시백이 모바일에 가장 영향력있는 카카오에 올라간 모습이죠. 둘이 만난 결과는 결과도 괜찮다고 합니다. 광고주 성공 사례 : [http://news.mk.co.kr/newsRead.php?year=2012&no=585129](http://news.mk.co.kr/newsRead.php?year=2012&no=585129) 카카오가 그만큼 영향력있는 모바일 광고 플랫폼이 된 반증이라고 봅니다. 역시 광고는 도달율이 장땡..

**4. 포인트 친구 애딩의 캐시백은 친구추가만 하면 적립되?** **주의하실 점이 포인트 친구 애딩은 친구 추가만 한다고, OK캐시백이 적립되지 않습니다.** 이를 위해서는 **사이트에서 인증 절차**를 거쳐야 합니다. 이는 플러스 친구를 맺은 사용자가 어떤 카드(OK캐시백의 어떤DB)와 매칭 되있는지 모르기 때문에, 사용자가 직접 등록해줘야 합니다. **5. 카카오 플러스채널의 한계** 위에서 불편한 웹에서의 인증 절차가 필요한 이유는** 플러스채널은 사용자가 광고주에게 정보를 보낼 수단이 없기 때문입니다.****
**{{IMG:6}}
**[ 입력창 없는 카카오 플러스 채널(포인트 친구 애딩) ]****
** 사용자의 입력정보가 광고주에게 전달될 수 없기 때문에 사용자는 카카오톡에서 직접 애딩에게 카드 등록이 되지 않습니다. 이점은 경쟁의 대상이 되기도 하는 라인의 공식계정과 큰 차이점을 보입니다. {{IMG:7}}
**[ 입력창이 있는 라인의 공식계정(운세친구) ]**
**
** 라인의 경우에는 공식계정은 봇역할을 하게 해서 ARS처럼 광고주와 사용자간의 양방향 정보의 교환이 가능합니다. 현재 카카오 플러스 채널은 광고주에서 사용자로 단방향으로 밀어주는 정보다 보니, 그 정보가 더욱 더 광고 처럼 보여지는 경향도 강해 보입니다. 분명, 라인과 카카오는 서로 벤치 마킹 대상이기도 할테니, 카카오에도 이러한 수단에 대한 고민도 있지 않을까 싶습니다.
**6. 카카오의 커머스 시장으로의 진출** 국내 모바일 시장에서 카카오가 가지는 위치는 절대적입니다. 그런 와중에 카카오는 스타일을 내놓았습니다. 사실상 지식쇼핑과 같은 이커머스(전자상거래)의 진출이라고 봐도 무방할 것 같습니다.

**OK캐시백도 모바일로 영향력 강화를 위해 애딩을 내놓았지만**, 향후에는 카카오도 네이버 마일리지와 같은 포인트 시스템을 내놓을 가능성도 농후하다고 봅니다.**갤럭시s2부터 장착된 NFC도 모바일 커머스에 대한 가능성을 크게 높여주고 있죠. 카카오는 과연 모바일의 네이버가 될 수 있을까요? 사실 저도 그 가능성을 낮게 보고 있지 않습니다. (제 밥줄 위험한 소리...)

One of Kakao's revenue models is the Plus Friend advertising subscription model. Among them, I received a review request for OK Cashbag's Point Friend. Through this review, I'd like to discuss an analysis of Kakao's Plus Friend. (I secretly vowed to myself that I would never do a simple review.)
**1. How to Add Point Friend Aeding (Kakao Plus Friend)** - This is a type of user acquisition channel. In particular, methods 3) and 4) are new methods that emerged from mobile SNS, making them very important elements for Kakao. Effectively utilizing each method is how advertisers can maximize their results.
**** 1) User: Access method via KakaoTalk menu** Friend Recommendations > Find via "View All Plus Friends" - The depth is too deep, so it's questionable whether any users would actually add Plus Friends this way. However, popular Plus Friends can be listed and viewed or found through search.  It would be meaningful when introducing how to add Plus Friends to users on offline media like print materials. If you search for "Aeding" in the search bar, you can add it.
{{IMG:1}}
** [Search Image]**** Access Path: Friend Recommendations > View All Plus Friends > Search Bar**
** 2) Advertiser: How to Add Friends via Web** OK Cashbag promotion page guides on how to add KakaoTalk friends. [http://www.pointfriend.co.kr/](http://www.pointfriend.co.kr/) If you follow the instructions on this page, instead of SMS verification, there's Kakao verification, and at this point, you can add Kakao's Plus Friend.**{{IMG:2}}
****[ Kakao verification code received from web ]** If you are a large advertiser with strong web influence, this is one way to transfer that web influence to Kakao.

** 3) Advertiser: How to Add Friends via Mobile Web** This method is similar to the PC web above, but for mobile browsers, you can activate the KakaoTalk friend add button. If you view the URL below on a mobile browser, the KakaoTalk friend add API will be called.  [http://m.kakao.com/s/473]{{IMG:3}}
**[ Friend Add Button on Mobile Web ]**
** 4) KakaoTalk Friends: Viral Method** After adding a Plus Friend, if you open the Plus Friend chat window, there's a "Recommend to Friend" feature. Through this, you can achieve virality. This is a means for viral marketing where increasing sign-ups through friend recommendations can provide additional benefits.{{IMG:4}}
**[ Clicking "Recommend to Friend" recommends to other friends ]**
**2. What is Point Friend Aeding (Kakao Plus Friend)?** It's a marketing tool for OK Cashbag, structured around subscribing to ads and receiving benefits. If you subscribe to ads, it provides information about a small amount of cashback and a means to receive that cashback. What Aeding means is: **If you watch ads, you earn money!** Simply put, that's it.
{{IMG:5}}**[ 200 points were credited after adding a friend. ]****
** Alternatively, you can view it as subscribing to content you're interested in, like celebrity news or a newspaper.
**3. The Largest Offline Advertising Platform Meets Mobile Advertising Platform.** What's interesting is that KakaoTalk's Plus Friend is an advertising platform, and the advertiser is OK Cashbag, but in fact, OK Cashbag is also an advertising platform, and the merchants that accumulate cashback are also OK Cashbag's advertisers. It's a scenario where OK Cashbag, the most influential offline advertising platform, has joined Kakao, the most influential mobile platform. The results of their collaboration are reportedly good. Advertiser Success Story: [http://news.mk.co.kr/newsRead.php?year=2012&no=585129](http://news.mk.co.kr/newsRead.php?year=2012&no=585129) I see this as proof that Kakao has become such an influential mobile advertising platform. Indeed, reach is everything in advertising.

**4. Is cashback from Point Friend Aeding credited just by adding a friend?** **Please note that OK Cashbag is not credited just by adding Point Friend Aeding.** For this, you need to go through an **authentication process on the website**. This is because the Plus Friend user's information isn't matched with any specific card (OK Cashbag's database), so the user must register it directly.
**5. Limitations of Kakao Plus Channel** The reason for the inconvenient web authentication process mentioned above is that **the Plus Channel lacks a means for users to send information to the advertiser.******
**{{IMG:6}}
**[ Kakao Plus Channel (Point Friend Aeding) without input window ]****
** Since user input information cannot be transmitted to the advertiser, users cannot directly register their card with Aeding within KakaoTalk. This point shows a significant difference from Line's official accounts, which are often competitors. {{IMG:7}}
**[ Line's Official Account (Fortune Friend) with input window ]**
**
** In Line's case, official accounts can act as bots, allowing for two-way information exchange between advertisers and users, similar to ARS. Currently, Kakao Plus Channel only pushes information unidirectionally from the advertiser to the user, which seems to strengthen the perception of that information as more purely advertising. Clearly, Line and Kakao benchmark each other, so I imagine Kakao is also considering such a feature. 
**6. Kakao's Entry into the Commerce Market** Kakao holds an absolute position in the domestic mobile market. Amidst this, Kakao launched "Style." In essence, it can be seen as an entry into e-commerce, similar to Naver's Knowledge Shopping.
{{IMG:8}}
**[ Kakao Style ]****
**While OK Cashbag launched Aeding to strengthen its mobile influence, **I believe there's a high possibility that Kakao will also launch a point system similar to Naver Mileage in the future.** NFC, which has been equipped in phones since the Galaxy S2, also greatly increases the potential for mobile commerce. Can Kakao truly become the Naver of mobile? Honestly, I don't see that possibility as low. (This is dangerous talk for my livelihood...)
