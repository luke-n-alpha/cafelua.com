지금은 그렇게 hot한 키워드는 아니지만, 클라우드가 무엇인가? 라는 질문을 하시는 분이 있어서 다시 생각해보고 정리 해봤습니다.이 서비스는 클라우드다, 저 서비스는 클라우드다 라고 이야기를 많이 하지만 혼용되는 것 같아서 제 나름대로 재정리해봅니다.

| 사용자 | 구분 | 기존 | 클라우드 |
| --- | --- | --- | --- |
| 기업 (기관) | 네트워크 | 인트라넷 | 인터넷 |
| SW지불형태 | SI, 패키지구매 | 종량제 |  |
| HW | 전산실 | IDC (PaaS/LaaS) |  |
| 업데이트 | SI개발 프로젝트 ,패키지 업데이트 | 상시(서비스 제공업체) |  |
| 커스터마이징 | 개별 최적화 | 선택 최적화 (SaaS) |  |
| 개인 | 네트워크 | Local | 인터넷 |
| SW지불형태 | 패키지구매 | 종량제 |  |
| HW | 개인단말 | IDC (PaaS/LaaS) |  |
| 업데이트 | 패키지업데이트 | 상시(서비스 제공업체) |  |
| 커스터마이징 | 제공안함 | 선택 최적화 (SaaS) 하는 경우도 있음 |  |

저는 처음 클라우드라는 이야기를 들었 을때, 클라우드는 뻥이다.. 라고 까지 얘기했었는데, 도대체가 기술적으로 봤을때는 C/S(Client Server)시스템으로 보였기 때문에 이해를 하지 못했던것 같습니다. 최근에는 이러한 것이 클라우드다라고 많이 이야기하면서 조금 감이 잡히는 것 같은데, 클라우드를 이야기하면 반드시 들어가야 하는것은 "인터넷"과 "선택하고 쓴만큼 내는 종량제"의 두가지 키워드입니다. 기술에 한정하는 협의로 말할때는 "인터넷"에 올리는것을 클라우드고, 비즈니스를 포함한 광의로 이야기할때는 "쓴만큼 내는 종량제"를 포함해야 합니다. 이러한 기술이 등장한 배경은 다양한 고객의 니즈를 수용하는 SW기술들이 쌓이면서 개별 커스텀 수준이 아닌, 다양한 옵션들만 선택 하여 고객의 니즈에 맞출수 있는 수준에 도달한 기업들이 등장(패키지화)했고, 이들이 이를 인터넷에 서비스를 만들어 올렸습니다.(기술의 협의의 클라우드) 그러면서 인터넷이 가진 기본적인 속성 곧, 개별 사용자의 추적이 가능하면서 이를 이용한 과금 모델이 개발되어 현재의 광의의 클라우드라는 용어가 탄생한게 아닌가 합니다. **"인터넷이라는 마켓에 SW를 내놓아 , 사용자의 액션별로 과금할  수 있게한것"** 그게 지금의 클라우드. 이렇게 정리하면 될 것 같 습니다.

While it's not as hot a keyword now, I've re-thought and organized what 'cloud' is, as some people still ask this question. Many services are called 'cloud,' but the term seems to be used interchangeably, so I'm reorganizing it in my own way.

| User | Category | Traditional | Cloud |
| --- | --- | --- | --- |
| Enterprise (Organization) | Network | Intranet | Internet |
| SW Payment Model | SI, Package Purchase | Pay-per-use | |
| HW | Server Room | IDC (PaaS/IaaS) | |
| Updates | SI Development Project, Package Updates | Constant (Service Provider) | |
| Customization | Individual Optimization | Selective Optimization (SaaS) | |
| Individual | Network | Local | Internet |
| SW Payment Model | Package Purchase | Pay-per-use | |
| HW | Personal Device | IDC (PaaS/IaaS) | |
| Updates | Package Updates | Constant (Service Provider) | |
| Customization | Not Provided | Sometimes Selective Optimization (SaaS) is offered |

When I first heard about 'cloud,' I even said it was a bluff... I couldn't understand it because, from a technical perspective, it just looked like a C/S (Client-Server) system. Recently, as more people talk about what constitutes cloud, I'm starting to grasp it. When discussing cloud, two keywords must always be included: "Internet" and "pay-per-use, where you pay for what you select and use." In a narrow sense, limited to technology, cloud refers to putting something on the "Internet." In a broader sense, including business, it must include "pay-per-use for what you use." The background for the emergence of this technology is that as SW technologies accumulated to accommodate diverse customer needs, companies emerged (packaging) that could meet customer needs by simply selecting various options, rather than requiring individual customization. These companies then built and uploaded these services to the Internet (cloud in the narrow technical sense). Subsequently, the Internet's fundamental characteristic – the ability to track individual users – allowed for the development of billing models based on this, which I believe led to the birth of the current broader term 'cloud.' **"Putting software on the Internet market and enabling billing based on user actions"** That's what cloud is now. I think this sums it up well.
