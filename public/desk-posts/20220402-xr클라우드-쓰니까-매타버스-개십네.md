**XR클라우드 가이드북 - WebXR 메타버스를 만들때는 XR클라우드** Description : 메타버스 인터넷 서비스를 만들고 싶을 때, 찾는 클라우드 서비스, 웹 개발자, 창작자, 기업, 기관 누구나 WebXR 메타버스는 XRCloud! developers.belivvr.com

https://developers.belivvr.com/xrcloud-intro/docs/intro/index.html

가격도 적어두었구요. 코인백서도 아닌데 뭔 가격부터 오픈하는가 라고 되묻는 분이 있을지도 모르겠는데**, 2022년 메타버스를 만들고자하면서 예산을 책정하기위해 머리를 쥐어뜯어야 하시는 어떤 분들을 위한 사전 배려라고 이해해주세요. (제안서는 이제 진짜 쓰지 말아야지..**)우선 XR Cloud가 뭔지 부터 아주 쉽게 설명 드리겠습니다. 저희가 공개한 글들은 SW엔지니어를 위해 쓴거라 의사결정자들이 듣기에는 어렵죠. 그래서 좀 쉽게 설명 드리겠습니다.제가 클래스브이로 VR가상교실 만들고나서 이래저래 고민이 좀 많았습니다. 설치도 어렵고, 배포도 어렵고, 버전은 맨날 충돌하고.. 포톤 라이브러리 업뎃하니 다 엎어야 하네? 더 좋은 솔루션 없을까? 그리고 이왕이면 웹에서 되면 좋겠는데? 그러다 발견했습니다.처음에는 WebXR을

네. 그걸 할 수 있게 해주는 서비스입니다. AWS에서 제공하는 허브 클라우드는 허브 웹사이트를 만들게 하지, 내 웹사이트에 뭔가를 붙힐수 있는 걸 제공하지 않습니다. 회원정보, 공간 관리 모두 주어진 사이트에서만 되고, 워드프레스처럼 멋진 플러그인 개발도 사실상 어렵습니다. (물론 워드프레스도 XXXX@!!|!!입니다.) 그걸 하시고 싶으시면 그냥 허브 프로젝트에 PR(Pull request)를 날려서 수정하셔야 합니다. 어쨌든 그걸 하라고 만든 프로젝트는 아니니까요.XR클라우드의 사용법은 간단합니다. (기존 웹 개발자에게는요. 개발자가 아니라면 함부로 어둠의 길에 몸담지 마시고, 허브만 경험하고 싶다면모질라 허브 그냥 쓰세요)아무튼 대표님이 갑자기 웹사이트에 메타버스를 빠르게 만들고 싶은데 돈은 없다하시면 사용하십쇼. XR클라우드. 사용법은 아주 간단합니다.​1. XR클라우드에 가입한다. (베타기간엔 무료다)2. 개발해야 하는 웹사이트를 등록한다. (2개이상 개발해야 하면 과금한다.)3. 사용할 공간을 고른다. (3개 이상 고르고 싶다면 과금한다.)4. 사용할 아바타도 고른다. (3개 이상 고르고 싶다면 과금한다.)

**​****5. (마지막으로 제일 중요한거!) API명세서 대로 개발한다. (끝)**​- 아바타 리스트 가져오기, 공간 리스트 가져오기, 공간 입장하기, 공간내 이미지 변경,영상 컴포넌트 변경, 무한롤백, 잠수함 배포, 몰래 퇴근하기, 재현안되요. 그건 버그아니고 피쳐에요. 등의 예상치 못한 API들을 학습해야 할 수도 있는데 그건 기분탓 입니다.

Hello. I'm Luke, the CEO of Belivvr, the oldest member, and the one in charge of being boring. Please call me metaverse walker as another nickname. As of March 31, 2022, we have released a guide document for a service called XR Cloud.

**XR Cloud Guidebook - XR Cloud for building WebXR Metaverses** Description: The cloud service you're looking for when you want to create a metaverse internet service. Web developers, creators, businesses, and organizations – anyone can build a WebXR Metaverse with XRCloud! developers.belivvr.com

https://developers.belivvr.com/xrcloud-intro/docs/intro/index.html

We've also listed the prices. Some might ask why we're opening with prices when this isn't even a coin whitepaper, but **please understand this as a pre-emptive consideration for those who have to rack their brains to budget for building a metaverse in 2022. (I really shouldn't write any more proposals...)** First, let me explain what XR Cloud is in a very simple way. The articles we've published are written for software engineers, so they can be difficult for decision-makers to understand. So, I'll explain it more simply. After creating a VR virtual classroom with ClassV, I had a lot of concerns. Installation was difficult, deployment was difficult, versions always clashed... Updating the Photon library meant overturning everything? Wasn't there a better solution? And ideally, it would work on the web? Then I discovered it. At first, WebXR...

And then the Mozilla Hubs project...

So, after a long time, I created an AWS account with this mindset...

I struggled with the installation for about a week. Open source says it *works*, but not that it *works well*... Who knew about region issues? (It seems to be fixed now.) I'm a bit of an old-school developer, so I had to learn AWS. Anyway, I got it running. But then, trying to fix it...

{{IMG:4}}

As expected, it wasn't that simple. As a backend developer, I had to re-learn A-frame, React, and even WebRTC servers??? Ugh... Anyway, I wanted to fix this and create something for people like me. So, we hired new developer gods, had them study, and created XR Cloud. XR Cloud allows you to create web services using Hubs. A web developer might think, "If I just let our service members choose avatars and attach spaces, the service is done, right?"

{{IMG:5}}
                                
That's right!!

Yes. It's a service that allows you to do just that. The Hubs Cloud provided by AWS lets you create a Hubs website, but it doesn't provide a way to attach something to *your* website. User information and space management are all confined to the given site, and developing cool plugins like WordPress is virtually difficult. (Of course, WordPress is also XXXX@!!|!!.) If you want to do that, you'll have to submit a PR (Pull request) to the Hubs project and modify it yourself. After all, that's not what the project was originally made for. Using XR Cloud is simple. (For existing web developers, that is. If you're not a developer, don't venture into the dark path recklessly; if you just want to experience Hubs, simply use Mozilla Hubs.) Anyway, if your CEO suddenly wants to quickly build a metaverse on your website but has no budget, use XR Cloud. The usage is very simple.
1.  Sign up for XR Cloud. (It's free during the beta period.)
2.  Register the website you need to develop. (If you need to develop more than 2, you'll be charged.)
3.  Choose the spaces to use. (If you want to choose more than 3, you'll be charged.)
4.  Choose the avatars to use. (If you want to choose more than 3, you'll be charged.)

{{IMG:6}}

**​****5. (Finally, the most important thing!) Develop according to the API specification. (End)**​- You might have to learn unexpected APIs such as Get Avatar List, Get Space List, Enter Space, Change Image in Space, Change Video Component, Infinite Rollback, Submarine Deployment, Sneak Out of Work, Cannot Reproduce (That's not a bug, it's a feature). But that's just your imagination.
