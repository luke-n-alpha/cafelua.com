XRCLOUD를 개발하면서 빌리버가 자체 개발한 기능들을 소개 시켜드리는 것 중에 한가지 말씀 안드렸던 것이 있었습니다.  바로 공유스크린 컴포넌트 입니다. 이는 공간내 미디어를 배치하는 미디어프레임의 위치를 고정하는 속성과 유사하면서 화면공유, 웹캠의 공유의 결합 형태라고 볼 수 있습니다. 한마디로 말하면 메인 스크린 같은개념으로 공간내에 1개만 배치하기를 권장합니다. 이왕 설명 드리는김에 미디어 프레임을 포함하여 한꺼번에 설명을 좀 드리겠습니다.​**1. 다양한 미디어 콘텐츠 공유를 돕는 컴포넌트****1) 미디어 프레임 : 전시에 쓰기 좋습니다.**- 허브(XRCLOUD)의 공간에는 이미지, 영상, 음악, pdf문서 등 다양한 미디어 파일을 드래그앤 드롭으로 공유가 가능합니다.
- 3d glb파일은 지원하지 않습니다. (BELIVVR에서 한번 수정할 수 있는지 보겠습니다.)

While developing XRCLOUD, there was one feature developed by BELIVVR that I hadn't introduced yet. That is the Shared Screen component. It is similar to the property of fixing the position of a media frame, which places media within a space, and can be seen as a combination of screen sharing and webcam sharing. In short, it's like a main screen concept, and we recommend placing only one in a space. Since I'm explaining it anyway, I'll explain it all at once, including the media frame.

**1. Components that help share various media content**
**1) Media Frame: Great for exhibitions.**
- In the Hub (XRCLOUD) space, various media files such as images, videos, music, and PDF documents can be shared via drag-and-drop.
- 3D GLB files are not supported. (BELIVVR will check if this can be modified.)
- When first shared, it appears in front of the avatar's eyes, and the Media Frame is the component that helps share it in an exact position.

{{IMG:1}}

- Using this, it's possible to display content in a ROOM by dragging and dropping it into a frame. Host users can fix its position.

{{IMG:2}}

**2) Shared Screen: Great for education and meetings.**
- Host users can share their screen and webcam, allowing them to conduct classes or broadcast events. Basically, these sharing methods utilize the media frame.
- **BELIVVR's self-developed Shared Screen component** provides a component that allows all users in the space to instantly share their screen and webcam on that screen when used. It can be placed and utilized in classrooms, meeting rooms, auditoriums, and event rooms.

{{IMG:3}}

                            BELIVVR’s spoke : Shared Screen component

- Currently, the shared screen does not offer dynamic aspect ratios and only supports a 1:1 ratio, so please adjust the width primarily based on PC standards. (We will review a PR to the hub after future modifications and completion..)
