** 1) Wireless AP**
이 인터넷 전화는 모뎀외에 안테나가 달린 기계를 하나 더 주는데 바로 그 기계의 정체는 무선인터넷공유기 곧 **wireless acess point**라고 불리며 그 통신규약은 국제 표준인 IEEE-802.11 시리즈를 씁니다. 현재는 주로 b,g,n규격을 사용하는데 이 규격에 따라 속도의 차이를 보여줍니다.  가장 흔히 쓰는 방식이 b/g이며 50mbps급의 속도를 보여줍니다. (mylgNet의 최대 속도가 50mpbs 인 이유입니다.) 최근엔 100mbps급의 n장비들이 나오고 있습니다.  그리고 이 통신방식은 통상적을 wifi 무선 lan이라고 불립니다. **이 기계가 주는 장점은 수십미터 이내에서 고속 무선인터넷 이용이 가능하다는 것입니다.** 투과성과 회절성도 보장이 되므로 가정용으로 적합한 무선 방식입니다. 또한 화두가 된 애플의 아이폰이나 노트북들은 일반적으로 이 기술을 이용하여 무선인터넷을 즐길 수 있게 합니다.

** 2. 인터넷 전화는 보안에 취약한가 ?**
기업에서는 비용과 보안 때문에 인터넷 전화를 이용합니다. **인터넷 전화가 보안에 취약하다는 이상한 기사가 예전에 뜬적이 있는데 그건 말도 안되는 이야기입니다.** Public 인터넷을 이용하는 사용자 패킷은 물론 위변조 도용이 분명 가능합니다. 이를 부인 하지는 않겠으나 기본적으로 여기서 사용되는 기법이란 기존의 전화에서 힌트를 얻은 기법입니다. 해킹은 과거 도청에서 시작됩니다. 세계적인 해커의 시작도 시외전화의 무료사용이었습니다. 더군다나 저도 통신병이었지만 일반전화는 아무런 암호화가 되어있지않고 단자함을 빼서 선만 꽂으면 이용이 가능합니다. 기존전화에도 보안장비가 달려있는 경우가 있습니다. 그러나 이는 인터넷에서는 모두 소프트웨어로 구현되어있습니다. 인터넷 전화가 보안에 취약하다면 보안에 신경을 많이 쓰는 미국정부나 기업이 사용할리는 없겠죠. 높은 수준의 보안을 원한다면 폐쇄된 전용선을 깔고 물리적 보안을 하면 됩니다. 이는 기존 전화뿐만 아니라 인터넷선도 마찬가지고 실제로 은행이 하고 있습니다.

** 2) 가입자 인증을 위한 패스워드 설정**

이러한 역할을 해줄 수 있는 곳이 어디일까요? 가깝게는 파워콤 같은 isp 업체, 금융기관, 인증기관정도 들 수 있겠죠. 하지만 **이러한 보안작업이 복잡하고 어렵다는 점에서 가장 손쉽게 할 수 있는 곳이 isp업체가 아닌가 싶습니다.** 최근 파워콤 설치를 해보면 알약을 깔아주는데, 이러한 서비스는 라이트 유저들의 보안 향상에 꽤 도움이 됩니다.
마찬가지로 무선설정시 인터넷기사분들이 은행원처럼 개인의 보안계정등록과 장비들을 등록하는데 도움을 주는 겁니다. 물론 이때도 은행에서 그러하듯 기사님도 고객의 패스워드는 노출되지 않도록 해야합니다.

-  ISP 업체(파워콤)의 홈페이지에 공인인증서등을 통해 로그인을 한다.
- 가지고 있는 무선 장비들을 등록한다. (Mac Address등의 식별값에 대한 유저들이 알기 어려운 정보는 기사가 도움을 준다.) 일종의 제품등록과 비슷한 개념
- AP는 외부의 유저로부터 접속 요청을 받는다. MAC Address를 확인 한 후, 1차적으로 인증된 기기인지를 ISP업체에 묻는다.
- 인증된 기기일 경우, ISP업체에서 무선장치는 ID와 패스워드를 묻는다.

- 최종 인증완료된 기기임을 확인한 AP는 사용자에게 무선 인터넷을 허용해준다.

**  * 위의 시나리오는 개인정보를 ISP업체 대신 제 3의 금융기관(CA)같은데서 행할 수도 있다. 가입자의 정보를 가진 Wifi를 가진 핸드폰같은경우, ISP업체가 아닌 통신사 서버를 통해 동일한 인증절차를 가질 수 있다.**

If I were to talk about home wireless APs with the potential for public Wi-Fi, those who only use computers for web surfing might wonder what I'm talking about. However, many of them are actually already using APs. **1) Wireless AP**
This internet phone provides an additional device with an antenna, besides the modem. That device is a wireless internet router, also known as a **wireless access point**, and its communication protocol uses the international standard IEEE-802.11 series. Currently, b, g, and n standards are mainly used, and they show differences in speed according to these standards. The most commonly used method is b/g, offering speeds of up to 50mbps. (This is why mylgNet's maximum speed is 50mbps.) Recently, n-standard devices capable of 100mbps are emerging. And this communication method is commonly called Wi-Fi wireless LAN. **The advantage this device offers is the ability to use high-speed wireless internet within tens of meters.** Since permeability and diffraction are also guaranteed, it is a suitable wireless method for home use. Furthermore, Apple's iPhones and laptops, which have become a hot topic, generally allow users to enjoy wireless internet using this technology.

**2. Are Internet Phones Vulnerable to Security Threats?**
Companies use internet phones for cost and security reasons. **There was a strange article in the past claiming internet phones are vulnerable to security, but that's nonsense.** Of course, user packets on the public internet can certainly be tampered with or stolen. While I won't deny this, the techniques used here are fundamentally derived from traditional telephony. Hacking began with wiretapping in the past. The start of world-renowned hackers also involved free use of long-distance calls. Moreover, even though I was a communications soldier, regular phones have no encryption, and you can use them just by pulling out the terminal box and plugging in a wire. Traditional phones sometimes have security equipment attached. However, on the internet, all of this is implemented in software. If internet phones were vulnerable to security, the US government or companies that prioritize security would not use them. If you want a high level of security, you can install a closed dedicated line and implement physical security. This applies not only to traditional phones but also to internet lines, and banks actually do this.

**1) Essential Security Settings for Wireless APs (Must-read for My LG 070 users!)**

**1) Subscriber Authentication for Devices**
**To enable mylg070 phones to be used without security settings, it only needs to know if the user is authorized.** Basically, the phone has a unique device address (MAC address), or it identifies the device with other information embedded in the phone. This is **matched with LG's subscriber information, making it a security-allowed target.** In other words, even for a secured wireless network, **if authenticated device information can be received and used from another server (e.g., an LG server or a national public institution), then differentiated security settings by role and accountability for security incidents can be established. Of course, the AP owner wouldn't need to know the personal information of those who access the AP.**

**2) Password Setting for Subscriber Authentication**
Nevertheless, there's a problem: device theft. This could be addressed by setting a password on the device, but it doesn't seem very secure. So, what I thought of, as mentioned before, is to ask for the password of the real-name information one more time when accessing the device registration system of an institution that holds real-name information.
Where could such a role be performed? Closely, ISP providers like Powercom, financial institutions, or certification authorities could be considered. However, **given that such security work is complex and difficult, I believe ISP providers are the easiest ones to implement it.** If you've had Powercom installed recently, they install 'AlYac' (a security software), and such services are quite helpful for improving the security of light users.
Similarly, when setting up wireless connections, internet technicians would help register individual security accounts and devices, much like bank tellers. Of course, in this case, just like at a bank, the technician must ensure that the customer's password is not exposed.

**Scenario**
- Log in to the ISP provider's (Powercom) website using a public certificate, etc.
- Register owned wireless devices. (For identification values like MAC Address, which users might find difficult to know, a technician provides assistance.) This is similar to product registration.
- The AP receives a connection request from an external user. After verifying the MAC Address, it first asks the ISP provider if it's an authenticated device.
- If it's an authenticated device, the wireless device asks for an ID and password from the ISP provider.
- After authentication is complete, the ISP provider informs the AP that the MAC is finally authenticated.
- The AP, having confirmed that the device is finally authenticated, allows the user to access wireless internet.

**\* The above scenario could also be performed by a third-party financial institution (CA) instead of the ISP provider for personal information. In the case of a Wi-Fi-enabled phone that holds subscriber information, the same authentication procedure could be carried out through the telecommunication company's server, not the ISP provider.**

**4. The Potential of Public Wi-Fi**
With the resolution of the iPhone's LBS issues, the need for Wi-Fi has grown, and many devices will begin to support Wi-Fi starting from this. Inevitably, as more users adopt Wi-Fi, it will be exposed to more security threats. Therefore, I hope for a world where, along with appropriate security policies, authenticated users can share their resources and access the internet anywhere. And, for now, the importance of security for internet phone providers, who are supplying the most APs to light users, is increasingly growing.
