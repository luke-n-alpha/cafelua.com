## 웹 상의 멀티미디어 컨텐츠에 포함되는 특정 언어를 다른 언어로 번역하여 제공하기 위한 방법, 시스템 및 컴퓨터 판독 가능한 기록 매체

METHOD, SYSTEM AND COMPUTER-READABLE RECORDING MEDIUM FOR PROVIDING WEB CONTENTS BY TRANSLATING ONE LANGUAGE INCLUDED THEREIN INTO THE OTHER LANGUAGEIPC 코드G06Q 50/00 (2006.01)출원번호1020080104470 (2008.10.23)공개번호1020100045336 (2010.05.03)등록번호101015234 (2011.02.09)네이버 전문정보 URL : [http://academic.naver.com/view.nhn?doc_id=37946961&applicationNumber=1020080104470](http://academic.naver.com/view.nhn?doc_id=37946961&applicationNumber=1020080104470)
잊혀질만하면 등록건이 날아와서 이게 도대체 무슨 발명 내용이었는지 가끔 매칭이 안되곤 하네요.이전에 이미 포스팅했던 특허에서 설명했던 내용입니다.

사실 발명은 하나였는데, 출원은 두개로 했었던 모양이네요. 2008년이라 가물가물.. 이전의 출원건은 번역시 프록시 서버를 이용해서 웹상의 멀티미디어를 대체해서 랜더해주는 방식의 웹 기술에 관한 것이었고, 이 출원건은 멀티미디어를 어떻게 번역할 수 있는가 하는 멀티미디어의 패턴인식과 멀티미디어의 재생성에 관한 내용입니다.
발명의 내용을 요약하자면, 패턴인식 기술을 이용해서 멀티미디어에 포함된 언어를 알아내고(영상신호에서 OCR을 통해 글자를 인식해 랭기지와 컨텍스트를 판별하고, 음성신호에서는 음성인식기술을 통해 랭기지와 컨텍스트를 판별하고) 이를 다시 유저가 원하는 다른 언어로 영상(폰트 오버랩)혹은 비디오(음성합성)를 하여 새로운 멀티미디어 파일을 만든다는 내용입니다.
더 더.. 간단히 요약하면, 자동 더빙.. 입니다.

## Method, System, and Computer-Readable Recording Medium for Providing Multimedia Content on the Web by Translating a Specific Language Included Therein into Another Language

METHOD, SYSTEM AND COMPUTER-READABLE RECORDING MEDIUM FOR PROVIDING WEB CONTENTS BY TRANSLATING ONE LANGUAGE INCLUDED THEREIN INTO THE OTHER LANGUAGE
IPC Code G06Q 50/00 (2006.01)
Application Number 1020080104470 (2008.10.23)
Publication Number 1020100045336 (2010.05.03)
Registration Number 101015234 (2011.02.09)
Naver Academic Information URL : [http://academic.naver.com/view.nhn?doc_id=37946961&applicationNumber=1020080104470](http://academic.naver.com/view.nhn?doc_id=37946961&applicationNumber=1020080104470)
Every now and then, a registration notice arrives, and sometimes I can't quite match it with what the invention was about. This is content that was explained in a patent I previously posted.

Actually, it seems there was only one invention, but two applications were filed. It was 2008, so my memory is hazy... The previous application was about web technology that renders web multimedia by replacing it using a proxy server during translation. This application is about multimedia pattern recognition and multimedia regeneration – specifically, how multimedia can be translated.

To summarize the invention, it involves using pattern recognition technology to identify the language included in multimedia (recognizing text from video signals via OCR to determine language and context, and determining language and context from audio signals via speech recognition technology), and then creating a new multimedia file by rendering it in another language desired by the user, either visually (font overlay) or audibly (speech synthesis).
Even more simply put, it's automatic dubbing.
