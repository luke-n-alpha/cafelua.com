****2.
취지 : **현재 대부분의 상용 OCR을 이용한 인식 결과는 언어 모델을 포함하고
있지 않으므로, 이미지를 텍스트 영역으로 판별 시, 이미지를 OCR로 인식 후에 매우 지저분한 인식 결과가 나오고 있다. 이는 OCR의 문서 구조 분석 단계가 완벽하지 않기 때문이다. 이를 문자
인식 결과와 언어모델을 가지고 텍스트 영역이 아닌 이미지나 혹은 노이즈 영역을 확인 할 방법을 제안한다.

****3.     ****구조**

1)
현재

[안넝하세요. 괄궭기] -> 언어모델

: 현재의 언어 모델은 OCR 결과를 보정해 주고 있는데, OCR이 인식한 후보 중 하나를 인식하도록 되어 있다. 이는 이미지
영역 중 일부가 텍스트 영역으로 삽입 되면 인식 언어모델을 통해도 가장 문법이나 확률적으로 가능성이 높은 출력을 하도록 되어있기 때문에, 말이 안되는 문자 배열이더라도 그대로 나오게 되어 있다.

l  언어모델은
확률기반 혹은 사전기반이 될 수도 있다.

2)
변경 후

: 언어모델은 문자열들간에 가장 확률이 높은 글자들을 취득하므로, 지나치게
확률 값이 높은 영역을 찾아낼 수 있다. 이 부분의 글자들을 언어모델에서 특정 임계 확률값이 넘으면
아예 잘못된 영역임을 OCR에 알려주거나, 언어모델에서 출력데이터에서
제거를 할 수 있다.

-
언어모델의 입력 값은 순수하게 텍스트 값으로만 존재하기 때문에, 어디서부터 제거 단위로 사용할 지 알 수 없다. OCR은 입력 글자의
위치 정보를 알고 있으므로, 어떠한 단위로 노이즈/이미지
영역과 글자영역를 분리하는 것이 좋은지 알 수 있다.

ex) 문서 구조 분석은 Zone 단위로 하는데, 보통 문자열의 문단 단위와 거의 비슷하다. 이러한 단위를 언어모델에
존재함 으로서, 해당 단위의 데이터가 노이즈/이미지 영역인지 OCR엔진에 알려 줄 수 있다.

-
언어모델로부터 받아온 이미지/노이즈 영역의 OCR의 처리

: 기본적으로 해당 OCR 영역은 텍스트로 인식하기에는 부적절한 이미지나
노이즈일 가능성이 많으므로, 인식 결과를 버린다. 그러나, 이미지내에 글자 인식이 가능하다면, 해당 영역을 이미지내에 글자
인식을 수행하는 특별한 OCR엔진을 통해 해당 인식결과를 개선할 수 있다.

**1. Title: Method for Discriminating Image/Noise Regions Using Language Model and OCR**

**2. Purpose:** Currently, most recognition results using commercial OCR do not include a language model. Therefore, when an image is determined to be a text region, the OCR recognition often yields very messy results. This is because the document structure analysis step of OCR is not perfect. This proposal suggests a method to identify image or noise regions, rather than text regions, using character recognition results and a language model.

**3. Structure**

1) Current

[안넝하세요. 괄궭기] -> Language Model -> [안녕하세요. 괄궤기]

: The current language model corrects OCR results by recognizing one of the candidates identified by OCR. If part of an image region is inserted into a text region, even with a recognition language model, it is designed to output the most grammatically or probabilistically likely result. Therefore, even an illogical character sequence will be output as is.

l The language model can be probability-based or dictionary-based.

2) After Change

Recognition Result: 안넝하세요. -> Language Model -> Final Recognition Result: 안녕하세요.

: Since the language model acquires the characters with the highest probability among character strings, it can identify regions with excessively high probability values. If the probability value for characters in this part exceeds a certain threshold in the language model, it can inform the OCR that it is an incorrect region, or the language model can remove it from the output data.

- Since the input value of the language model exists purely as text, it is not possible to know where to use it as a removal unit. OCR knows the position information of the input characters, so it can determine what unit is best for separating noise/image regions from character regions.

ex) Document structure analysis is done in Zone units, which are usually similar to paragraph units of character strings. By having such units in the language model, it can inform the OCR engine whether the data in that unit is a noise/image region.

- Processing of image/noise regions from the language model by OCR

: Basically, there is a high possibility that the OCR region is an image or noise unsuitable for text recognition, so the recognition result is discarded. However, if character recognition is possible within the image, the recognition result can be improved by performing character recognition in that region through a special OCR engine specialized in character recognition within images.

2) Determination of image regions through OCR recognition results and a language model.

3) When an image region is determined, recognition is performed using an OCR engine specialized for images.
