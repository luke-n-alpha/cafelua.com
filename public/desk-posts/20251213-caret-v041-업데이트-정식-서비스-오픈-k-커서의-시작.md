Caret 서비스 페이지 정식 오픈! VS Code에서 바로 만나는 한국형 AI 코딩 파트너, 무료 체험과 구독 플랜을 소개합니다.​안녕하세요. 캐럿티브의 루크입니다.드디어 캐럿(Caret) 서비스 페이지 오픈과 함께, v0.4.1 버전부터 정식으로 캐럿 계정 서비스를 이용할 수 있습니다. 이제 Caret에서는 별도의 유료 API 키 등록 없이도 손쉽게 '바이브 코딩'을 시작할 수 있습니다.

{{IMG:1}}

**-커서"**Caret을 한마디로 소개하자면 K-커서(K-Cursor)입니다.한국어로는 '캐럿'이라고 불러 주시면 되는데, '당근' 아닙니다. 캐럿은 키보드 숫자 6 위에 있는 특수 문자, 텍스트 커서(^)의 기호입니다.K-커서 캐럿은 한국어를 포함한 한중일 3국과 영문까지 4개 국어를 지원하여 누구나 쉽게 접근이 가능합니다.

{{IMG:2}}

별도의 애플리케이션을 설치할 필요 없이, 많은 개발자에게 익숙한 VS Code, Cursor, Antigravity의 플러그인 스토어에서 Caret을 설치하여 즉시 이용할 수 있습니다.

{{IMG:3}}

**네이버/카카오 소셜 로그인과 한국의 프로바이더 BizRouter 지원****K-Cursor**답게 네이버와 카카오의 소셜 로그인을 지원합니다.

{{IMG:4}}

또한 한국의 웍스AI에서 제공하는 기업용 LLM 라우터 [**BizRouter**](https://bizrouter.ai/)도 지원하며, 네이버나 업스테이지 같은 다양한 국내 LLM 프로바이더들을 지원할 예정입니다. 국내 AI 기업들과의 적극적인 협력을 통해 AI 산업 생태계를 확장하고, AI 기반의 바이브 코딩 경험을 혁신해 나가겠습니다.

{{IMG:5}}

{{IMG:6}}

**무료부터 시작하고 $10부터 시작하는 가벼운 유료 플랜**Caret은 가입 즉시 $2 상당의 20크레딧을 제공하며, 매월 10크레딧이 추가로 주어져 누구나 부담 없이 핵심 기능을 체험해볼 수 있습니다.유료 플랜도 월 $10부터 시작하여 Cursor나 Windsurf 대비 낮은 가격으로 부담 없이 이용 가능합니다.

{{IMG:7}}

{{IMG:8}}

**대화 시점으로 언제든 복구 가능한 '체크포인트' 기능 제공**AI와 함께 작업을 하다 보면, 언제부터 코드가 망가졌는지를 추적하기 어려운 경우가 발생합니다.Caret은 대화 중 특정 시점으로 프로젝트 상태를 되돌리고, 그 지점부터 다시 작업을 이어갈 수 있는 **체크포인트** 기능을 제공합니다.

{{IMG:9}}

- 해당 기능은 Git과 함께 사용하여야 활성화됩니다.
**지금 바로 경험해보세요**Caret은 이제 막 첫발을 내디 뎠습니다. 앞으로 한국 개발자들의 목소리에 귀 기울이며 더 많은 기능과 개선 사항을 빠르게 적용해 나가겠습니다.여러분의 소중한 피드백 하나하나가 캐럿을 더욱 발전시키는 원동력이 됩니다. 지금 바로 VS Code 마켓플레이스에서 caret 을 검색하고, 한국형 AI 코딩 파트너와의 새로운 협업을 경험해보세요!궁금한 점이나 제안하고 싶은 내용이 있다면 언제든 [GitHub 이슈](https://github.com/aicoding-caret/caret/issues)나 커뮤니티를 통해 편하게 말씀해 주세요.또한 기업(B2B)과 기관 도입, 커스텀 개발에 대한 문의도 언제나 열려 있으니 자유롭게 연락 부탁드립니다.여러분의 즐거운 코딩 라이프를 캐럿이 항상 응원하겠습니다.​감사합니다.​​​

Caret Service Page Officially Launched! Meet Your Korean AI Coding Partner Right in VS Code, Introducing Free Trial and Subscription Plans.
Hello, this is Luke from Caretive.
Finally, with the official launch of the Caret service page, you can now officially use the Caret account service starting from v0.4.1. With Caret, you can easily start 'Vibe Coding' without needing to register a separate paid API key.

{{IMG:1}}

**-Cursor"**
If I were to introduce Caret in one word, it would be K-Cursor.
In Korean, you can call it 'Caret' – it's not 'carrot'. Caret refers to the special character (^) above the number 6 on the keyboard, the text cursor symbol.
K-Cursor Caret supports four languages, including Korean, Chinese, Japanese, and English, making it easily accessible to everyone.

{{IMG:2}}

Without needing to install a separate application, you can immediately use Caret by installing it from the plugin stores of VS Code, Cursor, and Antigravity, which are familiar to many developers.

{{IMG:3}}

**Naver/Kakao Social Login and Support for Korean Provider BizRouter**
**True to its name as K-Cursor**, it supports social logins from Naver and Kakao.

{{IMG:4}}

It also supports [**BizRouter**](https://bizrouter.ai/), an enterprise LLM router provided by Korea's WorksAI, and plans to support various domestic LLM providers like Naver and Upstage. Through active collaboration with domestic AI companies, we will expand the AI industry ecosystem and innovate the AI-powered Vibe Coding experience.

{{IMG:5}}

{{IMG:6}}

**Light Paid Plans Starting from Free and from $10**
Caret provides 20 credits worth $2 immediately upon signup, with an additional 10 credits given each month, allowing anyone to experience core features without burden.
Paid plans also start from $10 per month, making it affordable compared to Cursor or Windsurf.

{{IMG:7}}

**Efficient Token Cost Management with the Latest Google Gemini Models, Real-time Price, and Context Window Monitoring**
The models available in Caret include the latest **Gemini 3 Pro**, **2.5 Pro**, and **2.5 Flash**.
For light and fast tasks, you can use Gemini 2.5 Flash, and for more complex tasks, you can use the Pro models.
Additionally, you can check token usage, cost, and context size per session and conversation in real-time, enabling efficient AI token cost management.

{{IMG:8}}

**'Checkpoint' Feature for Restoring to Any Point in the Conversation**
When working with AI, it can sometimes be difficult to trace when the code started to break.
Caret provides a **Checkpoint** feature that allows you to revert your project's state to a specific point in the conversation and resume work from there.

{{IMG:9}}

- This feature is activated when used with Git.
