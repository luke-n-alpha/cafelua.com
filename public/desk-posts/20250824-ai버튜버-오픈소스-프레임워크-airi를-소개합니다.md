Seeing Airi, which dreams of being an open-source framework like Neuro-sama, who is receiving tremendous attention, looked interesting, so I ran it.

{{IMG:1}}
                                
It's amazing.

It seems that sometimes API saving doesn't work well. There are cases where you need to reload the screen. By default, for 2D, you can use Momose Hiyori, the default Live2D character, and for 3D, ReLU is provided as a VRM file. It seems the developer is considering activities, given the Discord name is Airi & ReLu.

{{IMG:2}}

{{IMG:3}}
                                
This friend seems to be ReLu.

I didn't have much time, so I did a quick test, and currently, OpenAI TTS is slow... It's a queue-and-output method, so situations arise where the output comes later. STT was configured but didn't work. The console log is exploding, but I don't have time to debug, so I'll just pass.

Overall, the structure is in place, but it feels a bit clunky. With a clean UI, it seems promising as a framework, and I suspect they might be dreaming of a model where character cards are sold.
I thought a simple contribution would be Korean localization, so I made some changes and submitted a PR. However, they use Crowdin, so I put in a request to add Korean, and they created a Korean channel on Discord when I asked.
