저는 HTC 플라이어 태블릿과 갤럭시s2의 두대의 단말을 쓰고 있습니다. 이중 HTC 플라이어의 요금제는 월 12,000원으로 와이브로 10기가, 3g 1기가로 좀 넉넉한 편이지만, 갤럭시 s2의 요금제는 34요금제로 월 100mb의 데이터요금을 쓰고 있습니다. 두개 합쳐서 대강 55 요금제 수준의 요금을 내고 있습니다. 이렇게 한대에는 HTC요금이 워낙 싸기 때문에 이를 이용한 테더링을 이용하고 있기 때문인데요. 테더링으로 아끼는 방법들은 대강 다들 아실 테고, 34요금제의 100메가를 알차게 쓰는 방법을 이야기해볼까 합니다. 테더링의 단점은 매번 설정해줘야 한다는 단점이 있기 때문에 100메가의 데이터 요금도 잘 쓴다면, 테더링 없이도 필요한 대부분의 기능을 사용할 수 있습니다. 오늘 소개시켜드릴 기능은 갤럭시s2 ICS업그레이드 이후, 가장 맘에 드는 기능 중 하나입니다.**
****1. ICS이상에서 데이터 사용 옵션을 이용해보자. (****메뉴 > 데이터사용 )**설정을 들어가시면 아래와 같은 모습을 보실 수 있습니다.{{IMG:1}}여기서 데이터 사용을 선택해 주시구요.
{{IMG:2}} ICS이전에는 데이터 네트워크 사용의 옵션만 있었습니다.3g로 데이터를 쓸지 말지만 결정할 수 있었죠.그러나 ICS부터는 보다 새부 기능이 가능합니다.
**1) 사용 제한 설정, 사용주기 설정**우선 데이터 사용량 제한 설정과 사용주기를 설정 할수 있는데요.사용량에 대한 경고와, 일정 이상 넘어가면 아예 사용할 수 없게 만들어버립니다.제 경우에는 100MB까지만 쓰는 요금제 이므로, 75MB에 경고, 100MB에 제한을 걸어두었습니다.
**2) 어떤 놈이 많이 쓰는 놈인지 범인을 찾자.**{{IMG:3}}어떤 앱들이 가장 많은 데이터를 사용했는지를 볼 수 있죠.백그라운드에서 혼자 다운로드 받는 데이터까지 포함하므로, 어떤 놈이 데이터를 잡아먹는 범인인줄 알 수 있습니다.
{{IMG:5}}
확인을 눌러줍니다.이제 3g에서 페이스북이 보내는 push는 동작하지 않게 됩니다. 대신 그만큼 데이터는 세이브할 수 있죠.
**2. 빠른속도 ? 많은 용량 ? 그보다 더 좋은것은 스마트한 사용 습관** 저도 데이터를 많이 쓰는 편이지만, 이통사에서 주는 그러한 거대한 용량을 굳이 3g로 받아가며 비싼 요금을 낼 필요가 있나 싶습니다. 위의 방법을 잘 이용하면 3g 34요금제로도 잘 씁니다. 카톡만 쓰는 유저라면 100메가면 차고도 넘칩니다. (물론 이 경우, 보이스톡은 Wifi에서만 쓰세요.) 어차피 wifi구간도 널렸으니까요. 지금 쓰고 있는 와이브로 10기가는 테더링까지해서도 펑펑 씁니다. 다만, 음영구간이 제일루 짜증나는데요. 이동통신사에게 제일 필요한것은 속도와 용량보다는 품질이 필요한 시점이 아닌가 싶네요. 요금을 올리고 싶어하는 이동통신사는 좋아하지는 않겠지만요.

I use two devices: an HTC Flyer tablet and a Galaxy S2. Among these, the HTC Flyer's plan is quite generous at 12,000 won per month, offering 10GB of WiBro and 1GB of 3G, while the Galaxy S2's plan is a 34-plan, using 100MB of data per month. Combined, I'm paying roughly the equivalent of a 55-plan. This is because the HTC plan is so cheap that I use tethering with it. Most of you probably know how to save money with tethering, so I'd like to talk about how to make the most of the 100MB from the 34-plan. The downside of tethering is that you have to set it up every time, so if you use the 100MB data plan wisely, you can use most essential functions without tethering. The feature I'm introducing today is one of my favorites since the Galaxy S2's ICS upgrade.

**1. Let's use the data usage options on ICS or higher. (Menu > Data Usage)**
If you go into Settings, you'll see something like this:
{{IMG:1}}
From here, select Data Usage.
{{IMG:2}}
Before ICS, there was only the 'Data network usage' option. You could only decide whether or not to use 3G data. However, starting with ICS, more detailed features are available.

**1) Set data limit, set usage cycle**
First, you can set a data usage limit and a usage cycle. It provides a warning about usage and completely disables data if you exceed a certain limit. In my case, since my plan only allows up to 100MB, I set a warning at 75MB and a limit at 100MB.

**2) Find the culprit: which app uses the most data.**
{{IMG:3}}
You can see which apps have used the most data. This includes data downloaded in the background, so you can identify the culprit consuming your data.

**3) Restrict background data - Set limits per app**
Background data restriction refers to features that use data in the background even when the user is not actively using them. Most Android push notifications and widgets use this feature. In the case of Facebook, it's not something I necessarily need to receive in real-time, and I usually view it on Wi-Fi or when I choose to, so I will set a background data restriction for it.
{{IMG:4}}
If you select 'Restrict background data',
{{IMG:5}}
Press 'OK'. Now, Facebook push notifications will not work on 3G. Instead, you can save that much data.

**2. Fast speed? Large capacity? What's better is smart usage habits.**
I also use a lot of data, but I wonder if it's really necessary to pay expensive fees for the huge data allowances provided by carriers, especially when using 3G. If you use the methods above well, you can manage even with a 3G 34-plan. For users who only use KakaoTalk, 100MB is more than enough. (Of course, in this case, only use VoiceTalk on Wi-Fi.) After all, Wi-Fi zones are plentiful. I use the 10GB WiBro I currently have generously, even with tethering. However, dead zones are the most annoying. I think what mobile carriers need most is quality, rather than just speed and capacity, at this point. Mobile carriers who want to raise prices probably won't like that, though.
