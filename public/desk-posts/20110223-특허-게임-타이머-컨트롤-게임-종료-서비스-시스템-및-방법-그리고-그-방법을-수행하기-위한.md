발명자/고안자 : 양병석

1.     **배경 : **게임을 하다보면 한정된 시간내에 플레이할 이유가 생긴다
- 약속시간,  피씨방의 요금, 부모님이 설정한 플레이제한 시간
위와 같은 이유가 있으나 쉽게 중간에 끊기는 어렵다. 실제로 본인도 이 같은 이유로 약속시간에 늦은 경험이 있다. 이를 해결하기 위해 게임내에 알람 및 시간을 볼 수 있는 타이머 컨트롤을 제안한다.
2.     **기존 알람과 공통점 :** 게임의 구석에 현재시간, 플레이시간, 남은 시간을 알려주는 영역이 있어서, 손쉽게 사용자들이 게임 플레이시간을 컨트롤 할 수 있다. 이 경우에는 단순히 알람 혹은 타이머 컨트롤과의 게임 어플리케이션의 컨버젼스에 속한다.
3.     **차별성 :** 일반 알람과 타이머는 설정된 시간만을 알려주는데 반해 제안하는 게임시계는 게임의 종료를 제안하는데 중점을 두며, 되도록이면 유저의 게임 플레이 중에 방해를 주지 않도록 설계함에 목적이 있다.
-       **만료시간 : **플레이 중에 뜨게 한다면 플레이어 입장에서 매우 기분나쁠 수 있다. 한번의 플레이 예상시간을 고려하여 플레이 막간에 뜨게 하여 플레이중 시간이 만료되는 것을 방지할 수 있다.
**Ex) 카트라이더나 고고씽 같은 레이싱 게임의 경우, 1회 플레이시간은 3분으로 가정한다. 만료시간은 18:00 인 경우, 17:58분에 대기실로 나왔을 경우, 이번판 플레이를 진행 하지 않아여, 만료시간에 맞출 수 있다는 종료 권유 박스를 띄운다. **
-       **만료시간에 할 수 있는 선택 :**
l  **종료**
l  **타이머 취소**
l  **타이머 재 설정**
l  **타이머 보류(이 경우는 위와 같이 만료시간 정각이 안되었을 경우, 선택할 수 있는 버튼으로, 18:00시가 되면, 게임 플레이 중이라도 메시지 박스가 뜨게 되어있다.)**
-       **타이머 컨트롤 종료로 인한 게임 패널티는 없거나 작다. : **기본적으로 유저가 플레이 중 게임을 빠져나가게 되면, 빠져나간 유저에게는 패널티가 발생하게 된다. 그러나, 이 경우는 악의적인 종료로 보지 않아도 되므로, 게임내 패널티를 작게 혹은 아예 발생 시키지 않을 수 있다.****
-       **외부 API 제공 :** 한게임의 공통 타이머 모듈을 제공하여, 외부 API를 제공할 수 있다. 이 외부 API를 사용하기 위해서는 허용된 어플리케이션만 접근할 수 있도록 한다.****
**Ex) 허용된 PC방 어플리케이션, 허용된 아이들 보호 어플리케이션, 혹은 한게임에서 제공하는 외부 타이머 어플리케이션, 이 같은 어플리케이션들에게 Key를 발급하여, Key와 함께 접근하도록 함**
ð  **이를 이용하면, PC방의 요금이 만료된 시간이 타이머에 자동 설정 시켜, 추가 적인 요금 지출을 감소시키는 효과를 가져온다.**
ð  **다수의 한게임 게임들에게 플레이 누적시간을 적용하여, 한게임에 소속된 게임들의 총 플레이 시간을 부모들이 컨트롤 할 수 있다.**

Inventor/Designer: Yang Byung-seok

1.  **Background:** When playing games, reasons arise to play within a limited time.
    -   Appointment time, PC bang fees, play time limits set by parents
    Despite the above reasons, it's difficult to stop midway. I myself have been late for appointments for these reasons. To solve this, I propose an in-game alarm and a timer control to view the time.
2.  **Commonality with Existing Alarms:** There is an area in the corner of the game that displays the current time, play time, and remaining time, allowing users to easily control their game play time. This case falls under the convergence of a game application with a simple alarm or timer control.
3.  **Differentiation:** While general alarms and timers only notify of a set time, the proposed game clock focuses on suggesting game termination, with the aim of designing it to disturb the user's gameplay as little as possible.
    -   **Expiration Time:** If it pops up during gameplay, it can be very unpleasant for the player. By considering the estimated time for one play session, it can be set to appear during breaks in play, preventing time from expiring during gameplay.
    **Ex) For racing games like KartRider or GoGoSing, assume one play session is 3 minutes. If the expiration time is 18:00, and the player returns to the waiting room at 17:58, a termination suggestion box pops up, indicating that by not proceeding with this round, the player can meet the expiration time.**
    -   **Options available at expiration time:**
        l **Terminate**
        l **Cancel Timer**
        l **Reset Timer**
        l **Hold Timer (In this case, if the exact expiration time has not yet arrived, as above, this button can be selected. When it becomes 18:00, a message box will appear even if the game is in progress.)**
    -   **Game penalties due to timer control termination are none or small:** Generally, if a user exits a game during play, a penalty is incurred for the exiting user. However, in this case, it does not need to be seen as malicious termination, so in-game penalties can be made small or not incurred at all.
    -   **External API Provision:** By providing Hangame's common timer module, an external API can be offered. To use this external API, only authorized applications should be allowed access.
    **Ex) Authorized PC bang applications, authorized child protection applications, or external timer applications provided by Hangame. Keys are issued to such applications, allowing access with the key.**
    ð **Using this, the expiration time of PC bang fees can be automatically set in the timer, leading to the effect of reducing additional fee expenditures.**
    ð **By applying cumulative play time to multiple Hangame games, parents can control the total play time of games belonging to Hangame.**
