본래 이를 리뷰해보려고 했으나 서비스의 의의니 어떤유저에게 필요한지를 설명 하면서 길어졌습니다. 어차피 저처럼 wifi로거로 활동하는 블로거들도 꽤 있을거고 070앱을 검색창에 쳐보면 사용법과 장점은 수두룩하게 나올테니 부족한점과 개선점을 중심으로 리뷰해드리겠습니다. 진정한 리뷰는 사용자에게 장점을 하는것도 의미가 있겠지만, 사업자들에게는 부족한점을 피드백 받는게 중요하니까요. 무엇보다도 사용자들도 궁금할만한 부분과 알아두고 가입해야 할 부분도 있겠죠.

**1. 옵티머스큐의 프리로드된 070앱과는 비호환 , 완전한 방향의 전환
**옵티머스큐에는 이미 070앱이 프리로드 되어있습니다. 지우지도 못하죠. U플러스에서 스마트폰용 070을 가입시에 이를 이용할 수 없습니다. 프리로드된 070앱은 로그인 아이디도 물어보지 않습니다. 이를 사용하려면 따로 가입해야하고 단말기를 식별하는 방식인데, 070앱은 기존의 이 방식을 버리고 로그인기반으로 바뀐것 같습니다.
**이는 꽤 큰 변화이고 전략을 완전히 선회했음을 의미합니다. 이렇게 되고나니 프리로드된 070앱은 용량만 아깝네요. 2.2업데이트때는 선택적 삭제는 안될까요?
**
**2. 웹을 통한 불편한 가입절차
**사용전에 웹을 통해 가입을 해야하는데, 우선 앱을 통해 한방에 가입이 안된다는 점은 굉장히 낮은 접근도를 의미합니다. 또한 u플러스 사이트에서 가입시 작은 팝업을 한번 띄우고, 또다시 팝업으로 번호확인, 주소확인, 신용카드확인등을 해야하는데 이때 한 화면에 머무르며 입력하는 란이 지나치게 많을 뿐더러 닫기 버튼이 항상 아래에 눌러달라고 대기하는 모습을 띄고 있습니다.
이는 사용자로하여금 실수를 하기에 딱 좋게 생겼습니다. 그리고 한번 실수를 하면 처음부터 다시 다써야합니다. 심지어는 신용카드번호확인은 레이아웃이 깨지는 현상도 발견했습니다. U플러스박스 리뷰때 플래시버그와 레이아웃의 문제로 완료 버튼이 안보이는 문제를 지적한적이 있었는데 u플러스는 웹사이트에 대한 고민이 좀 필요한듯 보입니다. 화려함보다는 유저의 실수를 줄이고 편한 디자인과 보다 완벽한 qa를 요구합니다.

**3. 번호를 미리 선점하는 방식의 문제
**위에서 팝업을 통해 전화번호를 미리 고를 수 있는데 이때 고를 수 있는 번호 확인시 미리 예약을 해버립니다. 근데 문제는 팝업인지라 이를 실수로 날리게 되면 내가 예약한 번호인데도 고를 수 없는 사태가 발생합니다. 로그인한 정보가 있는데도 좀 어처구니 없는 상황이었습니다.

**4. 기존 070가입자의 앱 이동 지원 필요
**070은 저보다도 아내가 더 필요로 합니다. 집에 옛날 070단말이 있는데 지나치게 짧은 배터리로 인해 사실 거의 쓰지 못하고 있죠. 아내에게 스마트폰을 쥐어주고 기존번호를 옮겨오는것이 가장 손쉬운 방법일것 같습니다. 그런데 이 부분 역시 웹으로 쉽게 변경이 가능한게 아닌것 같습니다. 더군다나 tps로 묶여있는 요금제에서 이를 분리시 할인폭이 사라지는 등의 문제를 지니고 있습니다. 기존 070 가입자들의 배려가 필요한 부분입니다.

**5. Mms와 영상통화 지원
**070앱은 mms를 지원하고 있지 않았습니다. 아마도 요즘 스마트폰은 기본적으로 문자기능은 폰에서 이용하리라는 예측때문인지는 모르겠습니다. 그러나 해외에서라면 필요한 부분이 아닌가 싶습니다.
Skype는 영상통화를 지원하지만 070은 안됩니다. 070이 영상통화를 지원하고 페이스타임으로 발전할 가능성이 있지 않나 싶습니다. 무엇보다도 기존 피쳐폰과의 영상통화까지 값싸게 지원한다면 유저들이 반겨하지 않을까요?

**6. 앱을 통한 착신전환 필요
**070앱을 로그아웃 해두면 대기중으로 신호가 떨어집니다. 물론 웹에서 착신전환이 가능합니다. 그러나 wifi가 잡히지 않는 곳에서 070을 실행시키면 제대로 동작하지 않고 로그인 조차 되지 않습니다.
Wifi가 아니면 통화는 허용하지 않는다 하더라도 3g로 로그인을통해 착신전환 정도는 할 수 있게 해야하지 않을까 싶습니다.
대기중으로 나오지 않고 아예 3g 번호로 포워딩 되어 걸리는것도 괜찮겠죠. 이때 사용자에게 3g로 연결된다고 안내하는것도 유저들이 070에 걸었다고 생각했는데 핸드폰 요금이 나와 깜짝 놀라는 것을 막을 수 있을겁니다.

**7. 070앱의 미래는 Fmc 소셜허브**
070과 010의 두개의 번호를 가지게 된 지금, 드는 생각은 결국 이는 하나로 합쳐지게 될거라는겁니다. Usim은 가입자 정보를 담고 있습니다. 이는 곧 070의 로그인 정보도 사실 숨길수 있다는 점이죠. Kt의 Usim을 유저가 허락시에 u플러스의 070 앱이 접근할수 있도록 하고, wifi에서는 일반 전화앱을 띄워서 전화를 걸면 그냥 wifi망을 통해 전화가 걸립니다. 그리고 wifi망을 벗어나면 통화가 끊기지 않고 3g망으로 넘어갑니다. 심지어는 유선인터넷 노트북이 있는상황에서 블루투스로 폰이 연결되면 통화가 됩니다. 기지국과 망의 구분이 없는 이런 세상. 단순히 꿈일까요? 사실 이미 거의 근접해 있는 상황입니다. U플러스가 lg와 협력해 fmc단말을만들고 이통사간의 벽뿐만 아니라 이런 벽도 허무는 계기를 만들었으면 합니다. 그리고 이는 곧 소셜 허브로 발전할 수도 있겠죠.

While I initially intended to review it, explaining the service's significance and which users it's for made this post longer than expected. Since many bloggers, like myself, are active Wi-Fi loggers, and if you search for "070 app," you'll find countless guides on how to use it and its advantages, I'll focus my review on its shortcomings and areas for improvement. While a true review should highlight advantages for users, providing feedback on shortcomings is crucial for businesses. Moreover, there are parts that users would be curious about and should know before signing up.

**1. Incompatibility with Optimus Q's Preloaded 070 App, a Complete Change in Direction**
The Optimus Q already has a 070 app preloaded. You can't even delete it. When subscribing to the smartphone 070 service from U+, you cannot use this preloaded app. The preloaded 070 app doesn't even ask for a login ID. To use it, you have to sign up separately, and it identifies the device. However, the new 070 app seems to have abandoned this method and switched to a login-based system.
**This is a significant change and indicates a complete shift in strategy. With this change, the preloaded 070 app is just a waste of storage space. Could optional deletion be possible with the 2.2 update?**

**2. Inconvenient Web-Based Signup Process**
Before use, you need to sign up via the web. The fact that you can't sign up directly through the app signifies very low accessibility. Furthermore, when signing up on the U+ website, it first displays a small pop-up, then another pop-up for number verification, address verification, and credit card verification. At this point, there are an excessive number of input fields on a single screen, and the "close" button always appears at the bottom, seemingly waiting to be pressed.
This design makes it very easy for users to make mistakes. And once you make a mistake, you have to start all over again. I even found a layout issue where the credit card number verification screen was broken. I previously pointed out a Flash bug and layout issue in my U+ Box review where the complete button was invisible, so it seems U+ needs to put more thought into its website. Rather than flashiness, it requires a user-friendly design that minimizes errors and more thorough QA.

**3. Problem with Pre-reserving Phone Numbers**
Above, you can pre-select a phone number via a pop-up, and when confirming the number, it reserves it immediately. The problem is that since it's a pop-up, if you accidentally close it, you might find yourself unable to select a number you've already reserved, even though you're logged in. It was a rather absurd situation.

**4. Need for App Migration Support for Existing 070 Subscribers**
My wife needs 070 more than I do. We have an old 070 device at home, but due to its excessively short battery life, it's practically unusable. Giving my wife a smartphone and transferring her existing number seems like the easiest solution. However, this process doesn't seem to be easily changeable via the web either. Furthermore, separating it from a TPS-bundled plan can lead to issues like the loss of discounts. This is an area where consideration for existing 070 subscribers is needed.

**5. MMS and Video Call Support**
The 070 app did not support MMS. Perhaps this is due to the assumption that modern smartphones handle basic text messaging functions through the phone itself. However, I wonder if it might be a necessary feature for users abroad.
Skype supports video calls, but 070 does not. I wonder if 070 could support video calls and potentially evolve into something like FaceTime. More importantly, wouldn't users welcome it if it cheaply supported video calls even with existing feature phones?

**6. Need for Call Forwarding via the App**
If you log out of the 070 app, calls go to voicemail. Of course, call forwarding is possible via the web. However, if you try to run 070 in a place without Wi-Fi, it doesn't function properly and won't even log in.
Even if calls are not allowed without Wi-Fi, I think it should at least allow login via 3G to enable call forwarding.
It would also be good if calls were forwarded directly to the 3G number instead of going to voicemail. Notifying the user that the call is being connected via 3G would prevent users from being surprised by mobile phone charges when they thought they were calling a 070 number.

**7. The Future of the 070 App: FMC Social Hub**
Now that we have two numbers, 070 and 010, the thought that comes to mind is that they will eventually merge into one. USIMs contain subscriber information. This means that 070 login information could also, in fact, be hidden there. If a user permits the U+ 070 app to access their KT USIM, and they make a call using a standard phone app on Wi-Fi, the call would simply go through the Wi-Fi network. And when they leave the Wi-Fi network, the call wouldn't drop but seamlessly switch to the 3G network. Furthermore, if a phone is connected via Bluetooth to a laptop with a wired internet connection, calls would be possible. A world without distinctions between base stations and networks. Is this merely a dream? In fact, we're already very close to it. I hope U+ collaborates with LG to create FMC devices and create an opportunity to break down not only the barriers between mobile carriers but also these kinds of network distinctions. And this could soon evolve into a social hub.
