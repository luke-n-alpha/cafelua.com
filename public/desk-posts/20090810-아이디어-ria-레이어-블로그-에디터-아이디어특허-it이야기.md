- **제목 : 레이어 에디터 **

- **개선점 : **현재의 에디터의 경우, 1개의 html 문서를 작성을 하는 것을 원칙으로 한다. 제안 하는 방법은 다수의 html 문서 혹은 이미지를 겹처서 문서를 작성한다. 이는 포토샵의 레이어, 워드의 배경글 같은 개념으로 적용 될 수 있으며, 보다 html의 편집을 보다 자유롭게 할 수 있게 한다.. 배경글은 템플릿으로 이용될 수도 있으며, 레이어간 사용자 권한을 다르게 할 수도 있다.

- **주요 개념 정의 **

- **레이어 컨트롤** : 포토샵의 레이어 팔레트와 같은 역할을 하는 컨트롤로서, 레이어의 병합과 생성, 선택, 크기변경, 레이어 활성화 등을 할 수 있다. 일반적으로 포토샵의 레이어 팔레트와 비슷한 역할을 하면 된다고 볼수 있다.
{{IMG:1}}** [포토샵의 레이어 팔레트] **

{{IMG:2}}** [레이어 컨트롤]**

- **배경글** : 기본적으로 처음에 작성되는 글로, 글의 페이지 크기를 결정한다. 일반적인 포스팅과 동일하다.
{{IMG:3}}

- **레이어글** : 배경글 위에 똑 같은 크기로 덥히는 글로서 다수가 존재 할 수 있다. 배경글 보다 큰 레이어글은 작성할 수 없다. 혹, 작성이 가능하게 하더라도, 배경글의 크기가 확장된 레이어글의 크기를 따라가게 된다.
(레이어글은 html 혹은 비트맵 혹은 벡터이미지, 혹은 그 혼합 형태일 수 있다.)
{{IMG:4}}
[위는 이미지 레이어에 대한 예시다. 일반 포스팅 처럼 보통 에디터 일 수도 있다.]

- **병합** : 레이어글은 배경글과 병합 될 수 있다. Html 타입의 병합과 이미지 타입의 병합이 있을 수 있다. 보기에는 병합이전과 동일해 보일 수 있으나, 실제로 소스코드는 1개의 페이지가 되도록 한다. 이미지 타입의 병합은 병합된 상태가 이미지가 되도록 하는 기술이다.
{{IMG:5}}
[ 병합된 이미지 ]

- **스크랩시 배경글로만 사용하기 기능 **: 이 포스팅 기능을 사용시, 스크랩시, 수정은 배경글은 수정이 불가능하며, 레이어만 추가 할 수 있다. 이 기능을 활용 시 원본 손상은 없이 스크랩해간 사람이 자신만의 추가 편집을 할 수 있다.
(이는 레이어간의 사용자 권한을 다르게 줄수도 있음을 의미한다.)
{{IMG:6}}

- **활용 **

- 작성된 글에 밑줄을 긋거나, 화살표를 그리고 주석을 넣는 행위, 파워포인트 처럼 다양한 이미지 도형을 제공할 수도 있다

- 스크랩한 글에 자신만의 어떠한 새로운 표시를 가할 수도 있다.

- 블로그내에 기본 배경 포스팅 템플릿을 만들어 두어, 자신만의 포스팅 타입을 만들 수 있다. 이 기능은 배경글을 이용한, 사내 문서 템플릿 처럼 웹 상에서 활용 하는 것이다.

- **Title: Layer Editor**

- **Improvement Point:** Currently, the editor is designed to create a single HTML document. The proposed method involves creating documents by overlapping multiple HTML documents or images. This can be applied with concepts like Photoshop layers or Word's background text, allowing for more flexible HTML editing. Background text can also be used as a template, and different user permissions can be assigned to different layers.

- **Key Concept Definitions**

- **Layer Control**: A control that functions like Photoshop's layer palette, allowing for layer merging, creation, selection, resizing, and activation. Generally, it can be seen as performing a similar role to Photoshop's layer palette.
{{IMG:1}}** [Photoshop's Layer Palette] **

{{IMG:2}}** [Layer Control]**

- **Background Text**: This is the text initially created, which determines the page size of the document. It is the same as a regular post.
{{IMG:3}}

- **Layer Text**: This is text that overlays the background text with the same size, and multiple instances can exist. Layer text larger than the background text cannot be created. Even if it were possible to create larger layer text, the background text's size would expand to match the larger layer text's size.
(Layer text can be HTML, bitmap, vector image, or a hybrid form thereof.)
{{IMG:4}}
[The above is an example of an image layer. It could also be a regular editor, like a normal post.]

- **Merge**: Layer text can be merged with background text. There can be HTML type merges and image type merges. Although it may appear the same as before merging, the source code actually becomes a single page. Image type merging is a technology that makes the merged state an image.
{{IMG:5}}
[ Merged Image ]

- **Use as Background Text Only When Scrapping Feature**: When using this posting feature, upon scrapping, the background text cannot be modified, and only layers can be added. Utilizing this feature allows the person who scrapped the content to make their own additional edits without damaging the original.
(This also implies that different user permissions can be assigned to different layers.)
{{IMG:6}}

- **Applications**

- Actions such as underlining text, drawing arrows, adding annotations to written content, and providing various image shapes like in PowerPoint.

- You can also add your own new markings to scrapped articles.

- By creating default background posting templates within the blog, you can create your own posting types. This feature utilizes background text, much like an internal document template, for use on the web.
