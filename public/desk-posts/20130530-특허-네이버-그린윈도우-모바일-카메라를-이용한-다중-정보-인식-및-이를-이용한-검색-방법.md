# METHOD, SYSTEM AND COMPUTER READABLE RECORDING MEDIUM FOR RECOGNIZING MULTIPLE INFORMATION USING MOBILE CAMERA AND SEARCHING USING THE SAME

출원번호 :1020100043089 (2010.05.07)- 등록번호 : 1011934850000
출원인 :  엔에이치엔(주) / 엔에이치엔비즈니스플랫폼 주식회사발명자 : 양병석, 김형태
**1. 제목 : 모바일 카메라를 이용한 검색창 인식및 응용기술**
2. 서론 : 국내 포탈의 경우 검색창을 이용한 프로모션이 활발하다. 온,오프라인으로 많이 보이는 네이버 검색창에 ***를 쳐보세요. 같은 문구는, 수년전부터 각 포탈의 그린윈도우같은 CI를 활용되고 있다. 이 검색창은 2차원 바코드나 QR코드 보다 유저에게 인식성이 뛰어나며 광고의 효과까지 가지고 있다. 이를 활용한 검색기술을  구성해본다.
**3. 기술 적 용이성** - 그린 윈도우는 초록색 사각 테두리에 흰바탕에 검은 글씨의 형태로 되어 있어서 Feature가 매우 단순하다.  - 흰바탕에 검은 고딕 글씨의 경우에 인식하기에도 매우 용이한 형태이다.{{IMG:1}}
** 5. 사용 예시**  - 버스 정류장에 그린윈도우가 있고, 그 안에 버스정류장 번호가 존재한다. 이를 촬영시 바로 버스정류장 정보를 검색하여 준다.  - **꽃집의 간판의 그린윈도우를 촬영시 **꽃집으로 검색 결과를 보여준다.  - 명함에 있는 그린윈도우의 명함주소를 촬영시 온라인 명함을 다운로드 한다.{{IMG:2}}
**6. 응용 기술** 1) 검색 쿼리의 속성을 정의하는 부가 정보 삽입  - 검색창내에 있는 쿼리는 통합 검색에 대한 정보만이 아니라, 이미지 검색 혹은 온라인명함, 블로그 주소등을 나타낼수 있는데 이를 위해 사전에 formal한 부가 정보를 삽입이 가능하다.   ex) 그린 윈도우 내에 [블로그 - fstory97] 이 검색되는 경우 바로 m.blog.naver.com/fstory97로 이동한다.{{IMG:3}}       해당 부가 정보는 텍스트가 아니라 Symbol일 수도 있다.       [☞ 남대문] 인 경우, 네이버 지도 서비스의 검색 쿼리로 인식한다.{{IMG:4}}
2) 모바일 앱에서 검색 결과의 속성을 정의하여 선택 검색  - LCD의 그린 윈도우 가이드라인 옆에 검색 버튼을 다수를 위치한다.  - 통합검색, 이미지검색, 지식in 검색 버튼. 그린윈도우 맞추고 각 버튼을 누르는 경우 다른 검색결과를 보여준다.  - 혹은 먼저 인식된 쿼리를 판별한 후 어떤 검색결과로 이동할지를 선택하게 해도 좋다.
**7. 수익모델** - 모바일 웹의 키워드 비딩 - 기업과 소매점을 상대로 한 모바일 명함 서비스

METHOD, SYSTEM AND COMPUTER READABLE RECORDING MEDIUM FOR RECOGNIZING MULTIPLE INFORMATION USING MOBILE CAMERA AND SEARCHING USING THE SAME

Application Number: 1020100043089 (2010.05.07) - Registration Number: 1011934850000
Applicant: NHN Corp. / NHN Business Platform Corp. Inventor: Yang Byung-seok, Kim Hyung-tae
**1. Title: Search Window Recognition and Application Technology Using Mobile Camera**
2. Introduction: In the case of domestic portals, promotions using search windows are active. Phrases like "Try typing *** into the Naver search window," which are frequently seen online and offline, have been utilizing the CI, such as the "Green Window" of each portal, for several years. This search window offers superior user recognition compared to 2D barcodes or QR codes and even has an advertising effect. We will configure a search technology utilizing this.
**3. Technical Applicability** - The Green Window has a very simple feature, being in the form of black text on a white background with a green rectangular border. - It is also a very easy form to recognize, especially with black Gothic text on a white background.{{IMG:1}}
**4. Basic Configuration Diagram**
1) Mobile Client: Search Window Recognition
   - The application searches for the existence of a search window using a real-time camera app.
   - There is also a method to increase the recognition rate by overlapping the Green Window's guidelines in terms of UI. (Optional)
2) Query Extraction
   - The search window transmitted to the server extracts the query through preprocessing and OCR technology.
3) Mobile Search Result Generation
   - Extracts the URL of the corresponding mobile page or mobile search results from the recognized query.
4) Transmits the generated mobile search results to the client.
5) Renders the received results on the mobile device.
**5. Usage Examples**
 - If there is a Green Window at a bus stop containing the bus stop number, taking a picture of it immediately searches for bus stop information.
 - When photographing the Green Window on a florist's sign, it shows search results for "florist."
 - When photographing the business card address in a Green Window on a business card, it downloads the online business card.{{IMG:2}}
**6. Application Technology**
1) Insertion of additional information defining the attributes of the search query
 - The query within the search window can represent not only information for integrated search but also image search, online business cards, blog addresses, etc. For this, formal additional information can be inserted in advance.
   ex) If [Blog - fstory97] is searched within the Green Window, it immediately navigates to m.blog.naver.com/fstory97.{{IMG:3}}
   This additional information can be a Symbol rather than text.
   If it's [☞ Namdaemun], it is recognized as a search query for Naver Map service.{{IMG:4}}
2) Selective search by defining the attributes of search results in a mobile app
 - Place multiple search buttons next to the Green Window guideline on the LCD.
 - Integrated search, image search, Knowledge-in search buttons. When aligning with the Green Window and pressing each button, different search results are shown.
 - Alternatively, it is also good to determine the recognized query first and then allow the user to select which search result to navigate to.
**7. Revenue Model**
- Keyword bidding on mobile web
- Mobile business card service for businesses and retailers
