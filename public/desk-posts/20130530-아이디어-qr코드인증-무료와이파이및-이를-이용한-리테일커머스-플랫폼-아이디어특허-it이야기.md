커피숍에서 매번 QR코드 비번을 물어보는 것이 귀찮던 차에 생각해본 아이디어입니다. 간단히 설명드리면, 전용 앱을 이용하여 QR코드 스캔시, 앱ID나 단말ID기반으로 자동 인증 처리되며, 하루 이후에는 만료처리하는 방식 입니다. 시작페이지는 리테일 사업자의 페이지를 첫화면으로 하는 웹뷰 브라우져를 띄우도록 만들어, 리테일 사업자는 지속적으로 단골과 커넥션을 맺을 수 있는 앱입니다. 1. 제목 : **Qr코드인증 무료와이파이및 이를 이용한 리테일광고플랫폼****2. 최초 제안일 : 2013-04-22****3. 개념 : **카페같은 리테일 사업자들의 무선 와이파이존의 인증을 QR코드를 이용해 보안과 편의성을 도모하고, 스캔앱을 통해 시작페이지에 리테일 광고 플랫폼을 제공함을 목표로 한다.** **** (사용자의 입장에서는 최초의 인증및 앱의 최초의 시작페이지만 확인후, 기존 무료wifi와 동일하게 이용가능)****

This is an idea I came up with because it was annoying to ask for the QR code password every time at a coffee shop. Simply put, when scanning a QR code using a dedicated app, authentication is automatically processed based on the app ID or device ID, and it expires after one day. The starting page is designed to display a webview browser with the retail business's page as the first screen, making it an app where retail businesses can continuously connect with their regular customers.

1. Title: **QR Code Authenticated Free Wi-Fi and Retail Advertising Platform Utilizing It**
2. Initial Proposal Date: **2013-04-22**
3. Concept: **The goal is to enhance security and convenience for wireless Wi-Fi zone authentication in retail businesses like cafes using QR codes, and to provide a retail advertising platform on the starting page through a scanning app.** **(From the user's perspective, after the initial authentication and checking the app's first starting page, it can be used just like existing free Wi-Fi.)**

4. As-is, To-be
1) As-is
Problems with existing free Wi-Fi
{{IMG:1}}
- User's perspective: Tedious authentication required every time at each location, concerns about the security of Wi-Fi used by anyone.
- Business owner's perspective: Wi-Fi is open, allowing users outside the business premises to use it.
- Platform's perspective: Free Wi-Fi users only use Wi-Fi, becoming a "dumb pipe," leading to low usability as a platform service.

2) To-be
Improved QR Code Authenticated Free Wi-Fi
{{IMG:2}}
- User's perspective: No tedious authentication required every time at each location, problem solved with a single app installation and QR code scan.
- Business owner's perspective: Usable only in areas where QR codes are distributed, and customer management for Wi-Fi users is easy due to the retail advertising platform on the starting page (coupon push possible).
- Platform's perspective: When authenticating via the app, users are forced to view the platform owner's starting page, increasing PV and UB, allowing leverage of other platform owner services (e.g., direct Naver app download), and creating revenue models using local commerce and local community platforms.

5. Scenario
1) App Distribution
When connecting to Wi-Fi. Connect to the guide page and app download page.
: Compared to existing mobile web real-name authenticated free Wi-Fi, if the app is already downloaded, subsequent authentication steps can be skipped. The main goal is to install an app with good mobile accessibility.

2) QR Code Scan
**When scanning the offline QR code located in the store, the app performs authentication based on information that can identify the device, such as a device ID or app ID.** The authentication validity period is limited to one day, and upon subsequent reconnection, the QR code must be scanned again with the app. **If scanned with another QR code app, authentication is denied. (Example: LINE QR login)**
: Password-based Wi-Fi is difficult to manage passwords, but by using QR codes, usage outside the store can be blocked.

3) Move to Starting Page After Authentication
After authentication, the initial starting page opens in the app. This app displays the browser as a webview, similar to Naver or Daum apps, to prevent user abandonment.

4) Starting Page Configuration
- Portal search bar
**- Embedded frame for the retail store**
: Coupons for the store. Friend requests. Leave a review, reviews.
: Provide a platform for retail stores to manage this frame and page.
- News
- Recommended free content (N Store)
- Shortcuts: Naver. Daum. Bookmarks

This starting page can be used as a retail commerce platform and a portal platform. Users gain additional benefits such as free Wi-Fi, content, and coupons when using it. It enables continuous customer management for businesses. Platform owners secure PV to gain advertising revenue and platform power.
