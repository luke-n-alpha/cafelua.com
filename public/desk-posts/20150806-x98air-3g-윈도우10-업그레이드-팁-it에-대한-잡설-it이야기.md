I upgraded my x98 air 3g tablet, known for its excellent value for money, to Windows 10. There were several twists and turns, but the upgrade was successful, and I'm using it well, so I'm documenting the upgrade process.
**1. Let's download Windows 10. It must be 32-bit.** First, download Windows 10. I eagerly waited for the automatic Windows 10 upgrade in the bottom right corner on July 30th, but it remained in a reserved state, so I downloaded it manually. The download URL is below. The reason you must download the 32-bit version is that the x98air 3g's original drivers are 32-bit.
https://www.microsoft.com/ko-kr/software-download/windows10
[Windows 10www.microsoft.com](https://www.microsoft.com/ko-kr/software-download/windows10){{IMG:1}}

**2. Download and install. But an OTL error occurred.** After the download was successfully completed, I encountered the following error:
**"Failed to initialize the working directory."**
{{IMG:2}}

http://m.gfmarket.naver.com/sticker/detail/code/moon_and_james

{{IMG:3}}The reason is insufficient internal storage space. I spent a long time looking for the cause. Although the minimum required space for the Windows 10 upgrade was stated as 3GB, the download itself takes about 2.6GB, and there wasn't enough free space for installation, meaning the actual required space is much larger.
**3. Move the downloaded Windows 10 to the D drive on the microSD card.** I still had space on my D drive because I use a 64GB microSD card. So, you need to move the downloaded files to the D drive and then install them.
1) Press the Windows + E keys to open File Explorer.
2) Go to This PC > Local Disk (C:).
3) In the top menu, check View > Hidden items. This will show two folders: C:\Window.~BT, C:\Window.~WS
**4) Cut and paste (move) the hidden C:\Window.~WS folder to the D drive, D:\Window.~WS**

**4. Now, restart the installation.** If you do this, you should have free space on your C drive.
Rerun the file below.
**D:\Window.~WS\Sources\Windows\Setup.exe**
It will download again. But there's no need to worry. Unlike before, you won't encounter a "problem occurred" message, and the installation will complete successfully.
