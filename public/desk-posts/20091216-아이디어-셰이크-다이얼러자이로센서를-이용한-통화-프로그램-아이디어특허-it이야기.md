**제목 : 셰이크 다이얼러(Shake Dialer)**
**생각해본 날짜 : 2009년 12월 16일**
**작성자 : 숲속얘기([http://blog.naver.com/fstory97](http://blog.naver.com/fstory97))**
****
**배경 : **아이폰 같은 터치가 늘고 있는데 요즘같은 날씨에는 장갑 벗고 통화하는게 일임. 해서 어떻게하면 장갑을 벗지 않고, 혹은 운전중에 라도 정확한 통화를 할 수 있을까 하여 구상해본 아이템

**조건 :** 해당 폰에는 동작인식이 가능한 자이로센서가 내장이 되어 있어야 한다.

**1. 단축다이얼 설정 모드**
환경설정에는 단축다이얼을 설정한다. (기존의 단축다이얼을 써도 상관없다.)

**2. 단축 다이얼 선택 모드**
단말기를 흔들때 마다, 단축다이얼이 증가한다.
{{IMG:1}}
이때 단말기의 영상에서 해당 단축 다이얼의 정보를 음성과 화면을 통해 알려준다.

**3. 콜링 대기 모드**
** - 단축 다이얼이 선택되고 멈춘 상태 -**
** 1) 시간 만료**
n회의 흔들기(최소 1초이내의 간격)를 멈추고(1초 초과) 기다리면, n번째 단축다이얼이 선택된것으로 인식하고, Timer가 동작한다.
Timer가 만료되면, 선택된 단축다이얼은 해제된다.
****
** 2)  콜링**
1회 한번 더 흔들면 해당 단축 다이얼에 Calling을 시도한다.

** 3) 취소**
2회 흔들면(일종의 더블클릭 개념) 단축 다이얼 선택을 취소하고 단축 다이얼 선택모드(처음)으로 되돌아간다.

**4. 콜링 모드**
Calling을 시도하고 신호음이 가는 도중, 2회이상 흔들면 Calling을 중단한다.

**5. 통화 모드**
통화 도중, 통화를 종료하고 싶으면 2회이상 흔들면 통화를 종료한다.

**6. Tutorial 모드**
흔드는 동작의 Command들에 대한 튜토리얼
번호 올리기, 더블 셰이크(선택및 취소) 등의 튜토리얼

*** 모든 진행은 화면과 음성이 동시에 반영된다. 운전중에도 음성을 통해 핸드폰을 흔드는 것 만으로도 모든 통화동작을 동작할 수 있다.**

**Title: Shake Dialer**
**Date Conceived: December 16, 2009**
**Author: Forest Story ([http://blog.naver.com/fstory97](http://blog.naver.com/fstory97))**

**Background:** Touch phones like the iPhone are becoming more common, but in weather like this, taking off gloves to make a call is a hassle. So, I conceived this item to figure out how to make accurate calls without taking off gloves, or even while driving.

**Condition:** The phone must have a built-in gyro sensor capable of motion recognition.

**1. Speed Dial Setup Mode**
In the settings, set up speed dials. (Existing speed dials can also be used.)

**2. Speed Dial Selection Mode**
Each time the device is shaken, the speed dial number increases.
{{IMG:1}}
At this time, the device's display provides information about the selected speed dial via voice and screen.

**3. Calling Standby Mode**
** - State where speed dial is selected and stopped -**
** 1) Time Expiration**
If shaking n times (at intervals of at least 1 second) is stopped (exceeding 1 second) and you wait, the n-th speed dial is recognized as selected, and a Timer starts.
When the Timer expires, the selected speed dial is released.

** 2)  Calling**
If shaken one more time, it attempts to Call the corresponding speed dial.

** 3) Cancel**
If shaken twice (a concept similar to double-clicking), the speed dial selection is canceled, and it returns to the speed dial selection mode (initial state).

**4. Calling Mode**
While attempting a Call and the ringtone is playing, shaking more than twice stops the Call.

**5. Conversation Mode**
During a conversation, if you want to end the call, shaking more than twice ends the call.

**6. Tutorial Mode**
Tutorial for the shake gesture Commands
Tutorial for increasing numbers, double shake (selection and cancellation), etc.

*** All processes are reflected simultaneously on screen and via voice. Even while driving, all call operations can be performed simply by shaking the phone and using voice feedback.**
