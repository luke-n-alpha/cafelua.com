I sold my Galaxy Note 8.0 and am currently using a Chinese tablet, the x98air. I sold the Note 8.0 for 200,000 won used, added 100,000 won, and bought the x98air new for 300,000 won. The result has been very satisfying so far.

**1. x98 air + Alpha = Laptop under 1kg**

This is my current setup. It's a combination of the X98 air + Bluetooth keyboard + portable stand + HDMI adapter + microSD card.

{{IMG:1}}

Development tools like phpStorm or Eclipse run well. I thought it would be a bit inconvenient without a mouse, so I'm using an OMT OBK-B190, but a key broke off shortly after I started using it. T_T I bought it for 29,000 won on social commerce, but the lowest price now is 32,000 won. I wanted to buy the SkyDigital X11 Cursor with a trackball, but it's constantly sold out. Since it's broken, I'm using the slightly thicker iMagic BT300 I had before, and an irocks Bluetooth mouse simultaneously.

This is how it arrived when I first bought it.

{{IMG:2}}

I ordered a separate screen protector.

{{IMG:3}}

My goal was to reduce weight, so I didn't put anything on it. If you put any cover on it, the 500g weight immediately becomes 700g, making the lightness meaningless. My purpose was to use it lightly, and since it's cheap, I skipped the cover. Additionally, a Micro HDMI-HDMI adapter can be purchased for 3,000 won. You can connect it to a projector or a TV.

My existing laptop(?) bag, which used to contain an LG Gram and a Note 8.0, weighed almost 1.5kg. Now, things weighing less than 1kg fit neatly. Of course, I have other main PCs at the office and at home. Dropbox connects them all.

**2. Not a high-performance laptop, but usable. And long-lasting.**

For me, who pursued lightness, it became the best solution by combining a laptop and a tablet into one. The price, including all accessories, is under 350,000 won. The performance is as follows. The memory is a bit disappointing, but I didn't buy it for performance, so I'll pass. The battery seems to last about 7 hours. This is sufficient as my main purpose is note-taking during outdoor meetings. In the case of the LG Gram, the battery only lasted 2-3 hours, so it couldn't even get through a morning meeting, but I'm grateful for this one that lasts all day.

In the case of Android, the performance is snappy. When I reboot, an alert sometimes pops up saying the music app has crashed, but I just ignore it. It's probably because I deleted a lot of default apps. The surprising thing about Chinese tablets is that most of the pre-installed apps can be deleted, and there aren't many installed to begin with. Even with 64GB split between Android and Windows, it's more than enough.

**3. Windows + Android = OS Switching Method**

To switch OS, use **Volume Up + Power**. This wasn't explained separately, so I found out through an internet search. Of course, it's only possible when turning on the power. It takes a little time to boot, but it's faster than an HDD because it's eMMC.
