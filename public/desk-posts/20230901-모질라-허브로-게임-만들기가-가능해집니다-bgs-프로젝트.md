WebXR메타버스 오픈소스 프로젝트 모질라허브는 다양한 강점들이 있지만, 그 중 가장 강력한 강점은 웹 에디터로 손쉬운 메타버스 공간을 만들기 입니다. 하지만 이러한 공간제작에서 한가지 아쉬운 점이 있다면 게임과 같은 자유도나 인터랙션을 구현하지 못하는게 아쉬움이었습니다.  하지만 조만간 이러한 인터렉션 구현이 가능해 질 것 같습니다. 오늘 제가 소개시켜드리는 BGs(Behavior Graphs) 오픈소스 프로젝트 때문입니다. ​아래는 2022년 8월 15일 작년 영상으로 모질라 허브의 개발자 행사에서 코드를 직접 수정하며 사례를 보여주었습니다. 한 사람이 가까이 가면 문이 열리는데 원격의 다른 사람들이 이 문의 3D오브젝트의 상태와 애니메이션을 동기화 하는 사례를 보여주었습니다. 그래서 영상 제목도 "모질라 허브에서 동기화된 인터렉티브 애니메이션 컴포넌트 개발(Building a networked interactive animated component in Hubs) 입니다.​[https://youtu.be/ySINGYYsQQ8](https://youtu.be/ySINGYYsQQ8)

그리고, 얼마전 2023년 8월 18일 허브의 디스코드에서 새롭게 발표가 있었습니다. 아직 저도 직접 해보지는 못했지만 먼저 문서를 번역해보면서 개념을 좀 살펴보고 관련 내용과 문서, 영상을 공유드리며 가장 중요한 몇가지 포인트를 말씀드리겠습니다.

**4. 네트워크 컴포넌트들을 제공하여 동기화를 진행함**

발표의 핵심 내용은 어떤 플레이를 기준으로 컴포넌트를 동기화 할 것인가에 대한 내용이었습니다. 이를 위해서는 소유권(Ownership)이라는 개념과 이를 취득하기 위한 알고리즘 등이 설명 되었습니다. 그보다는 어떤 것이 동기화 될 수 있는 가가 더 궁금하실 것 같습니다. - 리지드바디(타입/질량/중력), 트랜스폼(위치/각도/크기), 커스텀 파라미터, 애니메이션, 오디오/비디오, 미디어프레임, 문자  컴포넌트들이 동기화가 가능함을 의미하는 것 같습니다. 현재 모질라허브의 소스를 보면 미디어프레임과 오디오/비디오가 동기화 됬던 것을 확인할 수 있었는데, 여기에도 동일하게 적용된 것 같습니다.​​

The WebXR metaverse open-source project Mozilla Hubs has various strengths, but its most powerful advantage is the easy creation of metaverse spaces with its web editor. However, one regrettable aspect of this space creation was the inability to implement game-like freedom or interaction. But it seems that such interaction implementation will soon be possible. This is thanks to the BGs (Behavior Graphs) open-source project I'm introducing today. Below is a video from last year, August 15, 2022, showing an example at a Mozilla Hubs developer event where code was directly modified. It showed an example where a door opens when one person approaches it, and other remote users synchronize the 3D object's state and animation of this door. Therefore, the video title is "Building a networked interactive animated component in Hubs."

**4. Provides network components for synchronization**

The core of the presentation was about which play to use as a basis for synchronizing components. For this, the concept of Ownership and algorithms for acquiring it were explained. You might be more curious about what can be synchronized. - It seems to mean that RigidBody (type/mass/gravity), Transform (position/rotation/scale), Custom Parameters, Animation, Audio/Video, MediaFrame, and Text components can be synchronized. Looking at the current Mozilla Hubs source, I could confirm that MediaFrame and Audio/Video were synchronized, and it seems the same applies here.

This seems to be the biggest trend in the metaverse recently. The 3D metaverse, once considered the exclusive domain of 3D game engines, is expanding its own territory in both apps and the web.
