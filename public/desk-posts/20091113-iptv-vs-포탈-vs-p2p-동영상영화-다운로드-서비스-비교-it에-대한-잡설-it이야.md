최근 동영상 컨탠츠 시장의 정상화에 대한 목소리가 높습니다. 한국영화가 뜨고 있고, 홈씨어터가 일반화 되고 있는 시점에서 한국의 패키지 게임 시장의 뒤를 이어서는 안되겠죠. 그래서 기존의 불법의 선봉이었던 p2p와 최근 확산되고 있는 IPTV 그리고 이제 막 시작한 포탈의 다운로드 서비스를 비교해보겠습니다.

| 구분 | iptv {{IMG:1}} | 인터넷 포탈 {{IMG:2}} | p2p {{IMG:3}} |
| --- | --- | --- | --- |
| 주요 사업자 | 3대 통신사(SK, LG, KT) | 포탈 사업자(네이버, 다음,파란) | 중소p2p사업자(프루나, m파일, xtoc, 파일구리 등) |
| 사업자 규모로 보면 iptv, 포탈, p2p 순입니다. |  |  |  |
| 가입자 | 상대적 보통 | 상대적 많음 | 상대적 작음 |
| 현재는 포탈 가입자가 가장 많으나, 통신가입자가 iptv가입자로 빠르게 유입되어 큰 성장세를 보이고 있습니다. p2p유저는 상대적으로 가입자는 적으나 가입자들이 파워유저로 디지털 허브 역할을 하는 경우가 많아 파급력이 큽니다. |  |  |  |
| 과금 | 신작 3500원 ~ 무료 DRM (48시간) | 신작 3500원 ~ 500원 DRM (유/무) | 500원미만 (패킷, 정액제 과금) |
| IPTV는 다른 이동기기로 파일 이동이 가능한 수단이 없고, DRM으로 가장 강력이 차단 하고 있습니다. 포탈의 경우 무료 컨탠츠가 없는 것이 단점이고, 다음의 경우 DRM이 존재하지 않는 것이 장점입니다. p2p는 가격경쟁력 면에서 수배로 가장 우수하여 컨탠츠거래 시장입장에서 볼 때 다른 수단의 경쟁력을 상실 시킵니다. 이는 불법 유통 컨탠츠에 p2p업체가 저작권료를 지불하지 않고 있기 때문입니다. |  |  |  |
| 컨탠츠 수 | 보통 | 적음 | 많음 |
| 사용자 참여가 활발한 p2p의 컨탠츠가 가장 다양하게 확보를 하고 있으며 가장 후발인 포탈 사업자가 가장 적음 |  |  |  |
| 컨탠츠 확보 속도 | 보통 | 보통 | 매우 빠름 |
| P2p의 경우 유저가 원하는 컨탠츠를 유저가 립핑하므로 컨탠츠 확보속도가 매우 빠릅니다. 저작권의 협의가 필요한 다른 서비스의 경우 훨씬 속도가 늦고, 그 다양성 면에도 따라가기가 어려운 면이 있습니다. 특히 해외 드라마와 에니메이션의 경우 압도적으로 p2p가 빠른 양상을 보여주고 있는데, iptv나 포탈 처럼 합법적인 서비스의 경쟁력 확보를 위해서는 컨탠츠의 수와 확보 속도를 올리는 것은 매우 중요합니다. Iptv를 기다리기 귀찮아서 다운받는 유저들도 있으니까요. |  |  |  |
| 사용자 접근도 | 매우 우수 | 우수 | 낮음 |
| iptv는 pc를 키는 부담이 없음, p2p사이트는 군소사이트로 이동 커뮤니티 접근 등 번거로움 |  |  |  |
| 검색 | 낮음 | 매우 우수 | 우수 |
| iptv의 가장 큰 문제는 검색이 용이 하지 않은 것입니다. 키보드에 비해 불편하고 느린 리모컨, 나쁜 검색 ui로 인터넷 사이트에 비해 매우 불편하여 조속히 개선되어야 할 점으로 보입니다. 전통적 검색강자인 포탈은 통합검색등과 연동 하여 다양하고 강력한 검색 서비스 제공이 가능할 것으로 보입니다. p2p는 저작권 문제로 많은 단어들이 필터링 되고는 있으나 다양한 방법으로 회피하여 목적하는 컨텐츠와 커뮤니티에 접근, 저작권 필터란 점이 가장 큰 불편함으로 작용하나 검색필터의 약점을 이용한 검색이 이루어지고 있습니다. (해리포터 -> 해.리.포.터 -> 핼리포터) |  |  |  |
| 성인컨탠츠 | 약 | 약 | 강 |
| 얼마전 일본에서 한국에 성인 컨탠츠에 대한 저작권을 시비건 적이 있었습니다만, 결국은 저작권을 인정하지 않았습니다. 보통 19금 영화와 달리 야동이라고 불리는 이 컨탠츠는 p2p사이트의 주 수익원이 되고 있습니다. p2p를 근본적으로 근절 시키고자 하는 노력을 하려면 영화 이상으로 저작권 문제를 시비 걸고 넘어가야하는 것이 바로 성인컨탠츠 입니다. 청소년 보호 장치는 여전히 포탈과 IPTV에만 머물고 있으며, 이 p2p는 완전히 사각지대 입니다. 불법 컨탠츠 유통을 손을 보려면 반드시 집고 넘어가야 하는 것이 바로 이 성인컨탠츠입니다. |  |  |  |
| ucc 지원 | 제한적 활용 | 매우 많은 활용 | 없음 |
| Ucc는 기본적으로 웹 환경에 시작한 것이므로, 웹에서 가장 많은 활용도를 보여줍니다. 그러나 모두 생산자에 대한 수익분배는 이루어지고 있지 않으며, IPTV에서는 제한적으로나마 포탈과 연계하여 UCC서비스가 이루어집니다. p2p의 경우 UCC와는 거리가 먼 서비스라고 할 수 있습니다. |  |  |  |
| 모바일 지원 | 없음 | 제한적 지원 | 사용자에 의한 컨탠츠 확보 |
| 모바일 기기의 경우 DRM 으로 파일을 외부로 이동 불가능하여 IPTV는 아예 지원 불가능 합니다. 포탈은 Mp4 형태로 일부 지원하나, 단말기에 맞는 다양한 포맷 제공은 하고 있지 못하고 있습니다. p2p는 모바일기기 플레이 목적의 커뮤니티를 중심으로 모바일용 컨텐츠가 사용자들에 의해 제작 유통되고 있습니다. Divx가 플레이가 가능한 핸드폰과 아이폰 같은 스마트폰들의 강세로 모바일에 대한 동영상 플레이 니즈는 Mp3만큼 커질 것으로 예상됩니다. |  |  |  |
| 향후발전방향 | 가전기기로 접근도가 가장 높다는 강점을 내세워 가장 쉬운 미디어 유통 플랫폼으로 변화 가능성이 높습니다. 전통적 방송 컨탠츠 확보가 용이하고, 모바일 IPTV의 스펙을 따로 가져 갈 것으로 예상됩니다. | 웹TV로 발전 가능성이 높으며 인터넷 유저들에게 가장 접근도가 높습니다. 모바일 풀브라우징이 가능해지고, Seamless한 값싼 무선 환경이 이루어질 경우, App이나 별도의 모바일 어플리케이션으로 활용이 가능할 것으로 예상됩니다. 그 외에 많은 인터넷 서비스와 연동이 가능하고, 막강한 사용자 DB를 가지고 있다는 것이 강점 입니다. | 불법 컨탠츠 유통이란 오명을 벗기 위해 저작권협의가 된 일부 유료 컨탠츠를 판매가 되고 있으나 활용도는 높지 않으며 IPTV나 포탈에 비해 접근도가 낮습니다. 앞으로도 많은 법적 장치에 의한 제제가 예상되며, p2p란 기술 자체에 관한 새로운 비즈니스모델이 필요합니다. |

**마무리 **
현재 포탈과 IPTV 양쪽다 저작권을 모두 사업자가 직접 협의를 합니다만, 이러한 경우 p2p보다 유통양이나 속도면에서 늦을 수 밖에 없습니다. 따라서  컨탠츠 유통 시장도 Mall in Mall 방식으로 하면서 해당 업체들이 유통 플랫폼과 검색 플랫폼을 제공하는 방향으로 가는 것이 맞지 않나 싶습니다. 해외 드라마와 에니메이션 수는 방송 3사에서 유통되는 수를 훨씬 뛰어넘게 마련이니까요. 그리고 성인물도 더 이상 음지에서 청소년들에게 무분별하게 노출되는 상황도 제도권안에서 유통되었으면 하고 바래봅니다.

어떤 서비스가 되었던 간에 우리 문화 산업을 위해 컨탠츠 유통 시장은 정상화 되야 할 것입니다. 하지만 현재 시장의 모습을 무시할 수는 없죠. 현재 시장의 흐름을 바꿀 수 있는 좋은 서비스와 법안들이 나오기를 바랍니다.

Recently, there have been strong calls for the normalization of the video content market. With Korean films gaining popularity and home theaters becoming widespread, we must avoid following in the footsteps of Korea's packaged game market. Therefore, I will compare P2P, which has historically been at the forefront of illegal distribution, with the recently expanding IPTV, and the newly launched download services from portals.

| Category | IPTV {{IMG:1}} | Internet Portal {{IMG:2}} | P2P {{IMG:3}} |
| --- | --- | --- | --- |
| Description | A business launched by broadcasters using internet technology, connecting directly to a TV to watch broadcasts. A major advantage is the ability to watch terrestrial real-time content. | Started by portals, which have the majority of internet users as subscribers, in conjunction with filmmakers and the 'Good Downloader' campaign to normalize the download market. | Began with Soribada's MP3 distribution, recognized as a traditional channel for illegal content distribution, allowing large amounts of data to be distributed cheaply. |
| Major Operators | 3 major telecom companies (SK, LG, KT) | Portal operators (Naver, Daum, Paran) | Small and medium P2P operators (Pruna, MFile, Xtoc, Fileguri, etc.) |
| In terms of operator size, the order is IPTV, Portal, P2P. | | | |
| Subscribers | Relatively average | Relatively many | Relatively few |
| Currently, portals have the most subscribers, but telecom subscribers are rapidly flowing into IPTV, showing significant growth. P2P users are relatively fewer in number, but they often act as power users and digital hubs, leading to a large ripple effect. | | | |
| Pricing | New releases 3500 won ~ Free DRM (48 hours) | New releases 3500 won ~ 500 won DRM (present/absent) | Under 500 won (packet, subscription billing) |
| IPTV has no means to transfer files to other mobile devices and is most strongly blocked by DRM. For portals, the lack of free content is a drawback, while Daum's lack of DRM is an advantage. P2P is superior in price competitiveness by several times, causing other methods to lose their competitive edge in the content transaction market. This is because P2P operators do not pay copyright fees for illegally distributed content. | | | |
| Content Volume | Average | Few | Many |
| P2P, with active user participation, has the most diverse content, while portal operators, being the latest entrants, have the fewest. | | | |
| Content Acquisition Speed | Average | Average | Very fast |
| In the case of P2P, users rip the content they want, so content acquisition speed is very fast. Other services that require copyright negotiation are much slower, and it's difficult for them to match the diversity. Especially for foreign dramas and animations, P2P shows an overwhelmingly faster acquisition. To secure competitiveness for legal services like IPTV or portals, increasing the volume and acquisition speed of content is very important. After all, there are users who download content because they find waiting for IPTV bothersome. | | | |
| User Accessibility | Excellent | Good | Low |
| IPTV has no burden of turning on a PC; P2P sites involve the hassle of navigating to minor sites and accessing communities. | | | |
| Search | Low | Excellent | Good |
| The biggest problem with IPTV is that searching is not easy. The remote control is inconvenient and slow compared to a keyboard, and the poor search UI makes it very inconvenient compared to internet sites, which seems to be an area that needs urgent improvement. Portals, traditional search powerhouses, are expected to provide diverse and powerful search services by linking with integrated search. For P2P, many words are filtered due to copyright issues, but users access desired content and communities by circumventing these filters in various ways. While copyright filtering is a major inconvenience, searches are conducted by exploiting the weaknesses of search filters. (Harry Potter -> H.a.r.r.y P.o.t.t.e.r -> Hally Potter) | | | |
| Adult Content | Weak | Weak | Strong |
| Recently, Japan raised a copyright dispute with Korea over adult content, but ultimately, the copyright was not recognized. This content, often called 'yadon' (porn) unlike typical R-rated films, is a primary source of revenue for P2P sites. To fundamentally eradicate P2P, the copyright issue of adult content must be addressed even more vigorously than that of films. Youth protection measures remain only on portals and IPTV, and P2P is a complete blind spot. If we are to tackle illegal content distribution, adult content is precisely what must be addressed. | | | |
| UCC Support | Limited utilization | Extensive utilization | None |
| UCC fundamentally started in a web environment, so it shows the most utilization on the web. However, revenue sharing for producers is not happening for all, and IPTV offers limited UCC services in conjunction with portals. P2P can be said to be a service far removed from UCC. | | | |
| Mobile Support | None | Limited support | Content acquisition by users |
| For mobile devices, files cannot be moved externally due to DRM, making IPTV completely unable to support them. Portals offer some support in MP4 format but do not provide various formats suitable for different devices. P2P sees mobile content produced and distributed by users, centered around communities for mobile device playback. With the rise of smartphones like DivX-compatible phones and iPhones, the need for mobile video playback is expected to grow as much as MP3s. | | | |
| Future Development Direction | Leveraging its strength as the most accessible home appliance, it has a high potential to transform into the easiest media distribution platform. It's easy to secure traditional broadcast content, and it's expected to have separate specifications for mobile IPTV. | It has high potential to develop into web TV and is most accessible to internet users. If mobile full browsing becomes possible and a seamless, inexpensive wireless environment is established, it is expected to be utilized as an app or a separate mobile application. Additionally, its strengths include the ability to link with many other internet services and possessing a powerful user database. | To shed its stigma of illegal content distribution, some copyrighted paid content is being sold, but its utilization is not high, and accessibility is lower compared to IPTV or portals. Many legal restrictions are expected in the future, and a new business model for P2P technology itself is needed. |

**Conclusion**
Currently, both portals and IPTV operators directly negotiate all copyrights, but in such cases, distribution volume and speed are inevitably slower than P2P. Therefore, I believe it would be appropriate for the content distribution market to adopt a 'Mall in Mall' approach, where relevant companies provide distribution and search platforms. The number of foreign dramas and animations will naturally far exceed what the three major broadcasters distribute. And I hope that adult content, too, will be distributed within the institutional framework, rather than being indiscriminately exposed to teenagers in the shadows.
Regardless of the service, the content distribution market must be normalized for the sake of our cultural industry. However, we cannot ignore the current state of the market. I hope that good services and legislation will emerge to change the current market trends.
