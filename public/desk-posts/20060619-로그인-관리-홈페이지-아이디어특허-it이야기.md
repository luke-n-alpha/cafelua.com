로그인 관리 홈페이지

0. 문제제기
- 사람들이 많은 사이트에 가입하지만 정작 자신이 어디어디에 가입했는지 조차 잊어버린다.
그리고 심지어는 암호를 잃어버리기도 한다.
이 문제를 해결하기위해 소프트웨어가 있으나,
대부분 자기 컴퓨터외에는 설치가 불가능하다.

1. 개념
- 웹에서 직접 로그인 아이디를 관리 해주는 사이트
- 하나의 아이디로 자신이 쓰는 모든곳을 통과시켜준다.

2. 대강의 기능
1) 본 웹사이트에 먼저 로그인한다.
2) 사용할수 있는 기능
- 개인정보 변경/탈퇴 : 일반적인 사이트와 동일
- Home 설정 : 로그인하면 웹브라우져의 첫페이지처럼 설정할수 있다.
- Myfavorite 편집
- 추천사이트
- 가입한 곳 찾아보기
- 메일 보내기/받기

3) 로그인 후에는 창 최상단에 heigt*10정도의 메뉴바가 생성된다.
아래는 모두 창으로 이용된다. 브라우져내의 브라우져라고 생각하면 되겠다.
다만, 모든 정보는 브라우져가 아닌 서버에 암호화되어 저장된다.

메뉴의 내용
- 내 정보 :
1) 개인정보 수정

2) 내가 여태껏 사용했던 사이트들의 정보 보여주기
흐름을 볼수 있다. 이 정보는 모두 서버에 저장되며 이를 이용하여 CRM에
이용할수 있다.

3) 메일 설정(외부메일을 지원하여 외부메일을 받아온다./ 웹진 수신여부설정)

4) 가입한곳 찾아보기 : 이 기능은 주민등록번호를 토대로 로봇이 돌아다니며
사이트들을 돌아다녀서 가입한 사이트를 찾아준다. 결과물이 나오는데는
시간은 꽤 오래 걸린다.
(기술적 문제가 가장걸린다. --;)

- 현재 이용중인 사이트 주소 : 현재 이용중인 사이트의 주소가 표기된다.
- 받은 메일 표시 : 클릭하면, 메일리스트를 보여준다.
- 즐겨찾기 추가 버튼 : 즐겨찾기에 추가된다. (그룹관리 지원)
- 즐겨찾기 이동 : 즐겨찾기는 자주 찾는 것이 상단으로 이동되어 빠른 이동성을 도모한다.
- 자동 로그인 설정 :
클릭시 로그인 설정 페이지로 이동한다.
자신이 가입되있는 홈페이지 리스트가 나온다.

- 자동로그인 / 아이디만 자동입력 / 아무것도 적지않음 (사이트마다 설정할수 있다)
- 추천사이트 : 광고성이 짖다. 다만, 내 정보의 인터넷이용의 CRM을 통해
사용자에게 맞는 사이트를 추천해준다.

3. 수익성
- 웹진 서비스를 이용하여 수익창출
- 광고베너, 추천사이트 등록

4. 문제점 : 1) 웹서핑중 가입이나 사용시 어떻게 아이디와 비밀번호를 추출하느냐... 기술문제
2) 컴퓨터에 흔적을 안남기는 보안문제 , 해킹대비
3) 가입한곳을 찾아보기 : 기술적 문제의 난점...

Login Management Homepage

0. Problem Statement
- People sign up for many websites, but often forget where they've registered.
And sometimes they even lose their passwords.
While there is software to solve this problem,
most of it cannot be installed outside of one's own computer.

1. Concept
- A website that directly manages login IDs on the web.
- Allows you to pass through all the places you use with a single ID.

2. General Features
1) First, log in to this website.
2) Available features
- Change/Withdraw personal information: Same as a typical website
- Home settings: Can be set as the web browser's homepage upon login.
- Edit Myfavorite
- Recommended sites
- Find where you've signed up
- Send/Receive mail

3) After logging in, a menu bar of approximately heigt*10 will be created at the top of the window.
Everything below will be used as a window. Think of it as a browser within a browser.
However, all information is stored encrypted on the server, not in the browser.

Menu Contents
- My Information:
1) Edit personal information

2) Show information about the sites I've used so far
You can see the flow. All this information is stored on the server and can be
used for CRM.

3) Mail settings (supports external mail to retrieve external mail / webzine subscription settings)

4) Find where you've signed up: This feature uses a robot based on your resident registration number to
browse websites and find sites you've signed up for. It takes
quite a long time for the results to appear.
(Technical issues are the biggest hurdle. --;)

- Current site address: The address of the currently used site is displayed.
- Display received mail: Clicking shows the mail list.
- Add to Favorites button: Adds to favorites. (Group management supported)
- Move Favorites: Frequently visited items move to the top for quick access.
- Auto-login settings:
Clicking moves to the login settings page.
A list of websites you've registered for appears.

- Auto-login / Auto-fill ID only / Do not enter anything (can be set per site)
- Recommended sites: Heavily promotional. However, it recommends sites suitable for the user
through CRM of my internet usage information.

3. Profitability
- Revenue generation using webzine services
- Advertising banners, recommended site registration

4. Problems: 1) How to extract ID and password when signing up or using during web surfing... Technical issue
2) Security issues of not leaving traces on the computer, protection against hacking
3) Finding where you've signed up: Technical difficulty...
