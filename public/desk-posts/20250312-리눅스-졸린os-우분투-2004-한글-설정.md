During the Zorin OS installation process, a drawback of Linux I encountered was the inconvenience of immediate Korean/English key switching, even after installing in Korean and setting up a Korean keyboard. Especially in applications like Windsurfer or coding tools, the issue of Korean characters only being typed in place was critical. I'm documenting the process of assigning it to Alt+R to use it exactly like Windows. Zorin OS was no different; I tried to use `ibus`, the default input method, but **the right Alt (Alt_R) key was being assigned by the system first**, so I ultimately decided to use `fcitx5`.

✅ Install fcitx5 and Change Input Method

First, install `fcitx5` and the Korean input engine.
```bash
sudo apt install fcitx5 fcitx5-hangul fcitx5-frontend-gtk2 fcitx5-frontend-gtk3 fcitx5-frontend-gtk4 fcitx5-frontend-qt5
```
After installation, you need to change the input method settings to fcitx5.
```bash
im-config -n fcitx5
```
The default input method will be set to fcitx5. However, it might not be applied to environment variables, so run the following commands to fix the settings.
```bash
echo "export GTK_IM_MODULE=fcitx5" >> ~/.profile
echo "export QT_IM_MODULE=fcitx5" >> ~/.profile
echo "export XMODIFIERS=@im=fcitx5" >> ~/.profile
source ~/.profile
```

✅ Resolving the Right Alt (Alt_R) Key Korean/English Switching Issue

The problem is that in Zorin OS (GNOME environment), the right Alt key is often assigned as a system shortcut by default. Therefore, to use Korean/English switching properly in fcitx5, you must first disable GNOME from intercepting the Alt_R key, and then configure it directly in fcitx5.

First, disable GNOME's setting that uses the Alt_R key as a system shortcut.
```bash
gsettings set org.gnome.desktop.wm.keybindings activate-window-menu "['']"
gsettings set org.gnome.desktop.wm.keybindings switch-input-source "['']"
gsettings set org.gnome.desktop.wm.keybindings switch-input-source-backward "['']"
gsettings set org.gnome.mutter overlay-key "''"
gsettings set org.freedesktop.ibus.general.hotkey triggers "[]"
gsettings set org.freedesktop.ibus.general.hotkey switch "[]"
gsettings set org.gnome.settings-daemon.plugins.keyboard active false
```
Now, set Alt_R as the Korean/English toggle key in fcitx5.
```bash
fcitx5-configtool
```
    * Go to the "Global Config" tab
    * Click Alt+Hangul in the "Input Method Switching" section
    * Click the "Add new key" button and directly input Alt_R
    * Apply and save

After applying the settings, restart fcitx5.
```bash
killall fcitx5
fcitx5 -r &
```

**✅ Force Alt_R Setting Using Xmodmap**

If Alt_R still doesn't function as the Korean/English toggle key even after applying the method above, you can force-map Alt_R as the Korean/English toggle key using Xmodmap.
```bash
xmodmap -e "keycode 108 = Hangul"
```
This only applies to the current terminal. To apply automatically on boot:
```bash
echo "keycode 108 = Hangul" >> ~/.Xmodmap
xmodmap ~/.Xmodmap
```

**✅ Korean/English Switching Test**

Now, press the Alt_R key to confirm that Korean/English switching works correctly.
Conclusion
Now, you can use fcitx5 as the default input method and still switch between Korean and English with the Alt_R key. If, even after performing this, the Alt_R key is occasionally not recognized or fcitx5 doesn't start automatically, you can log out and log back in, or run `fcitx5 -r &`.
