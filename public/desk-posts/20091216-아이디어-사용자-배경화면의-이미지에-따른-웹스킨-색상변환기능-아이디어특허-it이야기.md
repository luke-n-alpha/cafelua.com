**제목: 사용자 배경화면의 이미지에 따른 웹스킨 색상변환기능**
**최초 작성일 :** 2009년 05월 18일
**작성자 : **숲속얘기 ([http://blog.naver.com/fstory97](http://blog.naver.com/fstory97))
****
네이버 블로그 스킨에 대한 아이디어였습니다. 해당 내용은 스킨의 이미지에 따라 사용자 배경이미지가 올려지고 남은 부분의 대한 색상 선택, 그리고 사용자 배경 이미지 적용 이후 전경색에 보정에 관한 내용입니다.
****

**1. 적용 범위 : 블로그 스킨**
**3. 방법 : **스킨의 Background 이미지 적용시 해당 이미지 색깔을 분석하여 가장 어울리는 뒷 배경 색을 선택하도록 해준다. (네이버의 경우 현재는 그냥 거의 하얀색)
**4. 구현 방법 **
- 스킨의 이미지 업로드시 이미지의 칼라의 평균을 구한다.
RGB 값의 히스토그램의 평균을 구하면, 가장 많이 사용된 평균색상을 찾아낼 수 있다.
* 해당 방법은 그림이나 계산식으로 제시 가능
- 해당 평균값을 Background색으로 자동 선택 하거나 이용자에게 추천한다.

**[2] 배경 색에 따른 적응 컨탠츠(전경) 색상 자동 변환
******

**1. 적용 범위 : 변경 가능한 배경색을 사용하는 모든 웹
2. 내용 :**
포스팅 작성시의 본래 색깔이 아니라 배경 색에 따라 자동으로 웹의 글자색이 변경되는 시스템
**3.1 자연스러운 색상 변형**
** - 사람의 시각의 경우, 조명의 색깔에 따라 실제 색깔을 다르게 본다.
- 웹에서도 배경은 곧 조명역할을 하게 할 수 있다. (배경을 조명으로 본 개념)**
**   3.1.1 구현 내용**
- 본래의 색깔 + 배경의색 (조명색) = 변경된 색깔
* 배경의 색을 조명색을 구하는 방식은 3D의 랜더링효과 계산 가능, 그러나 이경우 계산양이 크므로, 간단하게 RGB값의 합산만으로도 비슷하게 구현이 가능하다.
**  3.2. 명시성이 높이기 위한 색깔 변형**
- 기존의 글자색과, 배경의 색이 거의 같은 경우 글자가 보이지 않는다. 대표적으로 검정색과 흰색의 글자가 많이 사용되지만, 어떤 글자든 그러한 경우는 존재할 수 있다.
- 이 경우, RGB합산이나 조명으로 배경색을 더하는 등의 적용은 불가능하다. 색상의 차이가 거의 없으므로 색의 합산이 되지 않을 뿐더러 명시성은 더 낮아져 유저에게는 불편하다.
**  3.2.1 구현 내용
**  ** - 색상의 차이값이 작은 경우, 보색으로 역산한다.
**   - 색상의 차이값이 배경값의 일정 범위 이상으로 비슷한 경우, 해당 색상의 보색을 취한 후, 다시 배경색을 조명으로 계산하여 전경색을 재구성할 수 있다.

**Title: Web Skin Color Transformation Function Based on User Background Image**
**First Written:** May 18, 2009
**Author:** Forest Story ([http://blog.naver.com/fstory97](http://blog.naver.com/fstory97))
****
This was an idea for a Naver blog skin. The content concerns selecting a color for the remaining area after a user's background image is uploaded based on the skin's image, and then adjusting the foreground color after the user's background image is applied.
****
**[1] Web Skin with Adaptive Background Image and Resolution**

**1. Scope: Blog Skin**
**2. Content:** When using a blog, the blog's background image often repeats and looks strange depending on the screen resolution. Most blog background images are typically based on a width of 1024 pixels. However, for LCD monitors, 1280 is common, and 1600 looks even stranger. This section proposes a solution to this problem.
**3. Method:** When applying a skin's background image, analyze the image's colors and select the most suitable background color for the remaining area. (In Naver's case, it's currently almost always white.)
**4. Implementation Method**
 - When uploading a skin image, calculate the average color of the image.
  By calculating the average of the RGB histogram, the most frequently used average color can be found.
 * This method can be presented with diagrams or formulas.
 - Automatically select this average value as the background color or recommend it to the user.

**[2] Adaptive Content (Foreground) Color Automatic Transformation Based on Background Color**
******

**1. Scope: All websites that use changeable background colors**
**2. Content:** A system where the text color on a webpage automatically changes based on the background color, rather than the original color used when writing the post.
**3.1 Natural Color Transformation**
** - In human vision, actual colors are perceived differently depending on the color of the lighting.
 - On the web, the background can also serve as lighting. (Concept of viewing the background as lighting)**
**   3.1.1 Implementation Details**
    - Original color + Background color (lighting color) = Changed color
     * The method of calculating the background color as a lighting color can be done using 3D rendering effects, but since this involves a large amount of calculation, a similar effect can be achieved simply by summing RGB values.
**  3.2. Color Transformation for Increased Legibility**
     - If the existing text color and background color are almost the same, the text becomes invisible. While black and white text are commonly used, such situations can occur with any color.
   - In this case, applying methods like RGB summation or adding background color as lighting is not possible. Since there is almost no difference in color, color summation won't work, and legibility will decrease further, causing inconvenience to the user.
**  3.2.1 Implementation Details
**  ** - If the color difference value is small, invert to a complementary color.
**   - If the color difference value is similar beyond a certain range of the background value, the foreground color can be reconstructed by taking the complementary color of that color and then recalculating the background color as lighting.
