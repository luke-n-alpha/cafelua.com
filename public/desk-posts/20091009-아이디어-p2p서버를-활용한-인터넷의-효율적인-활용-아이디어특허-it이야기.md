1. 제목 : p2p서버를 활용한 인터넷의 효율적인 활용
2. 작성일 : 2009년 6월 25일
3. 배경
- 많은 PV와 대형 가입자를 유치한 서비스의 경우 많은 비용을 소요한다.
- 사용자의 PC나 DTE(모뎀)의 경우 많은 시간 동안 유휴자원 상태에 있다.
- 현재 p2p는 특정 서비스의 동영상과 미디어와 파일의 공유에만 이용한다.
- 인터넷의 모든 자원은 URL이란 고유한 주소를 통해 식별이 된다.
- 대부분의 인터넷 자원들은 수시로 갱신되지는 않는다.
- 수초에서 수분단위로 갱신되는 자원이라할지라도 PV가 높은 페이지의 경우에는 많은 장비 비용이 투입된다.

5.1) 서비스 시스템에서의 p2p 서버로 인터넷 자원의 주소 등록
해당 시스템에 활용될 지원들은 DNS p2p 서버에 인터넷자원의 고유의 주소를 신고한다.

Client주소는 1개가 아니라 다수를 알려주어 변경 및 사용자의 응답이 없을 경우 전송 지연을 최소화한다.

5.7) Client에서의 다른 Client의 자원 다운로드
- p2p서버로부터 인터넷 자원의 주소를 받은 경우, 해당 주소들에 접속하여 데이터를 다운로드 한다. 이때 해당 자원들의 전송 상태나 위변조 여부를 검사하여 리포트를 만들고, 해당 리포트를 p2p서버로 전송한다.

5.8) 리포트를 받은 p2p는 Client list의 상태 정보 변경
- 우선순위와 변조, 혹은 응답이 없는 client 리스트(컴퓨터가 꺼져있는 것이 아니라 살아있으나 클라이언트가 삭제되거나 데이터가 소실된 경우)를 갱신

5.9) 서비스 시스템에서 해당 리소스 갱신
- Client List 리셋, Reg_date 변경

5.10) 클라이언트에 쌓인 데이터 삭제
- 클라이언트는 허용 용량을 설정하고, 허용 용량 이내의 데이터만 유지한다. 일정 기간 이상 p2p로부터 요구 받지 않은 데이터는 p2p에 삭제 허용을 요청하고, 삭제를 수행한다.

6. DTE단에 적용
- 실제로 항상 켜져있고, 적은 전력과 CPU를 소모하며 대기중인 자원은 PC보다는 모뎀이나 공유기이다. 해당 DTE에는 어느정도의 소프트웨어 처리능력이 존재한다. 여기에 위의 기능을 처리하는 DSP칩이나 FlashRom과 값이 싸진 Nand메모리를 탑제하여 위의 기능을 수행하는 것을 고려해볼 수 있다. 이 경우 PC의 성능저하 없이 QOS를 보장도 가능하다.

7. 가치
- 최소의 IDC센터 설립으로 비용 절감
- 인터넷 망의 고효율화
- 특정 서비스에 종속되지 않은 플랫폼으로서의 p2p서비스

1. Title: Efficient Use of the Internet Utilizing P2P Servers
2. Date: June 25, 2009
3. Background
- Services that attract high PVs and a large number of subscribers incur significant costs.
- User PCs or DTEs (modems) remain in an idle state for long periods.
- Currently, P2P is only used for sharing videos, media, and files of specific services.
- All internet resources are identified by a unique address called a URL.
- Most internet resources are not updated frequently.
- Even for resources updated every few seconds to minutes, pages with high PVs require substantial equipment investment.

5. Concept
5.1) Registering Internet Resource Addresses with a P2P Server in a Service System
Resources to be utilized in the system register their unique internet resource addresses with the DNS P2P server.

5.2) User Resource Request
- When a query from the user (browser) input is received, the P2P client on the user's PC connects to the P2P server, rather than going through an address via DNS.
- Alternatively, in a typical scenario, the DNS server directly calls the Naver service domain.
- Then, the [http://blog.naver.com](http://blog.naver.com/) server performs a redirect to the P2P server.

- The address of the Original Client is provided to the user, and the user Client's address is registered in the Client list.

Multiple client addresses are provided instead of just one, to minimize transmission delays in case of changes or no response from a user.

5.7) Resource Download from Another Client by a Client
- When a client receives internet resource addresses from the P2P server, it connects to those addresses to download data. At this time, it checks the transmission status and integrity (tampering) of these resources, generates a report, and sends this report to the P2P server.

5.8) P2P Server Updates Client List Status Information Upon Receiving Report
- Updates the client list based on priority, tampering, or non-responsive clients (cases where the computer is on but the client has been deleted or data lost).

5.9) Resource Update in Service System
- Client List reset, Reg_date change.

5.10) Deleting Accumulated Data on Clients
- Clients set an allowed capacity and only retain data within that capacity. Data not requested by the P2P server for a certain period is requested for deletion permission from the P2P server, and then deleted.

6. Application to DTE Units
- Resources that are always on, consume little power and CPU, and are in standby are modems or routers rather than PCs. These DTEs have a certain level of software processing capability. It is conceivable to implement the above functions by equipping them with a DSP chip or FlashRom to handle these functions, along with inexpensive NAND memory. In this case, QoS can also be guaranteed without degrading PC performance.

7. Value
- Cost reduction through minimal IDC center establishment.
- Increased efficiency of the internet network.
- P2P service as a platform independent of specific services.
