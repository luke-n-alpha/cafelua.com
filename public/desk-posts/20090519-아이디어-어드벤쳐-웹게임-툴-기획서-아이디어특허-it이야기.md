In line with the Web 2.0 concept, it features user-participatory games, where multiple users can share, distribute, and modify content.
It seems like more detailed aspects might be needed, such as storing data in XML and aiming for openness.
This was just a plan to create an adventure game tool for the web.
It seems possible to build it by customizing an open-source like Zeroboard. Recently, even PowerEditor has become open-source.
All the conditions are met, but the problem is execution and time.
