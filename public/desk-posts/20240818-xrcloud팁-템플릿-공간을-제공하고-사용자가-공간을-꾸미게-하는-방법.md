XRCLOUD가이드 문서의 업데이트 내용 중 "[XRCLOUD] 템플릿 공간을 제공하고 사용자가 공간을 꾸미게 하는 방법"를 공유합니다.**1. 2D, 3D 멀티미디어 파일 및 pdf파일의 배치를 통한 공간 꾸미기**- XRCLOUD(Hubs)의 Room에는 2D이미지, 영상, pdf문서, 3D오브젝트(glb,gltf)파일을 자유롭게 배치할 수 있습니다.

​**2. Host유저는 ‘고정’ 기능을 이용하여 Room에 영구 귀속 가능**- 이렇게 배치한 사용자의 멀티미디어 파일들은 Room의 세션이 모두 종료되고 새로 접속시에는 사라집니다. 하지만, ‘고정’기능을 이용하여 영구적으로 Room에 추가할 수 있습니다.
- **이 ‘고정’기능은 XRCLOUD의 GetRoomApi에서 제공하는 URL중 Guest URL은 사용할 수 없으며, Host URL로 접속했을 때만 이용이 가능합니다**. 따라서 해당 공간에 Host권한으로 접속한 유저만 공간을 꾸미게 하는 것이 가능합니다. 따라서 플랫폼을 개발시 공간을 꾸밀 수 있는 권한을 마이스페이스의 유저에게 혹은 플랫폼의 관리자에게 같이 차등을 두어 제공할 수 있습니다.

Sharing "[XRCLOUD] How to provide template spaces and allow users to decorate them" from the XRCLOUD Guide document updates.

**1. Decorating a space by arranging 2D, 3D multimedia files, and PDF files**
- In XRCLOUD (Hubs) Rooms, you can freely arrange 2D images, videos, PDF documents, and 3D object (glb, gltf) files.

**2. Host users can permanently assign content to a Room using the 'Pin' feature**
- Multimedia files placed by users in this way disappear when all Room sessions end and new connections are made. However, you can permanently add them to the Room using the 'Pin' feature.
- **This 'Pin' feature cannot be used with Guest URLs provided by XRCLOUD's GetRoomApi; it is only available when connected via a Host URL.** Therefore, only users connected with Host privileges to that space can decorate it. When developing a platform, you can thus differentiate and provide space decoration privileges to MySpace users or platform administrators.

- By using the media frame component, which allows you to snap and pin 2D images, videos, and PDF files to a specific location, you can make them appear fixed according to a more basic format.
- This feature is often used when providing MySpace services or event spaces.
