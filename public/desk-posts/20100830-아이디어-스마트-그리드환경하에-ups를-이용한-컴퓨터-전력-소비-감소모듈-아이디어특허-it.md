**1, 제목 : **스마트 그리드환경하에 UPS를 이용한 컴퓨터 전력 소비 감소모듈

**2. 최초 작성일 : **2009년 8월 19일

**4. 개념 :**
추가 장비 없이 UPS를 전력의 버퍼로 이용하여 전력이 저가인 심야에 충전을 하고, 전력이 비쌀 때 UPS의 일정부분을 사용하여 전기요금을 절감하는 개념

**5. 구성
** - 해당 기기는 UPS의 전력 충전 상황을 체크 하는 모듈
- 스마트 그리드로부터 요금 정보를 가져오는 모듈
- 시스템의 전원을 컨트롤할 수 있는 모듈
세가지 모듈로 이루어져있다.

6. 대게 UPS는 비상 시기 아니면 사용되지 않는 전력이고, 100%가용되는 상태이나  이를 버퍼로 이용시 전력소모를 아낄 수 있다.
- 이때 사용하는 방법은 주식을 매매하는 방법과 동일하다.
ex) 일일 전력 사용 그래프를 예측도 가능하고
분할 매수, 매매 전략등을 그대로 이용시 전력 단가를 낮추는것이 가능

**1. Title:** Computer Power Consumption Reduction Module Using UPS in a Smart Grid Environment

**2. First Draft Date:** August 19, 2009

**3. Background:** In a smart grid environment where electricity rates fluctuate in real-time, efforts are being made to minimize the cost of electricity used by systems.

**4. Concept:**
The concept involves using a UPS as a power buffer without additional equipment, charging it during off-peak hours when electricity is cheap, and using a portion of the UPS's power when electricity is expensive to save on electricity bills.

**5. Configuration**
It consists of three modules:
- A module that checks the UPS's power charging status
- A module that retrieves rate information from the smart grid
- A module that can control the system's power

**6.** Typically, a UPS is unused power except during emergencies, and while it's 100% available, using it as a buffer can save power consumption.
- The method used here is identical to stock trading.
e.g., It's possible to predict daily power usage graphs, and by directly applying strategies like dollar-cost averaging (split buying) and trading, it's possible to lower the unit cost of electricity.
