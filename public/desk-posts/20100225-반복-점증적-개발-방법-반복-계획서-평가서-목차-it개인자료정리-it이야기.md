**주제 : 반복 점증적 개발 방법, 반복 계획서. 평가서 목차 **
작성자 : 숲속얘기 ([http://blog.naver.com/fstory97](http://blog.naver.com/fstory97))
작성일 : 2010년 2월 25일
관련주제 : 소프트웨어 공학, 개발 방법론

**I. Iteration을 특징으로 한 반복 방법론 **
- 반복 점증적 개발방법론은 반복단계마다 목표를 설정하여 다수의 반복단계를 수행함 으로서 점증적으로 최종 완성도 도달하는 방법으로, 위험을 최소화 하는데 의의가 있다.
**II. 반복 계획서의 목차 **

| **목차** | **설명** |
| --- | --- |
| - 반복 범위 | 현 반복 단계의 명확한 범위 설정 |
| - 반복 목표 | 현 반복 단계가 도달 하고자 하는 목표 수준 설정 |
| - 위험 요소 | 현 반복 단계에서 통제 되어할 위험 요소 식별 |
| - 반복 전개 방안 | 목표에 도달하기 위한 전개 방안 기술 |
| - 테스트 방안 | 현 반복 단계의 테스트 방법 |
| - 반복 일정 | 현 반복 단계의 상세 일정 및 리소스 |

**III. 반복 평가서 목차 **

| **목차** | **설명** |
| --- | --- |
| - 목표 달성 리스트 | 목표 수행 척도 |
| - 평가 항목 | 정량화를 통해 KPI를 세움 |
| - 위험 및 대응 계획 | 위험 통제 수준 확인 |
| - 전체 프로젝트 진척도 | 현 반복단계의 현황, 일정, 예산 리소스 |
| - 총평 | 반복 평가의 총평 |

**IV. 점증적 개발 방법은 비용과 일정을 초과하기 쉽기 때문에 반복 단계에 관한 평가를 통한 Trace와 구체적인 목표수준 필요**

Author: Forest Story ([http://blog.naver.com/fstory97](http://blog.naver.com/fstory97))

**I. Iterative Methodology Characterized by Iteration**
- Iterative incremental development methodology is a method that incrementally reaches final completion by setting goals for each iteration phase and performing multiple iteration phases, and its significance lies in minimizing risks.
**II. Table of Contents for Iteration Plan**

| **Item** | **Description** |
| --- | --- |
| - Iteration Scope | Clear scope setting for the current iteration phase |
| - Iteration Goal | Setting the target level to be reached in the current iteration phase |
| - Risk Factors | Identification of risk factors to be controlled in the current iteration phase |
| - Iteration Deployment Plan | Description of the deployment plan to reach the goal |
| - Test Plan | Testing method for the current iteration phase |
| - Iteration Schedule | Detailed schedule and resources for the current iteration phase |

**III. Table of Contents for Iteration Evaluation Report**

| **Item** | **Description** |
| --- | --- |
| - Goal Achievement List | Metric for goal performance |
| - Evaluation Items | Establish KPIs through quantification |
| - Risks and Response Plan | Check risk control level |
| - Overall Project Progress | Status, schedule, budget resources for the current iteration phase |
| - General Review | General review of the iteration evaluation |

**IV. Since incremental development methods are prone to exceeding costs and schedules, a trace through evaluation of iteration phases and specific target levels are necessary.**
