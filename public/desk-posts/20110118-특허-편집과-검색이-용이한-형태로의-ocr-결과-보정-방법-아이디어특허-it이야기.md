1) Original

 
2) OCR Result :

Let's drink knowing what it is.
Alcohol is not a stimulant that excites people,
but rather a depressant, and when people hear this,
they usually react by saying they didn't know.
However, alcohol is clearly a depressant that suppresses the central nervous system.
A typical phenomenon is the suppression of antidiuretic
hormone secretion, which leads to an increase in urine output.
In the same vein, excessive drinking can lead to tragedies such as suffocation or respiratory depression
due to the suppression of the respiratory or vomiting centers.
However, these incidents are usually extreme.
 
The above result is a text file where an enter key exists at the end of every line. This causes inconvenience when copying and pasting the result into a word processor, as the user has to remove all line breaks.
 

 
The OCR results like the above have several problems.
- The phenomenon where a line changes and an enter key is applied in the middle of an unfinished sentence.
- Difficulty in searching for sentences that are cut off between pages when performing OCR on multiple pages.
l Ex) When the last part of the first page does not end a sentence, and the sentence starts on the second page.
- The phenomenon where unnecessary spaces are inserted due to large gaps between printed characters.
 
**5. Solution**
- This problem is solved using a language model and positional information between lines.
 
1) Line Merging: Each line is concatenated and passed to the language model, but parts where the line clearly changes do not need to be concatenated.
Such exceptions include cases where indentation occurs on a line,
e.g., if indentation of more than 0.5 times the height of the previous line is performed, it is implemented to be recognized as a new line.
If the area of the previous line ends without touching the right page margin,
Except for the above exceptional situations, lines are recognized as being connected.
 
2) The data passed to the language model is transmitted with all spacing initialized.
A flag is placed for each character to determine spacing.
e.g., The language model determines this and indicates the presence or absence of spacing for each character.
 
3) A new text result is generated by applying the spacing provided by the language model to the received characters.
Reference URL : [http://s.lab.naver.com/autospacing/](http://s.lab.naver.com/autospacing/)

**6. Effects**
1) Ease of Editing: When pasting into a word processor, there is no longer a need to remove line-by-line enter keys.
2) Correction of spacing typos.
3) Ability to respond to search queries including spacing.
* Currently, cross-line searches in book search assume no spacing, but this can now be determined.
