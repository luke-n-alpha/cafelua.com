포스팅 내용까지 수정해서 올려주었으나, 실패한 포스팅의 용량까지

1. When writing and uploading some posts by pasting content, the upload fails.
 -> If there's an issue with the content being uploaded, a warning should be given on the client side before the page changes, or the content should not be visible even if uploaded.
   Currently, the post itself disappears.
 
2. The file size of attachments from failed posts is also included in the user's daily allowed capacity (5M).
 -> The file size of attachments from failed posts should not be included in the user's daily allowed capacity.
 
I was trying to import a post from [http://tong.nate.com/fstory97/12602922](http://tong.nate.com/fstory97/12602922).
 
I saved the attachments to my PC and Copy & Pasted the content of the post.
For some reason related to the post's content,
the post wouldn't upload and failed every time.
This happened twice, didn't it?
Thinking it was due to the content,
I only attached a description of the file.
Then, the posting was successful.
(Bug 1. Content COPY&PASTED from the URL above cannot be posted.)
However, since I had already uploaded files twice,
it seems I used up my daily 5MB capacity,
and it says I cannot upload more than 5MB per day.
The fact that even the size of files that were not fully posted is included in the user's daily capacity limit ㅡㅡ;
I suspect this problem arises because the capacity is calculated at the time of file upload, not at the time of posting.
Furthermore, if there's a problem like this, when a post fails,
previously uploaded files become dead links and should be removed,
but it seems they are not being deleted from the server either.
Even though I modified and uploaded the post content, including the capacity of failed posts in the user's quota is,
I believe, a stressful experience for users who put effort into uploading.
