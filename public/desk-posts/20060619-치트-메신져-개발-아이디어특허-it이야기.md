* Wellknown포트를 이용하는 방법 :

--- Port사용에 관해 ------
1) 송/수신을 모두 사용가능한 랜덤포트를 이용하거나

p2p같지만 실제로는 중간에 client-server-client시스템

1. Features of this messenger
- Can bypass firewalls by using well-known ports (like web ports) or appear as other signals.
- Can deceive supervisors and professors by freely changing skins (e.g., Excel, Photoshop, Word, HWP).
- Has a self-destruct key, allowing quick and trace-free program deletion.

2. Purpose:
To develop a messenger that increases survival rates in academic and work environments where messenger use is increasingly prohibited.

3. Goals:
1) Not detectable by any firewall.
2) Can deceive any administrator.
3) Can instantly destroy the program, allowing users to feign ignorance even if caught.
4) Develop additional features suitable for highly monitored work environments.

* How to use well-known ports:

--- Regarding Port Usage ------
1) Use random ports available for both sending/receiving, or
p2p (ports decided between both parties are informed to the service server, and the service server, using a client-server system, informs each party of the other's port)
2) Relay using port 80 of the service-side server, like the web.
(If a service server is used, heavy load on the service server is also expected)
Looks like p2p, but is actually a client-server-client system in the middle
