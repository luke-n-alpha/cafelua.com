Caret v0.3.0 has updated its underlying project, Cline, from v3.26.6 to v3.32.7. This is a major update reflecting 421 commits contributed by 38 developers over approximately one and a half months. The main changes are as follows:

{{IMG:1}}

**Major Feature Updates**

* **Focus Chain & Deep Planning**: A task management feature has been added, allowing AI to create and track 'to-do lists' for complex tasks.
* *** YOLO Mode & Voice Mode**: 'YOLO Mode,' which delegates all tasks to AI for automatic execution, and an experimental 'Voice Mode' have been added. (Available with a Cline account. Caret will consider supporting this feature or external API integration.)
* *** Workflow & `.clineignore`**: 'Workflow' for automating repetitive tasks and `.clineignore` for controlling AI access have been added.
* **Synchronized Task History**: All records are synchronized in real-time, even when working across multiple VSCode windows.
* **Latest AI Model Support**: Supports Claude Sonnet 4.5 (1M context), GPT-5, and more.
* **15+ New API Providers**: Broadened choices including Oracle, Dify.ai, Z AI, Hugging Face, Groq, and more.
* **AI Optimization**: API requests are reduced by 30-50% when modifying multiple files at once, and TODO lists are managed more systematically.
* **Protobuf Type System**: Internal communication structure has been reorganized based on Protobuf to ensure stability and speed.
* **Enhanced MCP Support**: Strengthened support for MCP (Model Context Protocol) for integration with external AI tools.
* **UI/UX Overhaul**: Improvements to task headers, focus chain design, settings screen, and more.
* *** 4-Language Cline-Compatible Caret Documentation Site Update**: Caret's documentation site provides all content in 4 languages, including Cline's documentation which is only available in English. If you are curious about the detailed features of Caret or Cline, please visit [[Caret Korean Documentation](https://docs.caret.team/ko/getting-started/what-is-caret)].

**How a Solo Developer Tracks Changes in Large-Scale Open Source with AI**

Operating a project based on rapidly changing large-scale open source with a small team is Caret's biggest challenge. In an era like today, where rapid changes are demanded by AI, it's almost fate for an open-source project to start becoming outdated the moment it's forked. Especially for development based on projects like Cline, which undergo frequent major structural changes, we've learned that it's difficult to keep up with changes using a typical merging process. In the v0.1 era, we chose to directly modify Cline's code, but we felt limitations in the face of rapid and massive changes. So, for the v00.2 update, we established a new principle of 'minimal invasiveness' and undertook nearly two weeks of arduous merging work. And for this v0.3 update, we successfully completed the merge in just one week, half the time compared to v0.2. The background that made this possible was the consistently maintained 'minimal invasiveness' principle and **semantic merging** through AI-based vibe coding. This would have been practically impossible without AI. Although it took one week this time, if we repeat this process a few more times and AI technology further advances, we expect that full automation, tracking upstream changes almost in real-time, will eventually become possible. If that happens, the open-source-based development ecosystem might enter an entirely new phase.
