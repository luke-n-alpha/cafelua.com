]**1. ****제목 : OCR 문서의 페이지번호와 인덱스를 추출하기 위한 방법**

**2. ****배경 :** 구글에서 OCR을 통하여서 디지타이징을 수행하고 있으며, 네이버 역시** 디지타이징**을 수행하고 있다. 그러나, 현재 OCR에서 페이지 번호는 스캔 파일명에 의한  방법과, 페이지번호를 사람이 **수동**으로 입력하는 방법을 취하고 있다.
이를 OCR된 문서로부터 **페이지번호**를 추출하는 방법을 제안하고자 한다.

**3. ****방법 : ****
**  OCR된 결과는 영역 정보와 텍스트의 결과의 쌍으로 나타나게 된다. 이중, 페이지 번호와 인덱스의 경우, 책에서 공통적으로 나타나며, 위치 또한 일정하다. 이를 OCR시스템으로 검출하는 방법이다.

: 페이지 번호는 상단 혹은 하단에 위치 한다.

**1. ****Title: Method for Extracting Page Numbers and Index from OCR Documents**
 
**2. ****Background:** Google is performing digitization through OCR, and Naver is also performing **digitization**. However, currently, page numbers in OCR are handled either by using the scanned filename or by **manually** entering the page number.
 We propose a method for extracting **page numbers** from OCR'd documents.
 
**3. ****Method:****
 OCR results appear as pairs of region information and text. Among these, page numbers and indexes commonly appear in books, and their positions are also consistent. This is a method to detect them using an OCR system.
   
**1) ****Conditions for Page Numbers****
    - Page numbers are numeric (numbers) in text information.
    - Position:
     : Page numbers are located at the top or bottom.
{{IMG:1}} 

[Red Area]
  
: It is located in an independent area, separate from the main text.
{{IMG:2}}

: If information exists on whether the image is a left page, a right page, or both pages at once, it is possible to predict the probability of the page number being on the left, right, or both sides of the image, and assign weights accordingly.
{{IMG:3}}
- If an image like the above consists of two files, and file #1 has information indicating it's a left page, the page number is likely to be in an area biased to the left. For file #2, it's likely to be in an area biased to the right.
- Alternatively, if it's a single file, it's likely to be located on either the left or right side.

 
: When a series of images (pages) are processed by OCR, if it's a single page, the page number area is likely to be close to the position of the page number on the previous second page. If it contains both left and right pages, it's highly likely to match the position of the immediately preceding page.

       [File #1]                          [File #2]

       [File #3]                          [File #4]
 
Ex) The position of the page number in File #1 and File #3 is the same.
: Page numbers consist of a single number.

   : When a series of images (pages) are processed by OCR, the number information in the text of the page number area of the previous page is likely to increase linearly, and this probability can be increased based on the fulfillment of conditions.
Ex) In the example above, the page numbers from the recognition results of files #1, #2, #3, and #4 are likely to increase sequentially, and this can be used in the OCR recognition results.
    
**-> ****By calculating the above conditions using formulas or probabilities, confirm the page number area and then input it as metadata in the OCR result.****
