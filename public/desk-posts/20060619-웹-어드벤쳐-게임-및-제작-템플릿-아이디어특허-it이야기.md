최초 작성일 : 2002. 04. 08

1. 웹어드벤쳐 : 아주 옛날 즐기던 간단한 그래픽과 텍스트로만 진행되던 어드 벤쳐 게임을 웹에서 템플릿을 제공하여 누구나 쉽게 제작하고 플레이 할수 있도록 한다.
유사사이트로 어드벤쳐 게임을 제공하는곳은 있지만, 템플릿을 제공하여 제작이 가능하도록 한곳은 없다.
-- 연재소설을 쓰는것 처럼 게임을 진행할수있도록 하는것이 목표다.
제작자와 플레이어간에 상호교감이 이루어질수 있도록 충분한 환경을 제공 한다.

-- 현재는 어드벤쳐 툴만 계획했지만, 차후 육성시뮬레이션같은것도 웹툴로 제공할 수 있다.

------------- 구현 --------------------------
1. 이 서비스는 (게이머/제작자)로 나누어진다.

2. 먼저 제작자는 자신의 페이지를 생성할수 있다.
그래서 그 제작자는 마치 소설 연재하듯 게임을 연재하고,
일반 사용자는 그 페이지에 접속하여 게임을 즐기고,
진행이 안되는 부분이나 다온 부분에서는 세이브를 할수 있다.

ex) 1. 양병석(외계인의 침략 연재중..)
2. 김영수(그녀와의 사랑 연재중..)
3. 박영희(엽기적인 그녀 완결)

3. 게임 페이지.. 간단한 그래픽+텍스트 위주. 그리고 선택문으로 이루어진다.
그리고 각페이지로 링크가 되어 게임을 진행한다.

- 페이지 변환이나 특수효과등은 dhtml같은것을 이용하여 효과를 넣어준다.
- login정보를 이용하여 아이템 습득이나 이벤트 진행정도등을 기록할수 있다.

4. 게임은 장소위주/케릭터위주 로 생각해볼수 있다.
- 장소위주 게임은 주어진 이벤트를 진행시켜 갈수 있는 장소를 늘려 나가면서
마지막 장소(페이지)에 도착하면 게임이 종료되는것이다.

- 케릭터 위주 게임은 연애시뮬레이션을 생각해본것인데..
가상케릭터는 스케쥴에 따라 각 장소에 등장한다.
그 스케쥴은 이벤트에 따라 약간의 변동이 가능하며..
주어진 시간(페이지-장소를 이동할때마다 게임내의 시간이 흐른다)
내에 게임을 완료못하면 Game over가 되기도 한다.

케릭터에 맞는 아이템이나 이벤트를 실행하면 케릭터가 공략되며
마지막에 원하는 케릭터의 엔딩을 볼수 있다.

5. 제작자 페이지
1) 처음에 장소위주 게임인지, 케릭터 위주 게임인지 택일한다.

** 장소위주라면 처음에 장소리스트를 보여준다.
** 장소를 클릭하면 장소 에디팅과 이벤트 에디팅으로 나누어진다.
-- 장소 에디팅은 장소의 기본적인 풍경(이미지파일 업로드나 배경음악
셈플로 주어진것을 고를수도 있다)
간단한 풍경 설명/ 보이는 아이템 목록

-- 아이템은 공원이라면 공중전화/벤치/가로등.. 알아서 생성할수 있다.
이건 텍스트 정보다.

-- 아이템의 기본적인 설명을 적는다.
* 케릭터가 그 장소에서 관찰을 선택하고 벤치를 선택했을때..
" 무척 더러운 벤치가 보인다. " 라고 출력하도록..

-- 장소에서 이벤트에디팅을 고르면 그 장소에 이벤트를 에디팅할수 있다.
이벤트는 일련번호가 붙어있고.. 다른 이벤트가 실행되야만 실행되는것에
관한 것을 속성을 정한다.

-- 여기서 이벤트라 함은 텍스트에 간단한 이미지 포함하는정도..

** 케릭터 위주는 훨씬 더 복잡해진다.
-- 케릭터 에디팅 하는 페이지가 더 존재한다.

최초 작성일 : 2002. 04. 08

1. Web Adventure: This service provides templates for simple graphic and text-based adventure games, which were popular in the past, allowing anyone to easily create and play them on the web.
While there are similar sites that offer adventure games, none provide templates for creation.
-- The goal is to allow games to progress like a serialized novel.
It provides a sufficient environment for creators and players to interact.

-- Currently, only an adventure tool is planned, but in the future, even育成 simulation games could be offered as web tools.

------------- Implementation --------------------------
1. This service is divided into (gamer/creator).

2. First, creators can create their own pages.
The creator can then serialize a game as if writing a serialized novel,
And general users can access that page to enjoy the game,
And save their progress at parts that are stuck or completed.

ex) 1. Yang Byeong-seok (Alien Invasion serialized..)
2. Kim Young-soo (Love with Her serialized..)
3. Park Young-hee (My Sassy Girl completed)

3. Game page.. mainly simple graphics + text. And consists of choices.
And links to each page to progress the game.

- Page transitions and special effects can be added using DHTML or similar.
- Login information can be used to record item acquisition or event progress.

4. Games can be thought of as place-centric / character-centric.
- In a place-centric game, you progress through given events, expanding the places you can go,
The game ends when you reach the final place (page).

- A character-centric game is envisioned as a dating simulation..
Virtual characters appear at various locations according to a schedule.
This schedule can vary slightly depending on events..
If the game is not completed within the given time (time in the game flows each time you move pages/locations), it can result in Game Over.

By performing items or events appropriate for the character, the character can be攻略 (conquered/won over),
And finally, you can see the ending of your desired character.

5. Creator Page
1) First, choose whether it's a place-centric game or a character-centric game.

** If it's place-centric, a list of places is shown first.
** Clicking on a place divides into place editing and event editing.
-- Place editing includes basic scenery of the place (uploading image files or choosing from provided background music samples)
Simple scenery description / list of visible items

-- Items can be created as needed, e.g., for a park: public phone/bench/street lamp.
This is text information.

-- Write a basic description of the item.
* When the character chooses to observe in that place and selects the bench..
"A very dirty bench is visible." is displayed.

-- If you choose event editing in a place, you can edit events for that place.
Events have serial numbers.. and properties are set for events that only run after another event has run.

-- Here, an event means text with simple images included.

** Character-centric is much more complex.
-- There are additional pages for character editing.
