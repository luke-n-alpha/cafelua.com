**0. 배경 **
브라우져의 시작화면만큼이나 중요한 포지션이 개인 PC와 핸드폰의 바탕화면이다.
많은 회사들이 자체 바탕화면을 제작한다.
원하는 취향의 바탕화면을 찾기가 힘들다.
****
**1. 바탕화면 스마트파인더
- 업체 바탕화면 (공식 바탕화면) / 사용자 바탕화면 (일반 유저 업로드된 데이터)
- 유저 추천 시스템

**2. 효과 :** 업체 광고, 게임 광고, 연애인 프로모션

**3. 바탕화면 제작기 제공 (Flex, Silverlight ,Java applet, Window App)**
** - 네이버 카페의 대문 꾸미기와 비슷한 형태이면 될듯**
1) 소스 이미지 업로드
3) 달력 템플릿 입히기
4) 문구 입력
5) 바탕화면 공유하기 (아이템 팩토리 형태)
6) 바탕화면 검색 (스마트파인더)

적당한 바탕화면을 찾기가 힘들어서 생각해 본겁니다.
특히 달력이 포함된건 2009년 이전것도 많고.
취향대로의 바탕화면을 쉽게 찾아주는 서비스가 있었으면 좋겠다는 생각에 작성해봤던겁니다.

**0. Background**
The desktop wallpaper on personal PCs and mobile phones holds a position as important as a browser's start screen.
Many companies create their own wallpapers.
It's hard to find wallpapers that match one's desired taste.

**1. Wallpaper Smart Finder**
- Search by resolution, calendar inclusion, categories like anime, games, illustrations, photos, celebrities, and other tags.
- Company wallpapers (official wallpapers) / User wallpapers (data uploaded by general users)
- User recommendation system

**2. Effects:** Company advertisements, game advertisements, celebrity promotions

**3. Provide Wallpaper Creator (Flex, Silverlight, Java applet, Window App)**
- It could be similar to decorating the main page of a Naver Cafe.
1) Upload source image
2) Select resolution (stretch * shrink * crop)
- Various resolutions from 1920 to 320, or selection by mobile device model.
3) Apply calendar template
4) Enter text
5) Share wallpaper (item factory style)
6) Search wallpaper (Smart Finder)

I thought of this because it's hard to find suitable wallpapers.
Especially those with calendars, many are from before 2009.
I wrote this with the hope that there would be a service that easily finds wallpapers according to one's taste.
