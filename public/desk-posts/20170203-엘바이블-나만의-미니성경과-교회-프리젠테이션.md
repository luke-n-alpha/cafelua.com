지난번 엘바이블 하드웨어 소개에 이은 두번째 소프트웨어 소개를 할까 합니다. 먼저 만들어진 소프트웨어는

[엘바이블 :: 함께 사용하고 함께 만드는 온라인 성경 소셜네트워크 elbible.com](http://elbible.com/)

입니다.

현재 특징은 회원가입이 가능하고(탈퇴 수정이 아직 없어요 ㅋㅋ), 한국어와 영어 성경을 쓸수 있으며, 사용한 단말에서는 마지막 읽은 위치에서 읽을수 있습니다. 단순히 쿠키에 위치를 저장하고 있기 때문이죠.  bootstrap과 codeignitor로 개발했으며, cafe24에서 500원짜리 호스팅을 돌리고 있습니다. 장점은 별도의 설치가 필요 없고 매우 가볍다는겁니다.

{{IMG:1}}

심플 성경

로그인 하시면 북마크용도로 사용가능한 간단한 좋아요(하트 마크)가 가능하며, 글쓰기를 눌러서 말씀을 선택하거나 혹은 그냥 단독으로 메모가 가능합니다.

{{IMG:2}}

좋아요, 성경메모

{{IMG:3}}

선택 안하고 그냥 메모도 가능합니다.

원래 소셜기능등을 포함하려 했으나, 아직 안했습니다. 여력이 없어서 아마 할지 모르겠습니다.

{{IMG:4}}

아마 100년후 구현될지 모르는 소셜기능

더 치명적인건 아직 메모 작성한건 한페이지에 100개를 노출시켜놨는데 자동 페이지 넘김도 구현 안했습니다. 샘플코드는 찾아놨는데 ㅜㅜ 아직까지 적용을 안할정도로 게으릅니다.

현재 소스는 [https://github.com/elbible/elbible.com](https://github.com/elbible/elbible.com) 에 올라가 있습니다.
설명은 부실하고, 코드는 난잡합니다.

{{IMG:5}}

https://blog.naver.com/PostView.naver?blogId=fstory97&logNo=220926705067&redirect=Dlog&widgetTypeCall=true&noTrackingCode=true&directAccess=false#

혹, 나만의 성경을 만들고 싶다면, 코드를 조금만 안다면 간단한 lamp나 호스팅만으로 해볼수 있을겁니다.

무엇보다도 제가 자부하는 기능은 바로 프리젠테이션입니다.
구현은 아주 간단한데,  선택 구절을 새창으로 뿌려주는 기능과, 메모한 문구와 구절을 새창으로 뿌려줍니다. 이걸 노트북에 hdmi로 물려서 확장형으로 바탕화면을 설정후, 자식창은 프리젠테이션 화면으로 넘기고 F11(전체화면)을 설정하면 손쉽게 나만의 방송실이 됩니다. 부모창에서 비디오 버튼을 눌러주시면 미리 만들어놓은 문구로 바뀝니다. 텍스트도 쓸수 있으니 문구가 아닌 주기도문이나 찬송가 텍스트도 넣어놓을 수 있죠.

{{IMG:6}}

리스트에서 누르면 바뀜

가끔 목사님이 갑자기 다른 구절을 찾으셔도, 부모창에서 성경탭을 눌러 해당구절을 찾은후, 선택해서 비디오 버튼을 누르면 자식창에 바로 찾은 말씀이 뿌려집니다.
** * 브라우저는 크롬만 기준해서 개발했습니다.  크롬을 꼭 설치 하시길 바라며, 크기는 175% 정도 해놓으면 어르신들도 잘 봅니다.**

{{IMG:7}}

이렇게 관제 모드가 됩니다.

만약 노트북이 없으시다면 핸드폰으로도 가능합니다. 안드로이드 핸드폰은 확장 디스플레이 연결이 안되는게 단점이라 시나리오와 다른 말씀을 보여주는것은 어렵습니다. 앱도 있습니다. (그런데 버그는 보장 못함. 안쓴지 오래되서.. 노트북이 편합니다.) 안드로이드앱은 그냥 웹뷰로 [elbible.com](http://www.elbible.com/)  을 쌓은게 사실 다 입니다.

[[엘바이블 프로젝트 - 앱 다운로드] 함께 쓰고 함께 만드는 온라인 성경 SNS플랫폼 elbible.modoo.at](http://elbible.modoo.at/?link=18n61swf)

지난번 함께 뭐라도 모여서 만들 의지를 가지신 개발, 디자이너, 기획, 문서화 라도 도움을 주실 크리스챤 능력자를 모은다는 포스팅을 올렸습니다. 몇몇 분들이 연락을 주셨고, 차주 월요일 저녁에 역삼에서 1차 킥오프 미팅을 가지려고 합니다. 온라인 페이스북 그룹은  비공개 그룹을 만들었고, 이를 중심으로 1개월에 1회 정도 오프라인에서 만나고 온라인으로 계속해서 무언가 만들어가자는 정도의 계획이 있습니다.
이것이 엘바이블이 될지 혹은 무엇이 될지는 모르겠지만요.

Following the previous introduction to Elbible hardware, I'd like to introduce the second part: the software. The first software created is

[Elbible :: An online Bible social network that we use and create together elbible.com](http://elbible.com/)

It is. Current features include user registration (no withdrawal/modification yet, lol), the ability to use Korean and English Bibles, and the ability to resume reading from the last read position on the device used. This is simply because the position is stored in a cookie. It was developed with Bootstrap and CodeIgniter, and is running on a 500 won hosting plan from Cafe24. The advantage is that it requires no separate installation and is very lightweight.

{{IMG:1}}
    Simple Bible

Upon logging in, you can use a simple "like" (heart mark) for bookmarking purposes, and by clicking "Write," you can select a verse or simply make a standalone memo.

{{IMG:2}}
    Like, Bible Memo

{{IMG:3}}
    You can also just make a memo without selecting anything.

I originally intended to include social features, but I haven't yet. I'm not sure if I'll get to it due to lack of resources.

    Social features that might be implemented 100 years from now

What's more critical is that I've displayed 100 memos per page, but I haven't even implemented automatic pagination yet. I've found sample code, but I'm too lazy to apply it yet ㅜㅜ. The current source code is available at [https://github.com/elbible/elbible.com](https://github.com/elbible/elbible.com). The description is poor, and the code is messy.

{{IMG:5}}

https://blog.naver.com/PostView.naver?blogId=fstory97&logNo=220926705067&redirect=Dlog&widgetTypeCall=true&noTrackingCode=true&directAccess=false#

If you want to create your own Bible, you can do so with a simple LAMP stack or hosting if you know a little bit of code.

Above all, the feature I'm most proud of is the presentation function.
The implementation is very simple: it displays selected verses in a new window, and also displays memoized phrases and verses in a new window. By connecting this to a laptop via HDMI, setting up an extended desktop, moving the child window to the presentation screen, and pressing F11 (fullscreen), you can easily create your own broadcast room. If you click the video button in the parent window, it changes to a pre-made phrase. Since you can also use text, you can put in the Lord's Prayer or hymn texts instead of just phrases.

{{IMG:6}}
    Changes when clicked from the list

Even if the pastor suddenly looks for a different verse, you can click the Bible tab in the parent window, find the relevant verse, select it, and then click the video button to immediately display the found verse in the child window.
** * The browser was developed specifically for Chrome. Please make sure to install Chrome, and if you set the size to about 175%, even seniors can see it well.**

{{IMG:7}}
    This is how it becomes control mode.

If you don't have a laptop, you can use your phone. The downside of Android phones is that they don't support extended display connections, making it difficult to demonstrate scenarios beyond the basic phone screen. There's also an app. (However, I can't guarantee bugs. It's been a long time since I used it... A laptop is more convenient.) The Android app is essentially just a webview wrapper for [elbible.com](http://www.elbible.com/).

[[Elbible Project - App Download] Online Bible SNS Platform built together elbible.modoo.at](http://elbible.modoo.at/?link=18n61swf)
