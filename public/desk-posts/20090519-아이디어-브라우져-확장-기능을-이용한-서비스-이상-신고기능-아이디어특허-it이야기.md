1. 제목 : 브라우져 확장 기능을 이용한 서비스 이상 신고기능

2. 관련 서비스 : IE 네이버 툴바, 파이어폭스 확장 익스텐션
[http://toolbar.naver.com/home/index.nhn](http://toolbar.naver.com/home/index.nhn)
[http://t.lab.naver.com/firefox/](http://t.lab.naver.com/firefox/)

3. 배경 : 파이어폭스와 크롬, 사파리등 다양한 브라우져들의 유저들이 증가하며,
크로싱 브라우져 대책이 중요한 사항이 되어가고 있다.
그러나 비용등을 이유로 이에 대한 QA가 충분히 실행되고 있지 못한것이 현실이다.
대부분의 사용자들은 포탈의 서비스가 이상하다고 느끼는 경우 그냥 브라우져를 바꾸거나
다른 포탈의 서비스를 이용하게 된다.

4. 대책 : 웹서핑 중 유저들에게 피드백을 할 수 있는 기능을 브라우져 테마(IE툴바/파이어 폭스익스탠션)에서 제공한다.

5. 효과 :
1) 손쉬운 신고 기능
: 유저들이 따로 고객게시판을 찾을 필요가 없다.
2) 버그의 정보들을 손쉽게 취득한다
: 유저의 웹브라우징 히스토리
: 브라우져의 버젼 정보
: 버그 URL
: 버그 페이지 화면 캡춰
3) 위의 가용 정보를 이용하여 해결책 제시 페이지 이동기능

6. 시나리오
1) 유저는 네이버 테마, 네이버 툴바가 설치된 브라우져를 이용중이다.
2) 유저가 파이어폭스/IE/사파리 등을 이용하여 포탈내 서비스를 이용하다 버그(레이아웃 깨짐, 혹은 서비스 이상페이지)를 발견한다.
3) 유저는 버그 신고 버튼을 클릭한다.
4) 브라우져는 이상 페이지의 URL, 이상 페이지의 랜더된 화면을 캡춰 한다.
5) 페이지는 자동으로 네이버 고객게시판으로 이동된다.
6) 고객게시판의 Form정보에 자동으로 브라우져가 가지고 있던 정보들을 제공한다.
- 가용 정보
: 이상 페이지 출현전 까지 유저 서비스 이용 히스토리
: 이상 페이지 화면 캡춰 파일
: 이상 페이지 URL
: 브라우져 버젼 정보
7) 위의 가용정보를 살펴보고, 유사 신고가 접수되어 이전에 해당 이상기능에 대한 대책이 DB에 있는 경우,
해결책을 추천해 줄 수도 있다.
8) 유저는 고객 게시판에 부가적인 내용을 적어 신고한다.
9) 서비스 회사는 유저 불만 정보를 살펴보고, 문제를 해결한다.

1. Title: Service Anomaly Reporting Feature Using Browser Extensions
 
2. Related Services: IE Naver Toolbar, Firefox Extension
   [http://toolbar.naver.com/home/index.nhn](http://toolbar.naver.com/home/index.nhn)
   [http://t.lab.naver.com/firefox/](http://t.lab.naver.com/firefox/)
 
3. Background: As the number of users of various browsers such as Firefox, Chrome, and Safari increases, cross-browser compatibility measures are becoming crucial. However, due to reasons such as cost, sufficient QA for this is not being carried out, which is the current reality. Most users, when they feel a portal service is abnormal, simply switch browsers or use services from another portal.
 
4. Solution: Provide a feedback feature for users during web surfing through browser themes (IE Toolbar/Firefox Extension).
 
5. Effects:
 1) Easy Reporting Feature
  : Users do not need to search for a separate customer support board.
 2) Easily Obtain Bug Information
  : User's web browsing history
  : Browser version information
  : Bug URL
  : Screenshot of the bug page
 3) Feature to navigate to a solution suggestion page using the available information above
 
6. Scenario
 1) The user is using a browser with the Naver theme and Naver Toolbar installed.
 2) While using a portal service with Firefox/IE/Safari, the user discovers a bug (e.g., broken layout or abnormal service page).
 3) The user clicks the bug report button.
 4) The browser captures the URL of the abnormal page and a rendered screenshot of the abnormal page.
 5) The page automatically navigates to the Naver customer support board.
 6) The browser automatically provides the information it held to the form fields on the customer support board.
  - Available Information
   : User's service usage history until the abnormal page appeared
   : Screenshot file of the abnormal page
   : URL of the abnormal page
   : Browser version information
 7) By reviewing the available information, if similar reports have been received and a solution for the abnormal function exists in the database, a solution can be recommended.
 8) The user adds additional details to the customer support board and submits the report.
 9) The service company reviews the user's complaint information and resolves the issue.
