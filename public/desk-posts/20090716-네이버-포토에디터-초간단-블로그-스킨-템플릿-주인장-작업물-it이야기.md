**포토샵없이 블로그 스킨을 만들어보자 !**
******네이버 포토에디터 초간단 블로그 스킨 템플릿**
****
**1. 네이버 블로그를 쓰는 이유는 바로 편리한 스킨 편집과 공유**
제가 네이버를 쓰는 가장 큰 이유중 하나는 스킨 편집과 공유가 편리하다는겁니다. css와 html을 쓰면 더 강력하다고들 설치형 블러거들을 주장할지 모르겠지만, 전 그런거 싫습니다. 밥만먹고 쳐다보는게 그거인데, 블로그 할때도 그거 하라고요? 더군다나 전 디자이너가 아닙니다. 사내 디자이너분들에게 블로그 스킨 부탁했다가는 욕먹겠죠 {{IMG:1}}
또한 대부분의 라이트 유저들도 같은 생각일 거라고 생각합니다. 미니홈피처럼 블로그처럼 모두 쓸 수 있다는것이 바로 네이버 블로그의 매력이죠.

**2. 하지만 PSD를 다루는 그래픽 툴은 몽땅 유료 ㅜㅜ**
****
지난번 포토샵의 PSD 파일로 만들었던 스킨 탬플릿을 만들었었습니다.
[http://blog.naver.com/fstory97.do?Redirect=Log&logNo=70048721378](http://blog.naver.com/fstory97.do?Redirect=Log&logNo=70048721378)
그러나 회사에서는 포토샵을 사용할 수 없고, 오픈 캔버스 역시 PSD를 지원하는 놈은 상용입니다. 키젠을 구해서 설치하긴 했지만 찝찝하던 참에 네이버랩의 포토에디터가 레이어를 지원한다는 사실을 알고 해당 포맷에 맞게 고쳤습니다. {{IMG:2}}

**3. 그래서 만들었다! 네이버 포토에디터 블로그 스킨 템플릿 !**
** 따라해보면 아주 쉬운 스킨 만들기, 다른 소프트웨어를 깔 필요도 없습니다. 필요한건, 여러분이 지금 이 포스팅을 보고 있는 브라우져 하나면 끝 !! **{{IMG:3}}

 Due to the blog's capacity limit, I uploaded the 2.7M NPE file split into two RAR files. You can see that the file size is significantly reduced compared to Photoshop. This is because it's basically PNG compressed with ZIP, and it doesn't include the powerful but rarely used information found in Photoshop.
 Individuals can use ALZip to extract it, and those in companies can find suitable tools like Bandizip and RAR tools to extract it.
 Then you'll get the file below.
   blog_template.npe
 If you're curious about the format, you can uncompress this file again to see it, but I don't think many people will be curious, so I won't explain it.

 2. Launch Naver Photo Editor
[http://s.lab.naver.com/pe/](http://s.lab.naver.com/pe/)
{{IMG:5}}
 It works well on both Firefox and IE. I recently switched from Chrome to Firefox, so I haven't tested Chrome, but it should work fine since it's Flash-based.
 
 {{IMG:6}}
You'll see a screen like the one above. Click the **Import button** below.
Select "My PC", and when the file dialog appears, find and click the downloaded NPE file.

{{IMG:7}}
Now you should see this screen. It has loaded successfully.
Click the layer button in the top right to open the layer window.
You can check the final image by toggling the checkbox for the content layer. (Below is how it looks with the content layer turned off.)
{{IMG:8}}
 
**3. Load the image to use**
{{IMG:9}}
 Find a 1280*1024 image, which is commonly used for desktop backgrounds.
I'll use one of the images I collected from [http://memolog.blog.naver.com/fstory97/540](http://memolog.blog.naver.com/fstory97/540). Download that image and then click the **Import button** in the Photo Editor again to load that file. After loading, you'll see two files loaded below. Naver Photo Editor can load up to 5 image files. **(Sometimes there's a bug where importing doesn't respond, and you have to try twice to import.)**
{{IMG:10}}
 
**4. Copy the image**
 Select the {{IMG:11}} selection tool at the top and drag your mouse to select the entire image as shown below.
{{IMG:12}}
Right-click your mouse, and you can copy. You can also press Shift+C.
The Select tool is basically rectangular, but if you hold the tool down, it can change to other selection tool shapes.
If you want to try compositing characters, you can also use the magic wand tool.
 
**5. Paste**
 Select the first NPE file you loaded below. The layer window looks like this. You can paste what we copied over the sample background. If you have unnecessary layers, select them and click the red minus button at the bottom of the layer window to delete them.
{{IMG:13}}
 After selecting the sample background layer and pasting, it will look like this.
{{IMG:14}}
 If the layer order is incorrect, you can change the order of layers by dragging them.
 
**6. Adjust as desired**
* Think of layers as transparent sheets for easier understanding.

  Below is how it looks when the content layer is turned on to check the application.
{{IMG:16}}
 
**7. Save**
 To save the final image, turn off the content layer.
{{IMG:17}}
Click the save button. The image will be saved exactly as it appears. Use JPG as the file format.
{{IMG:18}}
Enter your desired filename and click save, and the file will be created.
****
**File Saving Tip)** Backup is essential!!!
1) If you save the NPE file, you can edit it again later.
2) To create a thumbnail, turn on the content layer, save as JPG, and then adjust the image size to easily get a thumbnail.
 
**8. Apply to your blog**
** **Click the remote control, then select the top area of the skin background. If you select the pattern area, the image will repeat below and look strange. Then, load the final saved image. (If it exceeds the size limit, increase the JPG compression rate when saving in step 7.)
{{IMG:19}}

**Remote Control Editing Tips)**

 2) The top blog menu and Naver menu will be visible if you change their colors according to your chosen background.
