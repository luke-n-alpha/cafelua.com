I upgraded the x98 air 3g tablet, known for its excellent value for money, to Windows 10. There were several twists and turns, but the upgrade was successful and I'm using it well, so I'm documenting the upgrade process.

**1. Download Windows 10. It must be 32-bit.**
First, download Windows 10. I eagerly awaited the automatic Windows 10 upgrade in the bottom right corner on July 30th, but it remained in a reserved state, so I downloaded it manually. The download URL is below. The reason it must be 32-bit is that the x98air 3g's original drivers are 32-bit.

[**Windows 10** www.microsoft.com](https://www.microsoft.com/ko-kr/software-download/windows10)

**2. Download and install. But an OTL error occurred.**
After the download was successfully completed, I encountered the following error: **"Could not initialize working directory."**

{{IMG:1}}

https://blog.naver.com/PostView.naver?blogId=fstory97&logNo=223833996878&redirect=Dlog&widgetTypeCall=true&noTrackingCode=true&directAccess=false#

{{IMG:2}}

The reason is insufficient internal storage space. I spent a long time looking for the cause. Although the minimum required space for the Win10 upgrade was stated as 3GB, the download only takes about 2.6GB, and there wasn't enough free space for installation, meaning the actual required space is much larger.

**3. Move the downloaded Win10 to the D drive on the microSD card.**
I still had space on my D drive because I use a 64GB microSD card. So, you need to move the downloaded files to the D drive and install them from there.

1) Press Windows+E to open File Explorer.
2) Go to My PC > Local Disk (C:)
3) In the top menu, select View > check Hidden items.
This will show two folders below: C:\Window.~BT, C:\Window.~WS
**4) Cut and paste (move) the hidden C:\Window.~WS folder to the D drive, D:\Window.~WS**

**4. Now restart the installation.**
If you do this, you should have free space on your C drive. Rerun the installation by clicking the file below: **D:\Window.~WS\Sources\Windows\Setup.exe**

It will download again. But there's no need to worry. Unlike before, you won't encounter a 'problem occurred' message, and the installation will complete successfully.

Click Disk Cleanup (D). Select "Previous Windows installation" from the Disk Cleanup items and click OK to free up space.
