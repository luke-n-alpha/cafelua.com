# 삽화 자산

- `cover-no-text.png` — 번역·재조판용 무문자 커버 원화.
- `cover-with-text.png` — 제목 《화성 침공》, 부제 ‘AI와 함께 소설을 만든 제작노트 포함’, 저자명이 들어간 한국어 커버.
- `cover-30.png` — 콘텐츠 스튜디오가 표시하는 현재 정식 커버. `cover-with-text.png`와 같은 이미지.
- `cover-mars-invasion.png` — 커버. 상륙선·붉은 습지·성곽·초록 이끼의 첫 대조.
- `01-red-descent.png` — 3장 〈붉은 낙하〉용. 커버와 같은 장면을 본문 삽화로도 사용할 수 있는 세로 판.
- `02-flare-first-battle.png` — 5장 〈첫번째 싸움〉용. 조명탄 아래 노출된 대병력과 하향풍을 일으키는 공격헬기.

나머지 삽화의 구도와 배치 원칙은 `../art-direction.md`를 정본으로 한다. 본문 삽화와 무문자 커버에는 제목·작가명·부대 표식·국기·대사를 넣지 않는다. 텍스트 포함 커버만 제목·부제·저자명을 사용한다.
