# 9장 스프레드 가이드

카드를 3x3 그리드로 배치합니다.

```
[과거]   [현재]   [미래]
[잠재력] [도전]   [목표]
[조언]   [외부]   [결과]
```

## 각 포지션 의미

### 1행 - 시간의 흐름

| 위치 | 의미 |
|------|------|
| **과거** | 현재 상황에 영향을 준 과거의 사건이나 에너지 |
| **현재** | 지금 겪고 있는 상황, 중심 에너지 |
| **미래** | 현재 흐름이 이어질 때 예상되는 방향 |

### 2행 - 내면과 외면

| 위치 | 의미 |
|------|------|
| **잠재력** | 아직 발휘되지 않은 숨겨진 힘과 자원 |
| **도전** | 마주해야 할 장애물, 극복 과제 |
| **목표** | 의식적으로 바라는 결과, 지향점 |

### 3행 - 조언과 결론

| 위치 | 의미 |
|------|------|
| **조언** | 카드가 전하는 핵심 메시지와 제안 |
| **외부** | 주변 환경, 타인의 영향과 시선 |
| **결과** | 모든 요소를 종합한 최종 방향성 |

## 해석 순서

1. 전체 배열 조망 (어떤 카드들이 나왔는지)
2. 시간순 해석 (과거 → 현재 → 미래)
3. 중심축 해석 (도전 - 잠재력 - 목표)
4. 조언과 결론 (조언 → 외부 → 결과)
5. 전체 통합 메시지

## 역방향(reversed) 카드

카드가 뒤집혀(역방향) 나오면 해당 카드의 에너지가 약화되거나, 내면화되거나, 반대 의미를 가질 수 있다. 예를 들어 나쁜 결과가 나왔을 때 특정 카드를 뒤집어서 나쁜 결과를 바꿀 수 있다. 이처럼 흐름을 뒤집고 싶은 경우 역방향을 응용할 수 있다.
